# 1~6장 시험예상문제 v4 디자인 변경판

v3의 동일한 75문항을 복습문제 공통 템플릿으로 표시하는 디자인 변경판이다. 새 문제 세트가 아니다.

- 상단바, 목차, 패널 크기 조절, 문제별 이전/다음, 라이트/다크 모드는 복습문제 템플릿을 공통 사용한다.
- 전체 제출 전에는 정답·출처를 숨긴다. 제출 후 현재 문제의 정답·풀이·출처를 오른쪽 패널에서 확인한다.
- 제출한 답안은 채점 결과와 일치하도록 잠기며, 다시 풀기로 입력과 정답 공개를 함께 초기화한다.
- 단답형의 기존 정답·허용답·대소문자 규칙을 보존한다. 미등록 표현은 자기채점 대기다.
- 기존 문항 본문·보기 순서·정답·풀이·그림·표와 새 카드 75개를 비교했다. 버전별 자원 경로 외에는 모두 동일하다. 그림 및 로컬 라이브러리 파일 바이트도 동일하다.
- 앞으로 생성하는 시험문제도 같은 공통 화면을 사용하도록 생성기와 스킬 지침을 수정했다.

## 검증

생성기 테스트 53개 통과. 저장소 테스트 120개 통과, 1개 기존 건너뜀(43 subtests). 저장소 명령은 `PYTHONPATH=tests .venv-question-bank/bin/python -m pytest -q`이다. Swig 의존성의 DeprecationWarning 5개가 있다.

실제 결과물의 1280×900 및 375×812, 밝은/어두운 화면에서 75문항 이동, 정답 비공개, 55개 객관식·20개 단답형 정답 채점, 허용답 대소문자 처리, 미등록답 대기, 초기화와 가로 넘침을 검사했다. JavaScript 비활성·제출 전 인쇄에서도 답 노출이 없었다. JavaScript 오류 및 외부 자원 요청은 0이다. 전환 애니메이션이 끝난 화면을 저장해 복습문제 기준 화면과 직접 비교했다.

## 검토 기록과 해설

이번 발행은 화면 변경 검증이다. 학술 내용의 근거는 기존 v3의 완료된 원자료·내용·독립 풀이 검토이며, 새로 학술 검토했다고 주장하지 않는다. v4의 새 출제용 question-review.json은 초기 상태 그대로 두고, 화면 변경 검증은 presentation-review/status.json에 별도 기록했다. 일반 새 출제 세트의 completion-status와 혼동하지 않는다.

별도 해설 내용은 동일한 문항을 다룬 기존 [v3 문제해설](../../문제해설_1장-6장_시험예상_v3.html)을 사용한다. v1~v3와 기존 해설 파일은 변경하지 않았다.

자세한 결과 및 화면은 presentation-review/에 보관했다. 커밋·푸시는 하지 않았다.
