## 경향 반영

매 실행의 공통 MD 두 개와 현재1~6장 은행·intake·장별 feedback(존재하는 파일)을 새로 읽었다. 비교 단위(염색체수/DNA양, 전구체/성숙mRNA, 핵/미토콘드리아), 단계·방향(합성/교정, 명/암반응), 명칭(정지/넌센스), 조건부 확률, 상황을 바꾼 원리 적용을 반영했다. 자체 그림은 세포주기 DNA량 그래프이며 그림 판독2문항·문제 표 판독3문항이다. 유형은 중복 가능하고 장별 고정비율·실제 난이도 통계로 주장하지 않는다.

공통 webquiz-style의 4장 ‘정본 bank 미등록’ 서술은 오래된 상태다. 현재 complete 검증된15문항 은행을 사용했다. 공통MD에 없는 오늘6장 경향은 오늘 등록된 questions/intake/feedback로 직접 확인했다. 원본 MD를 자동 수정하지 않았다.

- content/scope/style: 75문항의 모든 보기와 해설 판정 대응·계산·단위·범위·경향을 검토했다. 잘못된 보기를 풀이하는 데7장 이후 지식이 필요하지 않다.
- independent: 정답키·해설·출처 설계표를 보지 않은 별도 풀이자가 그림·표를 보존한 blind HTML을 풀었다. 75답이 키와 일치했다. 수업의 사람 유전체 근삿값3/3.2는 둘 다 명시 허용답에 들어간다.

- 단답형: NFC·양끝 공백 정규화와 명시 허용답만 자동 일치. 낯선 표현은 자기채점 대기, 빈 답은 미응답이다.

## 이전 버전·수정·중복

실행 전 기존 검증 완료 시험예상 세트는 없었다. 같은 RUN의 v1·v2는 원전 경로 정규화 및 일부 보기의 부분 단서 제거 전의 미검증 초안으로 보존했다. v3가 최종 검토본이다. 같은 RUN 초안은 이전 출제 이력으로 세지 않는다. 최종75개는 정확 payload·generated stem·선정 family 중복0이다. 감수분열·전사번역 등 넓은 교과 기전 가족은 서로 다른 판단 단위를 묻는다. p44의3′말단 연장 원리는 p38교정 방향 추론에 도움을 주지만 최종 답을 직접 제공하지 않는 원리 단서로 기록했다. 두 문항의 세부 판별은 다르다.

질문/해설 합계 수정 기록은2회이며 `review-evidence/repair-history.json`에 보존했다. 최초 해설 조립 전의 저작 자체검토·보기 라벨 대응 편집은 해당 author evidence에 보존했다.

## 공식 답·누락 자료·한계

- 실제 웹과제 공식 채점 화면이 없어 공식 답은 미확인이다. 원문의 선택 표시는 분석 답이나 학습자의 오개념으로 간주하지 않았다. 제공 기출의 붉은 인쇄 답과 일치함을 확인했지만 기관 공식 답안의 독립 provenance까지 확인한 것은 아니다.
- 1장 intake.md와 note-feedback.md는 부재로 manifest에 missing 기록했다. STT/1019 생명.md도 현재 없으므로1019범위는 사용자 확인과6장 전체 강의노트·교과서로 설정했다.
- 원자번호 문항(p2)은 제공1장 교재 스캔에서 해당 원소/원자 절 인쇄4~5쪽이 발견되지 않아 교재에서 직접 확인했다고 주장하지 않는다. 원 기출 PDF 인쇄키A와 독립 풀이의 양성자 수 판정은 일치한다.
- p20은 기출·수업의 동원체 표현과 교재 중심절(centromere)/동원체(kinetochore) 용어차이를 해설에 공개했다. p23의 p53 단백질 고유 사멸 유도 문장은 열람한 교재와 해당 STT 인용구에서 직접 확인하지 못했다. 웹 원문·종양억제 일반원리·p53 대표성·독립 풀이와의 일치와 이 직접 출처 확인 한계를 구별해 기록했다.
- 미해결 정답 충돌·범위 초과·문항 결함으로 보류한 최종 선정 문항은 없다. 검증 통과는 실제 시험 형식·난이도·예측 적중률을 보장하지 않는다.

기초 입력의 변경·삭제 또는 manifest의 missing 파일 신규 등장은 현재 검토를 무효화한다. 다음 실행은 최신 자료를 다시 읽어야 하며 기존 HTML이 자동 갱신되지는 않는다.
