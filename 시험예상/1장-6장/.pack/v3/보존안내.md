# 기존 해설과 학술 검토 근거 보존

사용자 승인에 따라 학습용 v1~v8 문제 HTML을 폐기했다. 현재 학습용 문제는 v9다. 기존 해설의 본문과 이 폴더의 자료·그림·카드·vendor·검토·manifest를 보존한다. 공개 해설 HTML의 원 문제 보기 링크 75개만 v9의 같은 문항으로 연결했다. 변경 전 해설 원본은 review-evidence/original-explanation-v3.html.txt에 바이트 그대로 보존했다.

v3 문제 HTML은 당시 검토 해시를 대조하기 위한 비공개 증거인 review-evidence/retired-question-v3.html.txt로 보존했다. 원래 경로와 SHA-256은 review-evidence/retired-source.json에 있다. 이 파일은 배포용 문제판이 아니다.

기존 completion-status.json, question-review.json, 해설 manifest와 validation은 당시 검증 기록이다. 원본 경로의 문제 HTML을 제거했으므로 현재 경로에서 v3 발행 게이트가 다시 성공한다고 주장하지 않는다. 원본 경로·검토 해시를 새 파일에 맞춰 바꾸거나 v9에 승인으로 복사하지 않았다. 해설의 화면 자원은 계속 원래 경로에서 제공한다.

v9는 같은 문항의 제목과 화면·동작을 변경한 사용자 확정 레퍼런스이며, 검증 상태는 .pack/v9/presentation-review/와 version-retirement.json을 참고한다. 이번 정리는 향후 생성된 이전 버전의 자동 삭제 정책이 아니다.
