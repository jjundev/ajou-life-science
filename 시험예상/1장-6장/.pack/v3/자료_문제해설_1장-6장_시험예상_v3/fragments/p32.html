문제를 먼저 읽어요

“유전자 정량”은 X에 있는 유전자의 활성량을 보정하는 현상을 찾아요. 공식 웹과제 정답 미확인의 분석 답이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

XX 세포는 X가 두 개, XY 세포는 X가 하나예요. 포유류 암컷 체세포에서 X 하나를 불활성화하면 두 성의 X 연관 유전자 발현량 차이를 줄여요. 이것이 유전자 정량 보정(dosage compensation)이에요. 유전자가 어디에 있는지, 염색체가 잘못 분리되는지, DNA가 재조합되는지와 구별해요.

왜 이렇게 푸는지 함께 따라가요

A. 유전자 복사는 유전자 사본이 늘어나는 변화예요. XX 세포의 X 하나를 꺼 발현량을 보정하는 현상과 다르므로 부적합해요.

B. X-염색체 연관은 유전자가 X에 위치한다는 뜻이에요. 위치 정보만으로 X 연관 유전자의 활성량을 같게 하는 기전은 설명하지 못해요.

C. X-염색체 비분리는 염색체가 분열 때 제대로 갈라지지 않는 현상이에요. 정상적인 XX 세포의 발현량 보정 기전이 아니에요.

D. 재조합은 대립유전자 조합이 바뀌는 일이에요. X 하나를 비활성화해 발현량을 조절하는 현상과 달라요.

E. X-염색체 불활성화는 XX 세포의 X 하나를 주로 꺼 X 연관 유전자 발현량을 보정하므로 적합해요.

따라서 분석 답은 E예요.

완성 답과 검산

X 수를 다시 비교하면 XX에서는 활성 X를 하나로 줄일 수 있고 XY에는 원래 X가 하나예요. 선택지 중 활성 X 수를 직접 조정하는 것은 E뿐이에요. 웹과제 공식 정답은 미확인이에요.

XX 세포의 X 하나를 불활성화해 발현량을 보정하므로 분석 답 E예요.
