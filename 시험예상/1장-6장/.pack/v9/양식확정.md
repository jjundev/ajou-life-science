# v9 기준 양식 확정과 이전 문제판 폐기

사용자 확정에 따라 시험예상문제_1장-6장_v9.html을 화면·동작 레퍼런스로 사용한다. 이 HTML과 기존 v9 패키지 내용은 변경하지 않았다. bio-exam-forecast/SKILL.md의 빌드 단계에서 references/exam-ui.md를 필수로 읽도록 연결하고, 데이터 계약과 브라우저 검토 기준을 보완했다. 향후 출제는 최신 범위·원자료·경향과 새 학술 검토를 따르며 이전 버전을 자동 삭제하지 않는다.

## 폐기와 보존

v1~v8 문제 HTML 8개와 불필요한 v1·v2·v4~v8 패키지 7개를 제거했다. 기존 v3 해설과 필수 .pack/v3 자료·그림·폰트·카드·검토·manifest는 보존했다. v3 문제 원본과 링크 변경 전 해설 원본은 .pack/v3/review-evidence/의 .html.txt 파일로 남겨 당시 해시를 검증할 수 있다. 이 증거 파일은 배포용 문제판이 아니다.

기존 공개 해설의 원 문제 보기 링크 75개만 v9의 해당 문항으로 바꿨다. 해설 본문·정답·자료는 유지했다. 원래 검토 기록의 경로와 해시를 다시 쓰지 않았다. 과거 complete/validation 기록은 당시 기록이며, 삭제된 v3 원래 경로에서 현재 발행 게이트가 성공한다거나 v9가 새 학술 검토를 받았다고 주장하지 않는다. 상세 삭제 목록과 원본 해시는 version-retirement.json, 보존 해설의 주의사항은 ../v3/보존안내.md에 있다.

## 확인 결과

- 스킬 frontmatter 검증 통과. 독립 읽기 전용 검토에서 새 범위 시험에 v9 양식을 적용하는 시나리오 통과.
- 생성기 테스트 61개 통과. 저장소 테스트 120개 통과, 기존 1개 건너뜀, 43 subtests 통과(기존 SWIG 경고 5개).
- 정리 후 실제 v9의 데스크톱/모바일 × 밝은/어두운 네 화면에서 기존 자동 이동·제출·채점·채점표·JSON·초기화 확인.
- 같은 네 화면에서 기존 해설 75문항 모두 접근, 이미지 로딩, 원 문제 보기→v9 연결 확인. 모든 로컬 HTML 링크와 스킬 문서 링크 확인.
- v3 원본 문제의 input_hash를 보존 스냅샷으로 재계산해 당시 question-review와 일치함을 확인. 해설의 기존 context_hashes 1,217개 모두 일치.
- 보존 대상 원본 568개는 그대로이며 공개 해설의 변경 전 원본은 증거 사본으로 확인. 관련 없는 기존 수정 파일 9개도 변동 없음.
