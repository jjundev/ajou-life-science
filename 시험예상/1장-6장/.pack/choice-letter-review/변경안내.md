# 선택지 표시 확정 — 2026-10-19

현재 시험 해설과 향후 exam profile 해설의 문제 패널 보기 표시는 실제 option ID를 사용한 `A.`, `B.` 등으로 통일했다. 기존 원문 선두 `(1)` 등은 브라우저 표시에서만 대체한다. 원문 문제 HTML, 해설 본문, 정답 모델의 ID와 키는 변경하지 않았다.

공개 HTML은 `시험예상문제_1장-6장.html`, `문제해설_1장-6장_시험예상.html`이다. 화면 제목에서도 v3/v9 표기를 제거했다. 해설의 원 문제 보기 75개 링크를 공개 문제판 경로로 변경했다. 내부 자료·검토 증거의 버전 경로는 보존하고 `.pack/publication.json`에 공개 파일과 원래 내부 버전을 연결했다. 사용자에게 보이는 버전 표기를 없애는 작업이며 과거 학술 검토를 현재 변경의 승인으로 복사하지 않는다.

`before.html.txt`는 이번 보기 표시 변경 직전 해설이다. 직전 파일명·화면 제목 변경 전 원본은 `../publication-cleanup/`에 보관했다. `change.json`의 보호 대상 파일 해시는 기존 자료·검토 기록의 보존 확인용이다. `verification.json`은 이번 표시·링크·원문 보존 검증이며 새 학술 검토가 아니다.

최종 사용자 수정에 따라 괄호 표기를 점 표기 `A.`, `B.`로 바꿨다. 직전 HTML은 before-dot-labels.html.txt, 최신 검증은 dot-label-verification.json에 보관한다.
