## 실행 전 환경 문제와 조치
- prepare 첫 실행에서 1~6장 questions.json 6개가 모두 `review hash mismatch`로 무효였다. 원인은 작업 트리 전체(3,403개 텍스트 파일)가 CRLF로 다시 체크아웃되어, LF 바이트로 기록된 은행 자산·근거 해시와 달라진 것이었다(시스템 git 설정 core.autocrlf=true). v9 source-manifest의 733개 해시도 LF 바이트와만 일치했다.
- git 인덱스(LF)와 내용이 같은 파일만 커밋된 LF 바이트로 되돌렸고(`git diff` 내용 차이 0), 6개 은행이 모두 `--complete` 검증을 통과했다. 그 뒤 새 RUN으로 prepare를 다시 실행했다. 은행 내용·검토 기록은 수정하지 않았다.
