문제가 묻는 것

이중가닥 DNA 한 분자에서 구아닌(G)이 22%일 때, 나머지 염기 조성에 관한 진술 중 옳지 않은 것을 골라요. 기출 원문이며 답 D는 5강 기출 합본의 빨간 표시(④)와 일치해요.

이 문제를 봤을 때 떠올릴 개념과 공식

‘이중가닥’이라는 조건에서 샤가프의 법칙(Chargaff’s rule)을 떠올려요. 이중가닥에서는 A가 T와, G가 C와 상보적으로 짝을 이루므로 분자 전체에서 [A] = [T], [G] = [C]예요. 이 관계는 두 가닥을 합친 전체에서 성립하며 한 가닥만으로는 성립한다고 할 수 없어요.

네 염기의 합은 100%이므로 한 염기의 비율에서 나머지를 구할 수 있어요. 또 DNA의 염기는 A·T·G·C이고, 우라실(U)은 RNA에서 T 자리에 오는 염기예요.

관련 정리노트: 상보적인 두 가닥과 이중가닥 전체의 A=T, G=C

첫 줄

G = 22%이므로 C = 22%예요. A + T = 100 − (22 + 22) = 56%이고, A = T이므로 A = T = 28%예요.

왜 이렇게 푸는지 함께 따라가요

A. (원문 1번) 맞아요. DNA의 염기는 A·T·G·C이고 우라실은 RNA의 염기라 DNA에는 없어요. 옳은 진술이라 답이 아니에요.

B. (원문 2번) 맞아요. 계산한 값 T = 28%, C = 22%와 둘 다 일치해요.

C. (원문 3번) 맞아요. T = A = 28%예요.

D. (원문 4번) 틀려요. 아데닌은 28%예요. 44%는 G + C(22 + 22)를 더한 값이거나 22%를 두 배 한 값이라, 한 염기의 비율과 두 염기의 합을 섞은 수치예요.

E. (원문 5번) 맞아요. [G] = [C]이므로 C = 22%예요.

따라서 옳지 않은 진술인 D가 답이에요.

완성 답과 검산

답 D. 계산한 조성을 더하면 A 28 + T 28 + G 22 + C 22 = 100%로 맞아요. 반대로 A가 44%라면 T도 44%여서 합이 44 + 44 + 22 + 22 = 132%가 되어 불가능해요. 거짓 진술은 D 하나이고, 강의노트 5장 PDF p1의 “[A] = [T], [G] = [C]”와 5강 기출 합본 PDF p5 문항 41의 빨간 표시 ④와 일치해요.

이중가닥 DNA에서 [A] = [T], [G] = [C]예요. G 22%이면 C 22%, A = T = 28%예요.

“아데닌 44%”(D)가 옳지 않아요. 44%는 G + C의 합이에요.
