# SSTT 공부 기록

이 폴더에는 생명과학을 혼자 공부하면서 소리 내어 정리한 내용의 전사본을 모읍니다. 문제를 풀며 떠올린 생각과 개념을 이해해 가는 과정을 남겨 두고, 추후 맞춤형 특강자료를 만들 때 참고하는 것이 목적입니다.

## 파일 구성

파일은 공부한 날짜를 앞에 붙여 `MMDD 공부.md` 형식으로 저장합니다. 같은 날짜에 기록이 여러 개면 뒤에 번호를 붙입니다.

- `0908 공부.md`
- `0910 공부.md`
- `0910 공부 2.md`
- `0922 공부.md`

각 파일은 전체 오디오 전사본을 담고 있으며, 발언 순서를 따라 타임스탬프와 내용을 기록합니다. 내용이 길면 `Part 01`, `Part 02`처럼 나눌 수 있습니다.

## 새 기록 추가하기

1. 공부한 날짜를 파일명 앞에 적습니다. 예: `1006 공부.md`
2. 같은 날짜에 파일이 이미 있으면 `1006 공부 2.md`처럼 구분 번호를 붙입니다.
3. 전사본은 말한 순서를 유지하고, 확인할 수 있는 타임스탬프를 함께 적습니다.
4. 긴 기록은 `Part 01`, `Part 02`로 나누어 정리합니다.

## 특강자료를 만들 때

이 기록은 공부 당시의 이해 과정과 질문을 담은 참고 자료입니다. 말한 내용에 추측, 망설임, 오류 또는 아직 배우지 않은 내용이 섞일 수 있으므로, 특강자료에 반영하기 전에 강의자료나 교재 등 기준 자료와 대조합니다. 당시 헷갈렸던 지점과 스스로 설명한 표현은 학습자의 관점과 필요한 보충 설명을 찾는 데 활용합니다.
