# ajou-life-science

아주대학교 생명과학 강의자료 및 아카이브 저장소입니다.

## 📁 디렉토리 구조
- `강의계획서/`: 강의계획서 PDF
- `23, 24 소스/`: 강의 자료 및 합본 PDF
- `교과서/`: 생명과학 교재 원본 및 장별 분할 PDF
  - `생명과학_기초와_응용_2판.pdf`: 교재 원본 PDF (522쪽)
  - `장별/`: 23개 장/부록별 분할 PDF 디렉토리 (`.gitignore` 관리)
- `scripts/`: 교재 PDF 분할 및 처리 자동화 스크립트
  - `split_textbook.py`: PyMuPDF 기반 무손실 장별 분할 엔진
- `tests/`: 메타데이터 및 분할 PDF 무결성 검증 테스트
  - `test_split_textbook.py`: 분할 로직 및 메타데이터 연속성 단위 테스트
  - `test_generated_files.py`: 생성된 23개 PDF 파일 전수 무결성(페이지 수, 렌더링) 검증 테스트

## 🛠 실행 및 검증 방법

### 1. 교재 분할 실행
```bash
python3 scripts/split_textbook.py --src "교과서/생명과학_기초와_응용_2판.pdf" --out "교과서/장별"
```

### 2. 전체 테스트 스위트 실행
```bash
python3 -m unittest discover tests -v
```
