## §1 단백질 4차 구조

0903에서 3차 구조·변성까지 했습니다. 그 뒤를 잇습니다.

**폴리펩티드와 단백질은 같은 말이 아닙니다.**

- 아미노산이 펩타이드 결합으로 쭉 이어진 **한 줄** = 폴리펩티드
- 이 한 줄이 그대로 하나의 단백질이 되기도 하고, **여러 줄이 모여야** 하나의 단백질이 되기도 함

```
  1 polypeptide  = 1 protein        -> stops at tertiary (3rd) structure
  2+ polypeptides = 1 protein       -> has quaternary (4th) structure

  hemoglobin = 4 polypeptides (alpha x2, beta x2)
```

> 💡 **교수님** — 김밥 한 줄이 야채김밥이면 그게 곧 하나의 메뉴죠. 그런데 야채김밥 2줄 + 참치김밥 2줄을 모아 **모둠김밥** 하나로 판다 — 그게 헤모글로빈입니다. 네 줄이 합체해야 하나의 단백질이 됩니다.

⚠️ **4차 구조는 모든 단백질에 있는 게 아닙니다.** 폴리펩티드 1개로 끝나는 단백질은 3차 구조가 마지막입니다. 4차 구조는 **폴리펩티드가 2개 이상 모일 때만** 생깁니다. 각 폴리펩티드가 각자 3차 구조를 이루고, 그것들이 모이면 4차 구조입니다.

📝 **관련 문항**: 이 절에 직접 대응하는 문항은 없지만, 단백질 구조 전체(1~4차)는 한 세트로 출제됩니다.

## §2 핵산 (DNA · RNA)

> 강의노트 1.2.5 · DNA 구조는 5장에서 다시 자세히 다룹니다. 지금은 뼈대만.

핵산도 단위체의 중합체이고, 그 단위체를 **뉴클레오타이드**라고 합니다.

### §2-1 뉴클레오타이드의 구조

뉴클레오타이드는 세 부분입니다.

```
        base           <- one of A, G, C, T(or U)
         |
        sugar          <- 5-carbon sugar (pentose)
         |
      phosphate        <- PO4, negative charge
```

| 부분 | 정체 |
|---|---|
| **인산기** | 인(P) + 산소(O). **음전하**를 띰 |
| **당** | 탄소 5개짜리 **5탄당** (탄수화물) |
| **염기** | 네 종류 중 하나 |

당의 탄소에는 번호를 매기되, 염기의 원자와 헷갈리지 않게 **프라임(')** 을 붙입니다 — 1' 탄소, 2' 탄소, ... 5' 탄소. 염기는 1' 탄소에 붙습니다.

⚠️ **왜 지금 프라임 번호까지 아느냐** — DNA 복제(5장)에서 5'→3' 방향이 결정적이기 때문입니다. 지금 익혀두라고 교수님이 강조했습니다.

### §2-2 DNA와 RNA의 차이

두 가지가 갈립니다 — **당**과 **염기 하나**.

| | DNA | RNA |
|---|---|---|
| 당 | **디옥시리보스** (2' 탄소에 H) | **리보스** (2' 탄소에 OH) |
| 염기 | A · T · G · C | A · **U** · G · C |
| 가닥 | 이중가닥 | 단일가닥 |
| 이름 | **D**eoxyribo**NA** | **R**ibo**NA** |

⚠️ **디옥시리보스 = 리보스에서 산소가 빠진 것.** "디(di, 떨어지다) + 옥시(oxy, 산소)". 원래 2' 탄소에 OH가 붙어 있는데(리보스), DNA는 거기서 산소가 빠져 그냥 H입니다(디옥시리보스).

**염기는 링 개수로 두 부류로 나뉩니다.**

| 부류 | 염기 | 링 |
|---|---|---|
| **퓨린** | 아데닌(A), 구아닌(G) | 링 2개 (이름은 짧고 구조는 큼) |
| **피리미딘** | 시토신(C), 티민(T), 유라실(U) | 링 1개 (이름은 길고 구조는 작음) |

> 💡 **교수님** — **아기는 순수(퓨어)하다.** 아데닌·구아닌 = **AG = 퓨린**. 이름 짧은 애들이 링은 두 개로 큽니다.

### §2-3 이중나선·상보결합·샤가프 법칙

뉴클레오타이드가 이어질 때, **한 뉴클레오타이드의 당과 아래 뉴클레오타이드의 인산기가 공유결합**합니다. 그래서 당-인산이 번갈아 이어진 **골격(backbone)** 이 생기고, 염기는 옆으로 삐져나옵니다.

```
   5' end                        3' end
    P                             base ... base
    |                              |
   sugar - base ... base       - sugar
    |                              |
    P            antiparallel      P
    |            (5'->3' one way,  |
   sugar - base ... base           sugar
                 opposite strand
                 3'->5')
```

DNA는 두 가닥이 마주 보는데, 한 가닥이 5'→3'로 내려가면 반대편은 거꾸로 올라옵니다 = **역평행**. 그리고 사다리가 아니라 **꼬여서 이중나선**을 이룹니다.

삐져나온 염기는 놀지 않고, 반대편 가닥의 염기와 **수소결합**을 합니다. 그런데 짝이 고정되어 있습니다.

```
   A === T     2 hydrogen bonds
   G ==== C    3 hydrogen bonds
```

⚠️ **짝이 정해져 있습니다 — A는 T하고만, G는 C하고만.** A 옆에는 무조건 T, G 옆에는 무조건 C. 이것을 **상보적(complementary) 수소결합**이라 합니다. 그래서 **한쪽 가닥 서열이 정해지면 반대편은 저절로 결정**됩니다 (한쪽이 CAGT면 반대편은 GTCA).

⚠️ **G-C가 3개, A-T가 2개** — 개수를 바꿔 쓰기 쉽습니다. 링 2개짜리 조합(G-C 중 G가 퓨린)이 더 단단히(3개) 붙는다고 엮으면 덜 헷갈립니다.

**샤가프 법칙** — A 옆엔 늘 T, G 옆엔 늘 C가 있으므로, 어떤 생물의 DNA든 **A 개수 = T 개수, G 개수 = C 개수**입니다.

📝 **관련 문항**: 14, 33 (핵산·뉴클레오타이드), 31 (상보결합 = 수소결합 · 0903 §1-4)

## §3 세포의 크기와 관찰

이제 분자에서 세포 구조물로 넘어갑니다. 세포는 생명체의 구조·기능의 기본 단위이자, **스스로 복제할 수 있는 가장 작은 단위**입니다.

### §3-1 세포는 왜 작은가

코끼리가 쥐보다 큰 것은 세포가 큰 게 아니라 **세포 수가 많은** 것입니다. 세포는 왜 그냥 커지지 않고 수만 늘릴까요?

핵심은 **표면적 대 부피 비**입니다.

```
   cube side x2:
     surface area  x4   (grows slower)
     volume        x8   (grows faster)
   -> surface/volume ratio DROPS
```

세포가 커지면 표면적도 커지지만, 부피가 훨씬 더 빨리 커져서 **단위 부피당 표면적은 오히려 줄어듭니다.** 세포는 표면(막)으로 끊임없이 물질을 수송해야 합니다 — 포도당·산소는 들어오고, 이산화탄소·노폐물은 나가야 합니다. 표면적 비가 줄면 수송이 부피를 감당하지 못해 살기 어려워집니다.

> 💡 **교수님** — 교실이 커지면 학생은 많이 들어가지만 학생 1명당 창문 면적은 줄죠. 환기가 안 됩니다. / 터미네이터2의 액체금속 로봇을 총으로 쏴 산산조각 내면, 부피는 같은데 표면적이 넓어져 열을 빨리 받아 금방 녹습니다.

### §3-2 현미경과 해상도

세포는 작아서 현미경이 필요합니다.

**해상도** = 두 점을 두 점으로 구분할 수 있는 **최소 거리**. 이 거리가 **짧을수록 좋습니다**(숫자가 작을수록 좋음).

⚠️ **해상도는 빛의 파장에 비례합니다 — 파장이 짧을수록 해상도가 좋아집니다.**

```
   shorter wavelength -> smaller (better) resolution number

   blue light  (short) -> better than red light (long)
   visible light limit  = violet (can't go shorter)
   electron beam        -> far shorter wavelength -> sees organelles, even macromolecules
```

가시광선은 보라색보다 파장을 더 짧게 할 수 없어 **광학현미경은 한계**가 있습니다. 이를 넘으려고 **전자현미경**(전자빔)을 씁니다 — 파장이 획기적으로 짧아 세포소기관, 심지어 고분자까지 봅니다.

📝 **관련 문항**: 이 절에 직접 대응하는 문항은 없습니다.

## §4 원핵세포와 진핵세포

지구의 모든 생물은 둘로 나뉩니다. 초기 생명은 원핵생물이었고, 그로부터 약 10억 년 뒤에 진핵생물이 나타났습니다.

| | 원핵세포 (prokaryote) | 진핵세포 (eukaryote) |
|---|---|---|
| 핵 | 없음 (핵양체) | 있음 (핵막으로 분리) |
| 막성 소기관 | **없음** | 있음 (미토콘드리아·골지 등) |
| 비유 | 텐트 / 컨테이너 | 30평 아파트 |

> 💡 **교수님** — 원핵세포는 텐트입니다. 거실·침실 구분 없이 DNA와 살림살이가 한곳에 엉켜 있죠. 진핵세포는 방을 **막으로 나눈** 아파트 — 유전자는 안방(핵), 에너지는 주방(미토콘드리아)에 따로 둡니다. **구획화**가 복잡한 생명으로의 진화를 가능하게 했습니다.

**원핵세포의 구조** — 단순하지만 필수 요소는 있습니다.

| 구조 | 역할 |
|---|---|
| **핵양체** | DNA가 뭉쳐 있는 부분 (막으로 싸이지 않음, "핵인 것 같은" 물질) |
| **리보솜** | 단백질 합성 공장 (점점이 박혀 보임) |
| **세포막(원형질막)** | 인지질 이중층 경계 |
| **세포벽** | 막 바깥의 단단한 벽 |
| **협막(캡슐)** | 세포벽 밖 다당류 층. 있으면 한 번 더 보호 (없는 균도 있음) |
| 섬모 / 편모 | 섬모 = 털, 편모 = 꼬리(있으면 헤엄) |

⚠️ **원핵세포도 DNA와 리보솜은 반드시 있습니다.** 유전물질 없이, 단백질 합성 없이 살 수는 없습니다. 없는 것은 **핵막과 막성 소기관**입니다.

📝 **관련 문항**: 8 (원핵·진핵 공통이 아닌 것 = 소포체), 17 (공통 = DNA), 30 (원핵이 가진 것 = 세포벽), 35 (진핵의 구별점 = 핵)

## §5 진핵세포의 소기관

진핵세포는 훨씬 복잡합니다. 핵 → 내막계 → 미토콘드리아 순으로 봅니다.

### §5-1 핵

DNA는 **핵막으로 둘러싸인 핵** 안에 있습니다.

⚠️ **이중층과 이중막은 다릅니다** — 교수님이 "다른 거냐?"라고 되물으며 강조한 지점입니다.

```
   bilayer         = phospholipid in 2 leaflets  = ordinary plasma membrane
   double membrane = TWO whole bilayers          = nuclear envelope, mitochondria

   membrane  =  ====   (one bilayer)
   nucleus   =  ====
                ====   (a second bilayer on top -> double membrane)
```
- **이중층(bilayer)** = 인지질 두 겹 하나 = 보통의 세포막
- **이중막(double membrane)** = 이중층 자체가 두 겹 = 핵막·미토콘드리아

세포막은 이중"층"(인지질 두 겹) 하나입니다. 핵막은 그 이중층 자체가 **두 겹** = 이중"막"입니다.

**핵공** — DNA의 정보는 단백질 설계도인데, 단백질을 만드는 리보솜은 핵 **바깥**에 있습니다. DNA는 소중해서 핵 밖으로 못 나가므로, DNA를 복사한 **RNA**가 대신 나갑니다. 그런데 RNA는 전하를 띠고 극성이고 커서 소수성 지질막을 통과하지 못합니다. 그래서 막에 뚫어놓은 구멍이 **핵공**입니다.

⚠️ **핵공으로 드나드는 것은 RNA이지 염색체가 아닙니다.** 11번 문항의 함정입니다.

**염색질 vs 염색체** — 같은 DNA인데 상태가 다릅니다.

| 상태 | 언제 | 모습 |
|---|---|---|
| **염색질** | 평상시 | 풀려 있음 (정보를 써야 하므로) |
| **염색체** | 세포분열 때 | 히스톤 단백질에 감겨 **응축** (현미경으로 보임) |

> 💡 **교수님** — 세포분열은 **이사 가는 날**입니다. 이사 가는 날엔 TV 안 보고 짐만 싸죠. 분열 중엔 DNA 정보를 쓸 일이 없으니 꼭꼭 싸맵니다(응축 = 염색체). 평상시엔 다 풀어놓고 씁니다(염색질). "염색해서 보인다"고 염색체입니다.

**인(nucleolus)** — 핵 안의 새까만 동그라미. 특별한 구조물이 아니라 **rRNA가 잔뜩 뭉쳐** 까맣게 보이는 것입니다. rRNA(리보솜을 구성하는 RNA)와 단백질이 여기서 합쳐져 **리보솜이 조립**되고, 조립된 리보솜이 핵 밖으로 나가 단백질을 만듭니다.

📝 **관련 문항**: 11 (핵공 · 세포소기관 설명)

### §5-2 내막계

핵막 바깥 세포질에는 소포체·골지체·리소좀이 있습니다. **이 막들은 서로 갈아탑니다.**

**소포체** — 핵막이 바깥으로 미로처럼 쭉 연장된 것. 표면의 리보솜 유무로 갈립니다.

| | 조면소포체 | 활면소포체 |
|---|---|---|
| 리보솜 | **있음** (거칠게 보임) | 없음 (매끈) |
| 기능 | 단백질을 받아 **3차 구조·변형** | **지질 합성 · 해독** |

**골지체** — 소포체와 달리 **폐쇄된 납작한 주머니**가 나란히 쌓인 것. 소포체에서 온 단백질을 다시 변형하고 **분류**합니다.

> 💡 **교수님** — 골지체는 **우체국**입니다. 파주로 갈 우편물, 고양으로 갈 우편물을 분류하듯 단백질의 최종 목적지를 정해 보냅니다.

**단백질 분비 경로** — 막이 조각나 소낭(작은 주머니)으로 단백질을 나릅니다.

```
   ribosome -> rough ER -> [vesicle] -> Golgi -> [vesicle] -> plasma membrane
   (make)      (fold,       (carry)     (modify,   (carry)     -> secreted / stay in
               modify)                   sort)                     membrane / stay in Golgi
```

⚠️ **리보솜은 두 종류입니다 — 교수님이 "여기만 조금 어렵다"고 한 곳.**

- **부착 리보솜** (조면소포체 막에 붙음): 위 경로에 실리는 단백질 = **내막계에 있거나, 세포막에 박히거나, 분비되는** 단백질을 만듦
- **자유 리보솜** (세포질에 떠다님): 그 경로가 **아닌** 곳의 단백질 = 핵·미토콘드리아로 가거나 세포질에 그냥 있는 단백질을 만듦

**리소좀** — 골지체 막이 떨어져 나와 생깁니다. `lysis`(분해)에서 온 이름으로, 단백질·지질을 다 잘라버리는 **재활용 장소**입니다.

⚠️ **리보솜(합성 공장)과 리소좀(분해장)은 이름만 비슷하고 정반대입니다.** 7번 문항이 "리보솜이 식균작용을 한다"고 유혹합니다 — 식균작용은 **리소좀**입니다.

| 리소좀의 두 작용 | 대상 |
|---|---|
| **자가소화작용** | 자기 것 (망가진 미토콘드리아 등 재활용) |
| **식균작용** | 밖의 것 (백혈구가 세균을 삼켜 리소좀과 융합해 녹임) |

이 **핵막·소포체·골지체·소낭·세포막**은 서로 융합하고 떨어지며 계속 갈아타므로, 하나로 묶어 **내막계**라고 합니다.

📝 **관련 문항**: 7 (리보솜 vs 리소좀), 11 (활면소포체·골지)

### §5-3 미토콘드리아와 세포내공생설

미토콘드리아는 **세포의 발전소** — 에너지를 **ATP** 형태로 만듭니다.

> 💡 **교수님** — ATP는 **에너지 화폐**입니다. 일해서 돈을 벌어 필요한 걸 사듯, 생물은 ATP에 에너지를 저장해뒀다 필요한 곳에 씁니다. (2장에서 자세히)

미토콘드리아도 **이중막**입니다 — 외막은 매끈하고 내막은 팍 접혀 있습니다.

```
   outer membrane : smooth
   inner membrane : folded -> "cristae"
   inside space   : matrix  <- ATP is made here
```
- 접힌 내막 = **크리스테(cristae)** · 내막 안쪽 공간 = **기질(matrix)**, 여기서 ATP가 만들어짐

⚠️ **내막이 접힌 이유는 표면적을 넓히기 위해서입니다.** ATP 생산 단백질이 내막에 박혀 있는데, 표면적이 넓을수록 더 많이 박혀 ATP를 빨리 만듭니다.

> 💡 **교수님** — 좁은 교실에서 전시회를 하면 벽 네 면뿐이지만, **파티션을 지그재그로** 세우면 붙일 면적이 늘죠. 크리스테가 그 파티션입니다.

**세포내공생설** — 미토콘드리아 안에는 **자체 DNA와 리보솜**이 있습니다. 왜?

린 마굴리스가 낸 답: **원래 하나의 세균이었는데, 커다란 세포에 잡아먹혀 공생하게 되었다.**

| 근거 | 내용 |
|---|---|
| DNA 모양 | 진핵생물 DNA는 직선인데, 미토콘드리아 DNA는 **세균처럼 고리 모양** |
| 리보솜 크기 | 미토콘드리아 리보솜이 **세균 리보솜과 같은 (작은) 크기** |

호기성(산소 호흡) 세균이 잡아먹혀 **미토콘드리아**가 되었고, 광합성 세균이 잡아먹혀 **엽록체**가 되었다는 설명입니다.

📝 **관련 문항**: 11 (미토콘드리아 = ATP)
