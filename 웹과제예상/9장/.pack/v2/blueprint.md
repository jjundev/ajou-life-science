# 9장 웹과제 예상 v2 설계

1105 정리노트(9장 강의노트 p1–3)와 1110 정리노트(p4–8)를 사용한다. 9장 세부 분류 중 세대교번, 체강·발생 양식·체절화 등은 수업에서 설명되지 않아 정답 근거로 쓰지 않는다. 9장 웹과제 bank·raw·intake가 없고 note-feedback은 미작성이다. 공식 정답·기출 재사용률·응시 여부는 미확인이다.

1~3장 정본 46문항(부정형 18/46, 그림 포함 8/46, 기출 기반 14/46)을 형식 참고로 사용했다. 별도 7장(부정형 4/13)·8장(0/14, 사례·자료 해석 중심) 원본 관찰도 참고했다. 9장 합본의 범위 내 완전 문항은 26개다. 원문 결함이 있던 1번은 새 보기를 쓰는 변형에만 사용한다. 사용한 기출 8·16·1·19·23은 v1의 3·25·6·27·18과 겹치지 않는다. 계산 근거가 있는 기출이 없어서 그대로 2·쌍둥이 3을 사용한다.

생성 목표는 부정형 4·계산 0·그림 판독 3·표 판독 3·ㄱㄴㄷ 1·장섞기 0이다. 독소의 분비·방출, 와편모조류 피해 원인, 공생 상대의 구별에 유형을 배정했다. ㄱㄴㄷ는 지의류 상대·영양·토양 형성의 진술을 따로 판정하기 위해 사용한다. 이 장의 근거는 구조·분류·증거 해석 중심이다. 근사 연대를 이용한 인위적인 계산은 넣지 않는다.

기본 12·심화 3은 9장 실제 분포 자료가 없어 택한 참고 목표다. p10·p15는 서로 다른 관찰이나 대조를 연결해야 풀리도록 설계했다.

## 회상·비교 연습

- p6 / 1105 s1-endosymbiosis / 이름 → 낯선 모식도 / 과정 그림에서 출발 물질을 찾고 소기관의 증거까지 연결한다.
- p7 / 1105 s0-rna / 기능 → 리보자임 / 동일 RNA의 두 역할을 두 대조로 분리하고 반응 촉진에서 자기 복제 입증까지 넘어가는 해석을 가른다.
- p8 / 1105 s2-toxins / 물질과 방출 과정 → 외독소·내독소 / '밖'과 '안'이라는 이름보다 어디에 있었고 무엇으로 이루어졌는지를 판별한다.
- p9 / 1110 s0-diversity / 배양 조건과 세포 수 변화 → 혼합영양 / 빛만 있는 조건과 외부 유기물만 있는 조건을 각각 대조군과 비교한다.
- p12 / 1110 s2-symbiosis / 바위 시료와 공생 상대 → 지의류 / 균류와 광합성 세균의 연합도 지의류가 될 수 있음을 회상한다.
- p13 / 1110 s3-animal / 거울상 도식 → 대칭 명칭 / 대칭선 개수로 세 종류를 비교한다.
