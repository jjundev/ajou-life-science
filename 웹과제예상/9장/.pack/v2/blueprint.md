# 9장 웹과제 예상 v2 설계

1105 정리노트(9장 강의노트 p1–3)와 1110 정리노트(p4–8)를 사용한다. 1112 강의의 화학 시냅스는 경계 주제다. 9장 세부 분류 중 세대교번, 체강·발생 양식·체절화 등은 수업에서 설명되지 않아 정답 근거로 쓰지 않는다. 9장 웹과제 bank·raw·intake가 없고 note-feedback은 미작성이다. 공식 정답·기출 재사용률·응시 여부는 미확인이다.

1~3장 정본 46문항(부정형 18/46, 그림 포함 8/46, 기출 기반 14/46)을 형식 참고로 사용했다. 별도 7장(부정형 4/13)·8장(0/14, 사례·자료 해석 중심) 원본 관찰도 참고했다. 9장 합본의 범위 내 완전 문항은 26개다. 원문 결함이 있던 1번은 새 보기를 쓰는 변형에만 사용한다. 사용한 기출 8·16·1·19·23은 v1의 3·25·6·27·18과 겹치지 않는다. 계산 근거가 있는 기출이 없어서 그대로 2·쌍둥이 3을 사용한다.

생성 목표는 부정형 4·계산 0·그림 판독 3·표 판독 3·ㄱㄴㄷ 1·장섞기 0이다. 독소의 분비·방출, 와편모조류 피해 원인, 공생 상대의 구별에 유형을 배정했다. ㄱㄴㄷ는 지의류 상대·영양·토양 형성의 진술을 따로 판정하기 위해 사용한다. 이 장의 근거는 구조·분류·증거 해석 중심이다. 근사 연대를 이용한 인위적인 계산은 넣지 않는다. 화학 시냅스는 12장 개념만으로 푸는 단독 경계 문항이다.

기본 12·심화 3은 9장 실제 분포 자료가 없어 택한 참고 목표다. p9·p10·p15는 서로 다른 관찰이나 대조를 연결해야 풀리도록 설계했다.

## 독립 풀이와 실제 집계

- 1차 정답 15/15. p5의 비교 기준, p9의 1112 경계 범위 표시, p14의 액체 단서를 보완했다. p10은 표 실험 조건 문구가 변경되어 함께 다시 검토했다.
- 2차 정답 4/4, 이의 0. 최종 원본 해시를 대조한 ledger는 15/15 일치, 이의 0.
- 실제 유형 부정형 4 · 계산 0 · 그림 3 · 표 3 · ㄱㄴㄷ 1 · 장섞기 0. 생성 목표와 일치한다. 이전 세트와 기출 번호 및 정규화된 발문 중복은 각각 0이다.
- 실제 난이도 기본 12·심화 3. 수준 1은 9, 수준 2는 3, 수준 3은 3 (p7, p9, p15). 기본·심화 문항 수는 참고 목표와 같아요.
