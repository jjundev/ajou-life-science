4장 유전 웹과제 예상 v1

2026-10-14 실제 4장 원본의 개념 피드백과 수정된 정리노트를 반영한 대비 세트예요. 기출 원문 재출제 규칙 이전의 legacy 생성 15문항이며 개요 2장을 포함해요. 독립 풀이 판정은 기본 14·심화 1, 유형은 부정형 4·계산 5·그림 3·표 1·ㄱㄴㄷ 0예요. 목표 기본 12·심화 3보다 심화가 2개 적어요. 짧은 교배·직접 판별에 불필요한 조건을 추가하지 않았어요. 공식 답 미확인·정본 bank 미등록 상태예요.

A. 예상 개요

실제 원본을 참고한 형식과 주제 대비

4장 실제 웹과제 원본을 참고한 대비 세트예요. 기존 v1의 번호와 정답 분포를 유지하며 개념 피드백과 수정된 정리노트를 반영했어요.

  • 실제 4장 원본을 참고해 갱신한 대비 세트예요. 공식 답 미확인·정본 bank 미등록이에요.
  • 4장 별도 원본 관찰: 15문항·부정형 4·계산 5·그림 3·표 1·ㄱㄴㄷ 0이에요. 유형은 겹칠 수 있어요.
  • 1~3장 정본 46문항의 확정 집계와 4장 관찰을 합산하지 않아요. 4장 기출 재사용 비율도 미집계예요.
  • 구성: 기출 원문 재출제 규칙 이전의 legacy 생성 15문항. 생성 유형 실제 수는 부정형 4·계산 5·그림 3·표 1·ㄱㄴㄷ 0예요.
  • 독립 풀이 판정: 기본 14·심화 1. 목표 기본 12·심화 3보다 심화가 2개 적어요. 짧은 교배·직접 판별에 불필요한 조건을 추가하지 않았어요. 실제 출제 통계가 아닌 생성·검토 결과예요.
  • 이번 수정은 ABO의 당 항원·복대립/연관 구별, 성별 조건의 분모, 부모가 바뀐 교배, 수용체 양의 관찰 수준을 반영했어요. 별점은 학습 근거의 반복을 표시하며 실제 출제 확률 수치가 아니에요.

막판 체크

  1. 분모 먼저: 아들일 때는 아들만 세요. 전체 출생 중 환자 아들이라는 질문과 나눠요. 정상 자녀 중 보인자라는 추가 조건은 심화예요.
  2. 교배마다 배우자: 분홍×붉음, 보인자×보인자처럼 부모가 바뀌면 외운 비율 대신 배우자를 다시 써요. 우성 부모에게 정상 자녀가 있으면 부모형부터 복원해요.
  3. 그림: 구조 변화는 글자의 양·순서·이동 상대, 비분리는 마지막 배우자 수, 연관은 부모 배열과 새 조합을 읽어요. 새 조합 두 유형을 합해 재조합 빈도를 구해요.
  4. 표: 수용체 양의 중간값은 그 측정 형질의 불완전우성이에요. 질병명이나 다른 표현형으로 기준을 바꾸지 않아요.
  5. 개념 경계: 복대립은 한 좌위의 집단 내 종류 수예요. ABO 당 항원, 완두 실험의 세대 길이, 정상 교차의 상동 상대와 전좌의 비상동 상대를 구별해요.
  6. 다른 실제 관찰: 정상 부모의 환자 아들 가계도에서는 보인자와 딸의 전달 경로를, 정량 보정에서는 X 불활성화와 바소체를 복습해요.

원문 기출이 없는 기존 legacy 세트이므로 원문과 대조하지 않은 ‘재출제 유력 기출 10개’나 공식 정답 목록을 제공하지 않아요. 실제 원본 15문항의 공식 답·정본 등록은 미확정이에요.
