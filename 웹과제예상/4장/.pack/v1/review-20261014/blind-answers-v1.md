# v1 블라인드 풀이 리뷰

근거는 허용된 0922·0929·1001 정리노트만 사용했다. 원본 정답·풀이·피드백은 읽지 않았다. 독립수준은 최소 풀이를 기준으로 1=직접 정의/관계/도식, 2=한 원리 적용의 짧은 추론, 3=여러 조건/원리 연결 또는 추가 조건부 계산이다. 노트에 동일 관계가 명시된 경우 직접 적용으로 판정했다.
