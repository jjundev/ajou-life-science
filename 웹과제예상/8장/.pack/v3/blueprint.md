# 8장 웹과제 예상 v3 설계

범위: 1029 정리노트 2·3절(종 개념·생식적 격리·이소적/동소적 종분화·배수성, 강의노트 8장 p1–2)과 1103 정리노트 전체(연대측정·지질시대·대륙이동·수렴진화·대진화 양상·멸종·진화발달생물학·계통수와 분류·rRNA 비교, 강의노트 8장 p3–6). 장마감 검토(`장마감_1103_8장.md`)에서 범위 불명·보충 학습 권장으로 분류된 9장 소재 및 생략 문항은 제외한다. 실제 8장 웹과제 bank(`questions.json`), raw, 문항별 피드백(`note-feedback.md`)은 모두 미등록·미작성이며 공식 답·응시 완료 여부도 미확인이다.

유형 목표: 1~3장 정본 46문항 확정 집계(부정형 18, 그림 포함 8, 기출 기반 14)와 8장 노트의 실제 판별 과제를 바탕으로 `부정형 4 · 계산 2 · 그림 3 · 표 2 · ㄱㄴㄷ 0 · 장섞기 1`을 목표로 정했다. 범위 안의 숫자 조건 기출(`8강 43`)은 v1에서 이미 사용했으므로 p1·p2는 기출그대로, p3·p4·p5는 기출쌍둥이(`{"기출그대로": 2, "기출쌍둥이": 3}`)로 배치했다. 장섞기 1문항(p7)은 8장 배수성 종분화를 1001 노트의 배수체·이수체 구분 및 0922 노트의 감수분열 4분염색체 짝짓기와 연결해 점검한다.

난이도 설계: 8장 실제 웹과제 분포 근거가 없어 참고 생성 정책(기본 12 · 심화 3)을 출발점으로 삼되, 조건을 억지로 늘리지 않고 작성 후 블라인드 독립 풀이의 실제 수준과 목표 차이를 공개한다.

## 재출제 유력 기출 10
- 8강 5 (초파리 짝짓기와 자손의 짝짓기 확인): ★★★ 생물학적 종 개념 검증 실험, p1 사용.
- 8강 16 (모든 생물의 가장 초기 공통조상): ★★☆ 계통수의 뿌리 의미, p2 사용.
- 8강 26 (난자와 정자를 만들지 못한다): ★★★ 노새 불임의 원인과 접합 후 장벽, p3 원문.
- 8강 29 (파나마 지협의 융기로 인한 서식지의 분리): ★★★ 이소적 종분화의 지리적 장벽, p4 원문.
- 8강 34 (영역, 계, 문, 종): ★★★ 분류계급의 큰 범위→작은 범위 순서, p5 원문.
- 8강 12 (모양이 다른 도토리를 생산하는 다른 지역의 참나무 집단): ★★☆ 아종의 정의(지역적 변이).
- 8강 18 (그 조상에서 진화된 특성을 공유한다): ★★☆ 계통분류학의 공유 파생특성 원리.
- 8강 21 (남세균류): ★★★ 세균역(원핵)과 진핵생물역 무리 구분.
- 8강 27 (공유된 특성에 근거한 분류는 진화적 관계를 나타냄): ★★☆ 린네 분류 체계의 현대적 의의.

- p6 / s2-prezygotic & s2-postzygotic / 동물 구애·단순 실험 대신 식물 꽃가루 이동·수분·2대 자손의 세 단계 표 / 현상→격리 명칭과 단계 / v2 p7과 생물(식물 수분 과정)·비교 단계(접합 전 2개+접합 후 1개)·발문 질문을 바꿔 꽃가루 관련 격리 혼동을 점검해요.
- p7 / s3-polyploidy / v1 p15(2n=16, 옳은 것)에서 염색체 수(2n=12)·발문 방향(옳지 않은 것) 변경 + 1001 이수체(2n+1) 비교 결합 / 숫자·단위·장섞기 / 세트 전체 증가(배수체)와 일부 염색체 증감(이수체) 및 배우자 염색체 수를 함께 점검해요.
- p8 / s0-dating / v1 p6(두 시료 표)·v2 p11(3.125% 단일 시료)에서 현재 25% 시료가 5,730년 더 지날 때의 비율(12.5%)과 총 경과 시간(17,190년)으로 조건·질문 변경 / 비율·시간 계산 / 반감기마다 처음 양의 절반을 빼는 오산을 진단해요.
- p9 / s0-geologic / v1 p8(텍스트 부정형)에서 4이언·3대 지질시대 연대표 도식과 옳은 것 판독으로 자료 형식·발문 방향 변경 / 도식 구간→사건 연결 / 시생·원생·현생이언의 핵심 사건 순서를 시각적으로 점검해요.

- p11 / s2-trends / v1 p11(텍스트 부정형)에서 분지형 말 화석 계통도 SVG 판독과 옳은 것 선택으로 그림·발문 방향 변경 / 도식→진화 경향 해석 / 살아남은 한 계열과 멸종한 여러 가지를 함께 읽는 기준을 점검해요.
