구분유사분열감수분열

딸세포 핵부모 핵과 유전적으로 같음부모 핵과 유전적으로 달라요

함정 ✗ 감수분열은 생물 전체의 체세포 어디서나 일어난다. ✓ 감수분열은 정자·난자를 만들 때만 일어난다. 체세포는 유사분열로 늘어난다. ✗ 체세포 분열은 분열 후 염색체 수가 절반으로 줄어든다. ✓ 체세포 분열은 염색체 수가 그대로다. 절반으로 줄어드는 것은 감수분열이다. ✗ 유사분열은 배우자를 생산하는 세포에서 일어난다. ✓ 배우자를 만드는 분열은 감수분열이다. 유사분열은 체세포 분열과 같은 분열이다.

⑤ 염색질·염색체

같은 DNA, 풀림 vs 응축 단서: 히스톤·양파 뿌리 끝

구분염색질염색체
언제평소(분열 안 할 때)세포 분열 중
DNA 상태DNA+히스톤, 풀림DNA+히스톤, 응축
현미경막대로 안 보임막대로 보임
  • 간기 염색체는 없다가 아니라 안 보인다(풀린 염색질로 존재).
  • 염색체를 보려면 분열 중인 세포를 본다: 양파 뿌리 끝.
함정 ✗ 염색체는 세포가 분열하지 않을 때도 막대 모양으로 보인다. ✓ 평소엔 풀린 염색질이라 안 보이고, 분열 중 응축됐을 때만 막대로 보인다. ✗ 염색질과 염색체는 히스톤 유무가 다른 서로 다른 물질이다. ✓ 둘 다 DNA+히스톤이고, 차이는 풀림과 응축이다. ✗ 염색체 응축은 분열 중기에 일어난다. ✓ 염색체 응축은 분열 전기에 일어난다(강의노트).
⑥ 자매염색분체·상동염색체

자매 = 복사본, 상동 = 엄마·아빠 짝 교수님 강조 단서: A와 a, 동원체로 붙음

구분자매염색분체상동염색체
생김한 염색체의 DNA 복제(S기)엄마 하나, 아빠 하나
붙음동원체로 붙어 있음동원체로 붙어 있지 않은 따로 된 두 염색체(감수 전기 I에는 짝을 지어 4분염색체가 됨)
같은 자리완전히 같음(C와 C)일반적으로 같은 유전자(X·Y 쌍 예외), 대립유전자는 같거나 다름(C와 c)
  • 동원체: 자매염색분체가 붙어 있는 잘록한 부위(X). 방추사(미세소관)가 붙는 곳.
  • A와 a는 같은 자리의 같은 유전자의 다른 버전, 곧 대립유전자. A·B·C는 서로 다른 유전자.
  • (별도 경우, 웹과제 Q5 그림) 동원체로 붙은 X자 염색체의 두 가닥은 자매염색분체라 유전 정보가 같다. 그 그림의 A·B는 가닥 이름이지 유전자가 아니다.
함정 ✗ 길이·모양이 같은 두 막대는 복제되어 생긴 자매염색분체이다. ✓ 같은 자리에 A와 a처럼 다르면 복사본이 아니라 상동염색체이다. ✗ 동원체는 상동염색체끼리 붙어 있는 부위이다(또는 핵이 있는 곳·염색체의 끝). ✓ 동원체는 자매염색분체가 서로 붙어 있는 부위이다. ✗ 상동염색체는 같은 유전자를 가지므로 대립유전자도 늘 같다. ✓ 같은 위치에 (일반적으로) 같은 유전자일 뿐, 대립유전자는 같을 수도 다를 수도 있다.

⑦ 2n·n

2배체·반수체와 무엇이 나뉘나 교수님 강조

2배체 2n
상동염색체를 쌍으로 가짐. 정자·난자 뺀 체세포
반수체 n
쌍마다 하나만 가짐. 정자·난자. "1배체"라 부르지 않음
사람
2n = 46개 = 23쌍. 정자·난자는 n = 23개
구분체세포 분열감수 1분열감수 2분열
나뉘는 것자매염색분체상동염색체자매염색분체
상동염색체안 나뉘고 따라감쌍이 갈라짐이미 쌍마다 하나
염색체 수2n → 2n2n → n1분열 뒤 이미 n
일어나는 때몸의 세포를 늘릴 때유성생식에서 정자·난자 만들 때만
함정 ✗ 사람 체세포는 2n = 46이므로 상동염색체가 46쌍이다. ✓ 염색체는 모두 46개이고, 2배체라 23쌍이다. ✗ 사람의 정자와 난자는 유사분열로 만들어지고 각 염색체를 두 종류씩 갖는다. ✓ 정자·난자는 감수분열로 만들어지고 반수체라 각 염색체를 한 종류만 갖는다. ✗ 체세포 분열 후기에는 상동염색체가 분리되어 염색체 수가 절반으로 줄어든다. ✓ 체세포 분열에서는 자매염색분체가 분리되고 2n이 그대로 2n이다. 상동염색체는 감수 1분열에서 분리된다.
⑧ 세포주기·간기

시기 → 일어나는 일 단서: 성장·DNA 복제·분열 준비

G1→S기→G2→핵분열→세포질분열 (앞의 셋이 간기, 뒤의 둘이 M기)

시기일어나는 일보기 단서
G1기성장, 단백질 합성, 세포소기관 늘어남세포 크기 증가, 생장
S기DNA 복제, 중심체 복제DNA 상대량 2배, DNA 중합효소 최고
G2기분열 준비(분열에 필요한 단백질 합성)분열 준비
M기핵분열 → 세포질분열. 염색체 응축, 방추사가 동원체에 붙음방추사 형성, 염색체 응축, 세포질분열
G0기G1기에서 멈춰 분열을 안 하는 상태신경세포, 분열 안 함
  • G는 Gap(틈)이다. 성장(Growth)이 아니다.
  • 간기에는 DNA가 풀린 염색질이라 막대 염색체가 안 보인다("없다"가 아니다).
함정 ✗ G1기에는 DNA 복제가 일어난다. / S기에 세포가 성장한다. ✓ 성장은 G1기, DNA 복제는 S기, 분열 준비는 G2기다. 방추사 형성·염색체 응축·세포질분열은 G1기가 아니라 M기 일이다. ✗ 간기는 유사분열기이다. ✓ 간기는 G1·S·G2를 합친 시기로 분열기가 아니다. 전기·중기·후기·말기는 M기 안의 단계 이름이다(M기는 세포질 분열로 끝남). ✗ M기에는 분열을 준비하며 방추사 구성 단백질 등이 합성된다. ✓ 분열 준비는 G2기다. M기는 분열 자체다. (ㄱ G1 생장·단백질 합성, ㄴ S기 DNA 상대량 2배는 옳다)
⑨ 확인점

함정 ✗ 확인점은 DNA 복제의 잘못을 직접 고치는 장치다. ✓ 확인점은 다음 단계로 못 가게 멈추는 지점이고, 고치는 일은 종양 억제 유전자가 한다. ✗ DNA 복제 확인은 S기가 진행되는 동안 일어난다. ✓ DNA 복제 확인은 S기가 끝난 뒤, 다음 단계로 넘어가기 전에 한다. ✗ 세포 크기가 충분해 3개의 딸세포로 나뉠 수 있는지, 세포벽이 만들어졌는지를 확인점에서 검사한다. ✓ 확인점은 DNA 복제·방추사 부착·분열 시기를 본다. 딸세포는 2개이고 동물세포에는 세포벽이 없다.
