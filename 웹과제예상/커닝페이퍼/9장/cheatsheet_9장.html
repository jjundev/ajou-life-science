③ 유기물 합성·원시세포

밀러-유레이 실험과 원시세포 단서: 메탄·암모니아·방전

가설
오파린-할데인: 초기 지구는 산소 적고 수소·메탄·암모니아·수증기 많은 환원 조건(가정)
입력
밀러-유레이(Miller–Urey): 수증기+수소·메탄·암모니아 순환, 전기 방전=번개 에너지
측정
약 일주일 순환·냉각 뒤 용액 성분 분석(색 변화 아님) → 아미노산 검출
결론
가정한 조건에서 간단한 유기물의 비생물적 합성 가능성. 살아 있는 세포 생성 아님
다른 후보
환원적 심해 열수구, 운석의 아미노산(우주 유입) — 가설. 우주에서 왔어도 최초 합성 질문은 남음
규산염
유리 용기의 규산염이 반응에 영향 가능(수업 영상 해석) — 실험 전체 무효는 아님

간단한 유기물→거대분자 조립→막으로 구획→복제·분열 가능한 세포

  • 아미노산→폴리펩티드, 뉴클레오타이드→DNA·RNA. 진흙 속 금속 이온이 조건에 따라 아미노산 연결 촉매.
  • 인지질 머리는 물 쪽, 꼬리는 서로 마주 보며 인지질 이중층 자가 조립 → 닫힌 소낭이 안팎을 나눔.
  • 원시세포(protocell) = 경계와 내부 물질을 가진 초기 세포의 모형. 복제·분열 체계가 더 필요, 실제 경로는 미확정.
  • 교수님: “생명까지는 아니고, 유기물까지 나왔다.”
함정 ✗ 밀러 실험에서 아미노산이 검출되었으므로 살아 있는 최초의 세포를 만든 것이 확실하다. ✓ 아미노산 검출은 간단한 유기물의 비생물적 합성 가능성만 보여 준다(세포 구조·자기 복제 미확인).
함정 ✗ 밀러-유레이 실험에 넣은 기체는 모두 무기물이다. ✓ 넣은 기체 중 메탄은 유기물이다.
함정 ✗ 인지질 이중층이 닫힌 소낭은 유전정보 복제와 세대 유지까지 가능한 세포다. ✓ 닫힌 소낭은 구획화 모형이며 복제·분열 체계가 더 필요하다.

④ RNA 우선 가설

RNA = 정보 + 촉매 단서: 리보자임·정보와 촉매를 함께

리보자임(ribozyme)
촉매 기능을 가진 RNA 자체. 모든 촉매가 단백질은 아님, 모든 RNA가 촉매도 아님
RNA 우선 가설
초기 RNA가 염기서열에 정보 저장 + 일부 RNA가 촉매로 RNA 합성·자기 복제를 도왔을 가능성
지지 근거
한 분자 종류가 정보·촉매를 함께 맡음 → 단백질 효소가 먼저 있어야 한다는 부담(시작의 문제)을 줄임
RNA 재료
뉴클레오티드 중합체. 아미노산은 단백질의 재료
DNA로 넘어감
RNA는 OH기로 반응성이 커 불안정 → 상대적으로 안정한 DNA가 장기 저장을 맡게 되었을 가능성(수업 설명, 경로 미확정. 전혀 안 변한다는 뜻 아님)
  • 가설 범위: 초기 생명의 정보·촉매 체계. 현재 세포는 유전정보를 주로 DNA에 저장.
  • 리보자임 존재는 가설 지지일 뿐, 원시 RNA의 완전한 자기 복제 직접 증거·현대 세포 재현이 아님. 단백질 우선 가설도 소개됨, 경로 미확정.
함정 ✗ 리보자임의 발견으로 모든 RNA가 재료 없이 완전한 자기 복제를 했음이 입증되었다. ✓ 일부 RNA가 초기 복제를 도왔을 가능성을 지지할 뿐, 최초 복제의 조건·경로는 미확정이다. ✗ 리보자임은 RNA를 감싼 단백질 껍질이므로 단백질 우선 가설을 지지한다. ✓ 리보자임은 촉매 기능을 하는 RNA 자체이며 RNA 우선 가설을 지지한다. ✗ RNA는 DNA보다 견고하고 안정해서 초기 정보 분자가 되었다. ✓ RNA는 OH기로 반응성이 커 불안정하고, DNA가 상대적으로 안정해 장기 저장을 맡는다.
⑤ 남세균과 산소

구분산소발생형비산소발생형
예남세균(cyanobacteria)황을 쓰는 광합성 세균(녹색세균)
에너지원빛빛
전자공여체물예: 황화수소

물 분해(명반응)→전자 공급 + O₂ 방출 (캘빈 회로는 O₂를 내지 않음)

광독립영양
남세균: 에너지원 빛, 탄소원 CO₂ (빛 = 에너지, 물 = 전자)

시기
물 쓰는 광합성 출현 약 30억 년 전(근사). 출현·화석·대기 산소 축적은 같은 날짜 아님 → 이후 산소 호흡 발달
초기 지구
산소 부족 → 발효·무산소 호흡과 연결
함정 ✗ 진정세균 중 녹색세균은 산소를 발생시키는 광합성을 한다. ✓ 녹색세균은 황을 이용하는 산소 비발생형, 산소발생형은 남세균이다.
함정 ✗ 빛을 쓰는 광합성 원핵생물은 전자공여체와 관계없이 모두 산소를 방출한다. ✓ 전자공여체가 물일 때만 물 분해로 산소를 방출한다(황화수소 이용 쪽은 산소 없음).
함정 ✗ 8장: 최초의 진핵생물 출현 → 광합성 생물에 의한 산소 발생 → 영장류 탄생. ✓ 8장: 광합성에 의한 산소 발생이 진핵생물 출현보다 앞선다.

⑥ 세포내공생·다세포

막 함입 vs 세포내공생, 군체 vs 분화 단서: 환형 DNA·세균형 리보솜

구분A 막의 함입B 세포내공생
일어난 일세포막이 안으로 접힘삼킨 세균을 소화 않고 함께 생활
설명하는 구조핵막·소포체·골지체미토콘드리아·엽록체
조상숙주의 기존 세포막산소 호흡 세균→미토콘드리아, 이후 남세균→엽록체
  • 공생 증거: 두 소기관의 자체 환형 DNA(핵은 선형), 크기·rRNA 서열이 세균형인 리보솜, 현재 관찰되는 공생 사례(가능성만 뒷받침, 과거 사건을 직접 본 것 아님).
  • 자체 리보솜 = 세포 안에서 일부 단백질 합성 가능. 세포 밖 완전 독립 생활은 아님.
  • 마굴리스 주장은 처음 거절, 증거 축적으로 수용.
  • 처음 진핵생물은 단세포. 군체(같은 종의 세포가 모여 삶, 수업 모형은 역할 분담 없음) → 분화(구조·기능 특수화: 운동·수축·자극 전달) = 다세포성 발달의 가능한 경로. 실제 군체의 분화 정도는 다양.
  • 분화 판정은 세포 수·겉모양이 아니라 실제 역할이 나뉘는지로.
함정 ✗ 막 함입으로 생긴 내부막도 모두 독립 세균이었으므로 자체 환형 DNA를 가진다. ✓ 막 함입으로 생긴 내부막은 자체 환형 DNA를 가져야 하는 것은 아니다(세균 기원은 미토콘드리아·엽록체). ✗ 세포내공생으로 모든 진핵세포가 엽록체를 가진다. ✓ 엽록체는 남세균과의 추가 공생이 일어난 계통에만 있다. ✗ 다세포체에서 기능이 다른 세포는 반드시 서로 다른 종이다. ✓ 같은 종의 세포가 서로 다른 기능으로 분화할 수 있다.
⑦ 원핵세포 구조·영양 방식

원핵세포 장비와 영양 두 축 단서: 핵양체·펩티도글리칸·에너지원/탄소원

⑧ 세균 무리·독소·항생제

내생포자
일부 세균이 불리한 환경에서 유전물질을 보호하는 휴면 형태. 건조·열에 높은 저항성, 조건이 좋아지면 다시 성장·분열. 효과는 개체 수 증가가 아닌 원래 세균의 생존. 예: 탄저균
클라미디아
숙주세포 안에서 증식하는 세포 내 기생 세균(바이러스 아님)
광합성 세균
녹색세균: 황 이용, 산소 안 냄 / 남세균: 물 이용, 산소 방출
그람양성
탄저균·스타필로코커스·스트렙토코커스·락토바실루스(유산균). 나선균: 매독
구분외독소내독소

예보툴리눔 독소(근육 마비)‘내’ = 외막 성분(저장 후 분비 아님)

  • 항생제 = 세균을 죽이거나 생장을 억제하는 물질. 내성은 세균 집단의 성질(사람이 약에 익숙해지는 것 아님).
  • 세균을 끓여 죽여도 이미 만들어진 독소는 남을 수 있다.
  • 슈퍼박테리아 = 여러 항생제에 내성인 세균(항상 전혀 안 듣는다는 뜻 아님).
  • 교수님 강조 질병으로 알려진 세균은 세균 전체의 일부.
함정 ✗ 효과가 없으면 투약량을 계속 늘리고, 나아진 느낌이 들면 남은 약을 멈춘다. ✓ 문제를 일으킨 세균의 종류를 확인 후 그에 맞게 처방하는 것이 최선이다. ✗ 세균이 항생제에 맞춰 의도적으로 내성 돌연변이를 만든다. ✓ 이미 있는 유전적 차이에 따른 선택으로 내성 비율이 늘어난다. ✗ 내생포자는 모든 멸균 조건에서도 살아남는다. ✓ 내생포자는 조건에 따라 높은 저항성을 보인다.
⑨ 고세균

고세균: 핵 없음, 그러나 세균과 다른 영역 단서: rRNA·메탄생성균

기준세균고세균진핵생물
핵막 핵없음(원핵)없음(원핵)있음
막·벽·기작전형적 벽 성분: 펩티도글리칸세균과 다른 막 지질·벽. 단백질 합성 등 일부 기작은 진핵과 유사일부 기작이 고세균과 유사
수업 예대장균·남세균·유산균메탄생성균원생생물·식물·균류(효모)·동물
  • 워즈(Woese): rRNA 염기서열 비교로 고세균을 세균과 구별 → 3영역(세균·고세균·진핵). 핵막은 세포 구조 기준, rRNA는 영역 근거.
  • 고세균은 전통 4계(원생생물·식물·균류·동물) 중 하나가 아니라 별도 영역. 4계는 모두 진핵생물.
  • 극호염(매우 짠 곳)·극호열(매우 뜨거운 곳): 높은 염분 서식 생물 → 고세균영역이 가장 유력(기출). 단 염분만으로 분류 확정 불가.
  • 아스가르드 고세균: 진핵생물 기원 연구에 중요(핵이 있다는 뜻 아님). 일부 호열성 고세균의 내열성 DNA 중합효소 → PCR.

메탄생성균 교수님 강조 무산소 늪·동물의 장: H₂가 전자 줌→CO₂가 받음→메탄(온실가스, 소 장내 메탄)

함정 ✗ 메탄생성균과 남세균은 둘 다 세균영역에 속한다. ✓ 메탄생성균은 고세균영역, 남세균은 세균영역이다. 둘 다 원핵생물. ✗ 고세균은 일부 기작이 진핵생물과 유사하므로 핵막으로 둘러싸인 핵을 가진다. ✓ 고세균은 핵막으로 둘러싸인 핵이 없는 원핵생물이다(5개 중 다른 하나: 4계 vs 고세균, 원핵 4개 vs 효모). ✗ 고세균은 모두 극한 환경에서만 살며, 서식지만으로 분류가 확정된다. ✓ 극호염·극호열은 일부 고세균이며, 분류에는 rRNA 등 추가 근거가 필요하다.

⑩ 바이러스

캡시드·외피·숙주 의존 단서: 캡시드·파지·뉴라미니다아제

바이러스
살아 있는 세포에 감염해 숙주세포의 장치로 증식하는 비세포성 입자
없는 것
자체 에너지 대사시스템·리보솜·펩티도글리칸 세포벽. 단, 일부는 복제 효소를 암호화·보유(효소 0개 아님)
유전체
DNA/RNA × 단일/이중가닥 = 네 유형, 한 바이러스는 그중 한 유형
‘외피’라는 말
coat = 단백질 캡시드, envelope = 일부에만 있는 지질막. 재료로 구별
숙주
동물·식물·세균 등 종류별로 다름(모두 사람 병원체 아님). 파지(박테리오파지) = 세균 감염 바이러스. 수업 예(복합형)는 머리에 DNA·꼬리로 세균 접촉

침입: 맞는 수용체(코로나19 ACE2, HIV CD4·CCR5)→복제: 중합효소, 뉴클레오타이드 닮은 물질이 핵산 합성 방해→방출: 인플루엔자 뉴라미니다아제(자나미비르가 억제)

  • 항생제 = 세균 표적. 항바이러스제 = 증식의 특정 단계 표적.
  • 감기: 여러 바이러스 / 독감: 인플루엔자.
  • 많은 RNA 바이러스: 복제 정확도 낮고 교정 제한적 → 돌연변이. 인플루엔자: 유전변이 → 표면 단백질 변화 → 기존 항체 인식 저하 가능(전부 무효 아님).
  • 단순 구조 ≠ 세포보다 먼저. 기원 가설: 세포가 먼저, 세포 DNA·RNA 절편이 단백질에 싸여 나옴(가능성).
함정 ✗ 바이러스는 생활사에 필요한 에너지를 생산하는 대사시스템을 갖추고 있다. ✓ 독립적인 에너지 대사시스템이 없어 숙주세포에 의존한다. ✗ 바깥 지질 외피는 바이러스가 숙주와 무관하게 스스로 합성한 세포막이다. ✓ 지질 외피는 숙주세포에서 나올 때 얻는 숙주 유래 막이다. ✗ 뉴라미니다아제만 억제하면 감염된 세포의 핵산 복제가 즉시 멈춘다. ✓ 세포 안 복제는 이어질 수 있고, 다른 세포로의 확산이 줄어든다.
⑪ 원생생물

원생생물: 다양성·구조·조류 교수님 강조 단서: 수축포·식포·위족·적조

두 계(식물·동물)→다섯 계→세 영역(세균·고세균·진핵생물) 안에 진핵 네 계(원생생물·식물·균류·동물)

  • 원생생물 = 동물·육상식물·균류에 넣지 않은 진핵생물 묶음. 핵은 공통, 단일 계통군 아님. 분류하기 어려운 극심한 다양성을 지닌 집단.
  • 단세포(짚신벌레·아메바·유글레나)와 다세포(미역·다시마·김)가 모두 있다. 기생은 일부만(말라리아·수면병·감자역병 원인 생물).
  • 영양: 종속영양(짚신벌레·아메바), 독립영양(해조류), 혼합영양(유글레나).

녹조류육상식물과 가장 가까운 현생 계통(직접 조상 아님)

적조·녹조생물군이 아닌 대량 번성 현상. 적조는 일부 와편모조류

적조: 대량 번성→호흡·사체 분해→용존 산소 감소→물고기 위협 (독소는 일부 종류만)

  • 산호는 동물, 광합성 공생 조류는 별개 생물. 백화가 오래가면 생존 위협(즉시 사망 아님).
  • 해조류·육상식물의 공통 능력은 광합성. 해조류 전반은 종자를 만들지 않음.
함정 ✗ 펩티도글리칸 세포벽은 원생생물의 특징이다. ✓ 펩티도글리칸 세포벽은 진정세균의 특징이다. ✗ 적조는 홍조류, 녹조는 녹조류라는 분류군의 다른 이름이다. ✓ 적조·녹조는 대량 번성 현상이고, 홍조류·녹조류는 생물군이다. ✗ 짚신벌레는 수축포에서 먹이를 소화하고 식포로 물을 배출한다. ✓ 짚신벌레는 식포에서 먹이를 소화하고 수축포로 물을 배출한다.

⑯ 사람류·화석 증거

사람류 = 습관적 두 발 걷기 · 루시 · 아프리카 기원 단서: 루시·허벅지뼈·유전적 다양성

영장류→유인원(사람 포함)→사람류(호미닌)→호모 속→호모 사피엔스

  • 영장류 공유 형질: 마주 보는 엄지, 유연한 어깨·엉덩이 관절, 큰 뇌·학습능력, 사회생활 → 사람류 구별 기준 아님.
  • 사람류 구별 주요 적응: 습관적 직립보행(일상적 두 발 걷기). 다른 유인원의 잠깐 두 발 서기와 구별.
  • 사람의 엄지발가락에 엄지손가락의 맞섬을 일반화하지 않음.
루시보행뇌 확대

  • 화산재 발자국 = 별도 보행 자료. 모양·배열·하중을 함께(깊이 하나로 판정 X).
  • 루시 ≠ 최초의 인간·확인된 직접 조상. 현생 침팬지가 그대로 사람이 된 것 아님.
