자손 과잉 + 자원 제한(무한히 늘지 않음)→경쟁

개체마다 변이 + 변이가 유전→유리한 형질 개체가 더 생존·번식

함정 ✗ 인위선택에서 사람은 원하는 새 형질을 만들어 품종을 얻는다. ✓ 인위선택에서 사람은 원하는 형질을 가진 개체를 골라 교배시킬 뿐이다.
함정 ✗ 많은 변이가 유전된다는 관찰에서 개체들이 제한된 자원을 두고 경쟁한다는 추론이 나온다. ✓ 경쟁이라는 추론은 자손 과잉과 자원 제한의 관찰에서 나온다(맬서스).

⑤ 자연선택의 논리

자연선택: 진화를 가져오는 원리 단서: 원리·가장 직접적인 결과

관찰추론
자손 과잉·개체군 크기 제한·자원 제한제한된 자원을 두고 경쟁
변이가 있고 많은 변이가 유전어떤 개체가 더 생존·번식

유전되는 변이 이미 있음→자원 제한으로 경쟁→그 환경에 유리한 개체가 더 생존·번식→다음 세대 비율 증가(대립유전자 빈도 변화)→보편화

  • 결과(멸종·지리적 변이)가 아니라 원리. 『종의 기원』 = "자연선택이라는 방법에 의한".
  • 직접 결과 = 개체군의 대립유전자 빈도 변화. 환경 변화는 원인 쪽, 새 대립유전자는 돌연변이.
  • 바뀌는 단위는 개체가 아니라 개체군. 고르는 주체: 자연선택 = 환경, 인위선택 = 사람.
  • 유전자가 제어하면 신체 모양·성장률·효소 활성·본능적 행동 모두 대상.
  • 생존 × 번식 둘 다 필요(교수님: "생존만, 번식만 해서는 안 된다"). 강의노트 표기: 적응도(생존 × 번식)를 높이는 적응형질을 선호.
  • 자연선택은 적응형질·선호형질을 보존, 줄어드는 쪽은 불리한 변이. 다윈 이론에 "적응형질을 제거한다"는 없음.
함정 ✗ 자연선택의 가장 직접적인 결과는 새로운 대립유전자가 만들어지는 것이다. ✓ 직접 결과는 이미 있는 대립유전자의 빈도 변화다. 새 대립유전자는 돌연변이로 생긴다.
함정 ✗ 영양실조로 다리가 짧아져 구멍에 잘 들어가는 강아지도 자연선택을 받는다. ✓ 살면서 생긴 차이는 유전되지 않아 재료가 아니다. 타고난 점박이 털처럼 유전되는 변이만 자연선택을 받는다.
함정 ✗ 어느 환경에 잘 적응한 개체는 다른 환경에서는 불리하다. ✓ 다른 환경에서는 잘 맞지 않을 수도 있다. 적응은 서식 환경을 빼고 정할 수 없다(큰 잎·큰 몸만으로 판단 불가).
⑥ 변형 혈통·계통수

계통수: 끊긴 가지=멸종, 끝=현존, 갈림점=공통조상 단서: descent with modification

변형 혈통
다윈이 '진화' 대신 쓴 말(descent with modification, '변화를 동반한 계승'). 모든 생물은 하나의 공통조상에서 조금씩 바뀌며 갈라져 내려왔다. 이를 나무로 그린 것이 계통수(樹=나무).
  • 세로축은 시간(아래 과거, 위 현재). 가지가 중간에 끝난 것은 시간 길이가 아니라 계통이 끊겼다는 뜻.
  • 새 종이 생긴 곳(새 계통이 나뉜 곳)은 갈림점. 끊긴 가지 끝이 아니다.
  • 공통조상의 증거: DNA·단백질 서열, 상동 구조, 화석(사람·침팬지).
함정 ✗ 계통수에서 꼭대기까지 닿지 않은 가지는 조상으로부터 새로운 종이 기원한 것을 나타낸다. ✓ 꼭대기까지 닿지 않은 가지는 멸종(멸절) 종이다. 새 종의 기원은 갈림점.
함정 ✗ 가지가 갈라지는 점은 멸종한 종이고, 도중에 끊긴 가지 끝은 공통조상이다. ✓ 갈라지는 점은 공통조상이고, 도중에 끊긴 가지 끝은 멸종한 종이다.
함정 ✗ 다윈의 '변형 혈통'은 자주 쓰는 기관이 발달하고 살면서 얻은 형질이 자손에게 전해진다는 뜻이다. ✓ 그것은 라마르크의 용불용설·획득형질 유전. 변형 혈통은 공통조상에서 조금씩 변하며 갈라져 내려왔다는 뜻.

⑦ 종합론·진화 증거

기준은 종 수준, 증거는 정황 증거 단서: 종 수준·시조새·DDT

현대적 종합론
다윈이 몰랐던 멘델 유전학(+생태·생리·유전학)을 진화론에 합침 → 형질이 다음 세대로 어떻게 전달되는지 설명. 중심 분야: 개체군 유전학(집단유전학 질문 = 미래 세대 유전자형 빈도)
진화적 변화
개체군의 유전적 구성이 바뀌어 대물림. 개체 수 증가만으론 부족(영양으로 키 큰 사람 증가 ✗)
구분기준예
소진화같은 종 안, 개체군의 작은 유전적 변화수업: 핀치 부리, 세균 항생제 내성. 기출: 개체군 색깔 작은 변화, HIV 약물 내성. 변형 문제: 해충 살충제 저항성 비율↑
대진화종 수준 이상: 종 출현·소멸수업: 새 종 탄생, 공룡 멸종. 기출: 갑작스러운 종 절멸, 공룡→새, 조류(藻類)→육상식물, 사자·호랑이 분기, 인간 출현
  • 적응: 짧은 시간에도 관찰(교재 DDT 모기 18개월). DDT는 뿌리기 전 돌연변이로 이미 있던 내성 개체를 골라 남김 → 자손이 늘어 집단 구성 변화. 항생제 내성도 같음(소진화) 교수님 강조
  • 화석: 시조새 = 공룡과 새의 중간 화석(깃털·속 빈 뼈 + 아직 긴 꼬리)
  • 생물지리학: 같은 지역 생물끼리 닮음(그 지역 공통조상). 섬 생물의 친척은 가장 가까운 대륙에(갈라파고스 핀치)
  • 비교해부학(상동·상사)·비교발생·비교분자 → ⑧
  • 정황 증거(CCTV 없음) ≠ 증거 없음. 진화를 부정하는 논문은 없음
  • 진화 연구가 아닌 것: 부모가 생애 동안 획득한 특성의 유전 연구(라마르크). 짧은 기간 분자실험·결과물 연구·섬의 많은 종 조사·상동기관 변이 연구는 맞음
함정 ✗ 소진화와 대진화는 변화의 크기와 걸린 시간으로 나눈다. ✓ 소진화와 대진화는 종 수준(종이 새로 생기거나 사라졌는가)으로 나눈다.
함정 ✗ 현대적 종합론은 DNA가 유전물질이라는 것을 보여 준다. ✓ 현대적 종합론은 형질이 다음 세대로 어떻게 전달되는지 보여 준다.
함정 ✗ 섬 생물의 가장 가까운 친척은 위도·환경이 비슷한 먼 섬에 있다. ✓ 섬 생물의 가장 가까운 친척은 가장 가까운 대륙(바하마 → 북아메리카)에 있다.
⑧ 상동·상사·분자 증거

닮은 이유가 조상인가 환경인가 교수님 강조 단서: 상완골·유선형·사이토크롬 c

구분조상 · 구조기능예
상동(homology)공통조상 공유(유전자 물려받음). 같은 대응 위치, 같은 구성 요소 같은 순서달라도 됨(판단 기준 아님)사람 팔·돼지 앞다리·돌고래 앞지느러미·박쥐 날개, 새 날개(교재)
상사(analogy)계열(조상)이 다름. 환경 때문에 겉모양이 비슷해짐비슷한 경우가 많음펭귄·상어·돌고래의 유선형 몸, 돌고래·상어 지느러미 겉모양

상완골 1개→척골·요골 2개→수근골→손가락 여러 갈래 = 상동기관

흔적기관

비교해부학

사이토크롬 c

공통 결론
DNA·화석·상동·흔적기관은 모두 인간과 침팬지의 공통조상을 가리킴
함정 ✗ 두 구조가 상동이려면 두 생물에서 동일한 기능을 가져야 한다. ✓ 기능은 달라도 되고, 해부학적·형태적으로 비슷해야 상동이다. ✗ 사람과 침팬지가 모두 맹장을 가진 것은 상사의 예다. ✓ 흔적기관 맹장을 함께 가진 것은 상동성의 증거다. ✗ 비교발생학 — 사람과 여러 동물의 사이토크롬 c 아미노산 서열 비교. ✓ 아미노산 서열 비교는 비교분자생물학, 비교발생학은 배아 비교다.

⑨ 변이의 원천

새 대립유전자는 돌연변이, 유성생식은 섞기 단서: 새롭고 독특한 유전자

원천하는 일새 대립유전자
돌연변이DNA가 바뀜(자발적)만든다 — 주된 원인
염색체 구조·수 변화유전 정보 배치가 달라짐변이를 늘림
유성생식: 교차·독립 분배·무작위 수정있던 대립유전자를 새 조합으로섞을 뿐
  • 판별 기준: 새 대립유전자를 만드는가, 이미 있는 것을 섞거나 고르는가.
  • 돌연변이: 자외선·여러 화학물질이 더 많이 일으킨다. 대부분 유해하거나 중립, 어쩌다 유익.
  • 빠르게 적응한 종 = 새 환경에 맞는 대립유전자를 이미 가지고 있었다. 선택은 이미 있는 변이에 작용.
함정 ✗ 한 개체군에서 새롭고 독특한 유전자가 생기는 주요 원인은 인위선택이다. ✓ 주요 원인은 돌연변이다. 인위선택은 이미 있는 변이 중에서 고를 뿐이고, 대진화·획득형질도 새 유전자를 만들지 않는다.
함정 ✗ 유성생식의 교차는 새로운 대립유전자를 만들어 변이를 늘린다. ✓ 교차는 이미 있던 대립유전자를 새 조합으로 섞을 뿐이다. 새 대립유전자는 돌연변이가 만든다.
함정 ✗ 돌연변이는 대부분 이롭다. ✓ 대부분 유해하거나 중립이다. 어쩌다 생긴 유익돌연변이를 늘리는 것은 자연선택이다.
⑩ 빈도·하디-바인베르크

빈도 계산과 유전적 평형 교수님 강조

구분뜻분모(셈 단위)
유전자형 빈도그 유전자형(AA·Aa·aa)을 가진 개체의 비율개체 수 N
대립유전자 빈도대립유전자 전체 중 한 대립유전자의 비율대립유전자 총수 2N

총수 = 개체 수 × 2→A 개수 = 2×AA + Aa→p = A ÷ 2N, q = 1 − p→p², 2pq, q²→× 다음 세대 개체 수

  • 빈도만 주면 p = AA 빈도 + ½ Aa 빈도. 예: 450·500·50(1,000개체) → 2,000개 중 1,400 → p = 0.7, q = 0.3.
  • p + q = 1, p² + 2pq + q² = (p + q)² = 1. 2pq의 2는 뽑는 순서 두 가지(pq만 쓰면 절반). p = 0.7 → 0.49·0.42·0.09(1,000개체면 490·420·90).
  • 하디-바인베르크 원리 다섯 조건: 돌연변이 없음 · 이동 없음(다른 개체군으로부터의 유입 없음) · 개체군 크기 무한 · 자연선택 없음(모든 유전자형이 똑같이 생존·번식) · 무작위 교배. 앞 넷은 p, q를 지키고, 무작위 교배는 p², 2pq, q²로 짝짓는다.
  • 유전적 평형: 다섯 조건이 유지되는 한 대립유전자 빈도와 유전자형 빈도가 세대가 지나도 변하지 않음. 다음 세대 p, q는 다시 셀 필요 없음.
  • 영가설: 평형 = 진화가 일어나지 않는 조건. 조건이 하나라도 깨져 빈도가 변하면 소진화(자연계에서는 반드시 일어남).
함정 ✗ 하디-바인베르크 원리의 조건: 자연선택이 존재한다. ✓ 조건은 자연선택이 없다(모든 유전자형이 똑같이 생존·번식). 개체가 드나드는 것도 조건이 아니라 깨진 상황.
함정 ✗ 대립유전자 빈도는 그 대립유전자를 가진 개체 수를 개체 수로 나눈 값이다. ✓ 대립유전자 빈도는 대립유전자 개수(2×AA + Aa)를 개체 수 × 2로 나눈 값이다.
함정 ✗ 평형 상태인 개체군에서는 대립유전자 빈도가 세대마다 변하므로 소진화가 활발하다. ✓ 평형은 빈도가 변하지 않는 상태(영가설)라 소진화가 일어나지 않는다.

7장 진화 사상과 소진화

⑪ 평형 계산 함정 · ⑫ 소진화 요인·유전자 확산 · ⑬ 유전적 부동

⑪ 평형 계산 함정

1세대 그대로 금지 · 환자=q²에서 역산 교수님 강조

1세대(평형 깨짐) AA·Aa·aa→p = AA + ½Aa, q = aa + ½Aa→2세대 p²·2pq·q²→3세대부터 같음

예: 0.50·0.20·0.30→p 0.60, q 0.40→0.36·0.48·0.16

환자 비율(aa) = q²→q = √q²→p = 1 − q→보인자(이형접합자 Aa) = 2pq

예: 1/400 = 0.0025→q 0.05→p 0.95→2pq 0.095 (약 9.5%)

  • 넘어가는 것은 유전자형 빈도가 아니라 p, q. aa = q²는 평형 가정이 있어야 성립.
  • 이주 섞이면 개수로: 900명 중 9명 → q 0.1, a 180개 / 1,000명 × 2 = 2,000개 → 0.09(P37).
함정 ✗ 평형이 유지되므로 자손 세대 유전자형 빈도는 1세대 값 그대로다. ✓ 평형은 2세대부터. 1세대에서 p, q를 구해 p², 2pq, q²로 계산한다. ✗ 400명 중 1명이 환자면 열성 대립유전자 빈도 q는 0.0025다. ✓ 0.0025는 q². q는 그 제곱근인 0.05다. ✗ 보인자의 빈도는 환자 빈도와 같은 q²이다. ✓ 보인자는 이형접합자 Aa로 2pq, 환자는 aa로 q²이다.
⑫ 소진화 요인·유전자 확산

평형 조건 뒤집기 = 소진화 요인 단서: 이동 없음·유입·유출

깨진 평형 조건소진화 요인빈도를 바꾸는 방식
돌연변이 없음돌연변이새 대립유전자·새 변이 생성
이동 없음유전자 확산 = 유전자 흐름다른 집단에서 유입·유출
개체군 크기 무한유전적 부동작을수록 우연으로 크게 흔들림
자연선택 없음자연선택잘 살고 번식한 쪽 대립유전자 증가
무작위 교배선택적 교배(성선택)짝으로 더 선택된 형질의 대립유전자 증가
  • 유전자 확산(gene flow): 꽃가루·씨앗 확산, 개체 이주로 이미 있는 집단 사이를 대립유전자가 오감. 유입·유출 모두 해당, 새 유전적 변이를 들여옴. 이주 직후 빈도 = 대립유전자 개수 다시 세기 ÷ (개체 수 × 2).
  • 돌연변이: DNA 염기서열의 자발적 변화(자외선·화학물질이 늘림). 대부분 유해하거나 중립, 드문 유익돌연변이는 자연선택으로 늘어남.
  • 근친교배(강의노트: 선택적 교배의 특별한 형태): 동형접합자 증가·이형접합자 감소, 열성 표현형이 자주 나타남. 교재 표 7.3: 선택적 교배는 대립유전자 빈도에 직접 영향 없음, 유전자 평형은 막음.
  • 획득형질은 유전되지 않아 빈도를 못 바꿈 → 소진화 요인 아님(기출 "빈도를 변화시키는 요소가 아닌 것"의 가장 확실한 고르기).
  • 유전적 부동(병목·창시자)은 ⑬, 자연선택 양상은 ⑭.
함정 ✗ 살면서 얻은 형질(획득형질)도 자손에게 전해져 대립유전자 빈도를 바꾼다. ✓ 획득형질은 유전되지 않아 빈도를 바꾸지 못한다. 소진화 요인이 아니다. ✗ 근친교배처럼 짝이 치우치기만 해도 대립유전자 빈도가 반드시 바뀐다. ✓ 근친교배는 유전자형 빈도(동형접합자↑·이형접합자↓)를 바꾼다. 무작위 교배가 깨진 요인은 유전자 흐름이 아니라 선택적 교배. ✗ 몇 개체가 떨어져 나와 새 지역에 새 집단을 세운 것도 유전자 확산이다. ✓ 유전자 확산은 이미 있는 두 집단 사이의 이동. 새 집단을 세우면 창시자 효과(유전적 부동).
⑬ 유전적 부동

우연이 빈도를 바꿈 = 유전적 부동 단서: 우연·예상치 못한 변화

유전적 부동(genetic drift)→우연한 사건으로 대립유전자 빈도가 예상치 못하게 변함→빈도가 변했으니 소진화(진화)

병목 현상우연(형질 무관). 그 자리에서 개체 수 시간적 급감줄어듦. 산불·홍수·폭풍·지진·사냥
창시자 효과우연(창시자 유전자). 소수가 공간적으로 떨어져 새 지역에 새 집단그대로. 몇 마리 탈출·폭풍에 실려 섬
자연선택형질에 따른 생존·번식. 유리한 형질 개체가 더 살아남음—. 감염 저항성·매에게 잘 띔
  • 병목 현상·창시자 효과는 둘 다 유전적 부동의 한 경우. 기출: 롱 아일랜드 도마뱀 탈출 = 창시자 효과, 산불 다람쥐 = 유전적 부동 / 감염 다람쥐 = 자연선택.
  • 작은 개체군일수록 영향 큼, 충분히 크면 작음(H-W "크기 무한"이 깨진 경우). 방향 없음: 같은 출발점에서 고정(빈도 1)·소실(빈도 0) 다 가능.
  • 유전적 다양성을 보통 줄임(사라진 대립유전자는 돌연변이·유전자 확산 없이 안 돌아옴) → 멸종 확률↑.
  • 헷갈리는 이웃: 기존 집단 사이 이동 = 유전자 확산, 친척끼리 교배 = 근친교배, 균형 유지 = 평형 다형성.
함정 ✗ 유전적 부동으로 변한 집단은 변화가 우연의 결과이므로 진화하지 않는다. ✓ 대립유전자 빈도가 변했으면 원인이 우연이어도 진화한다.
함정 ✗ 유전적 부동으로 변한 집단은 언제나 작은 창시자 집단으로부터 출발한다. ✓ 창시자 효과는 한 경우일 뿐, 그 자리에서 급감하는 병목 현상도 유전적 부동이다.
함정 ✗ 산불로 90%가 죽고 남은 다람쥐는 환경에 적응한 개체이므로 자연선택이다. ✓ 형질과 상관없이 운으로 살아남았으므로 유전적 부동(병목 현상)이다.

⑭ 자연선택 세 양상

적응도 = 자식 수, 양상 = 분포 모양 단서: 평균 이동·홀쭉·봉우리 둘

상대적 적응도
남긴 생존 자식 수를 다른 개체와 비교한 값. 돈·수명·건강 아님.
계산
자식을 가장 많이 남긴 개체 = 1.0. 흥부 10명 1.0 → 놀부 1명 0.1. 변형: A 12마리 1.0 → B 3마리 3/12 = 0.25, 0마리면 0. 산 기간은 안 씀.
작용 대상
대립유전자 자체가 아니라 개체의 표현형.
양상불리한 쪽평균·분포예
방향성 선택한쪽 극단평균 이동, 봉우리 하나 통째로항생제 내성 세균, 상아 짧아진 코끼리, 기린 목, 가뭄 뒤 핀치 부리
안정화 선택양 극단평균 그대로, 폭 좁아짐출생 체중(수업 퀴즈)
분단성 선택 (=다형화 선택)중간봉우리 둘, 다양해짐—
  • 그림: 점선 = 선택 전, 강조 실선 = 선택 후. 가로축 형질 값, 세로축 개체 수.
  • 판별: ① 선택받는 집단(항생제면 세균) ② 늘어난 쪽이 한쪽 끝·가운데·양 끝? ③ 평균 이동 / 폭만 감소 / 봉우리 둘.
  • 개체 수 감소로 양상을 정하지 않음. 핀치: 생존자 곡선이 낮음 = 개체군 줄어듦(커졌다 ✗), 평균선은 깊은 부리 쪽 이동.
  • 자연선택 직후 다양성: 일반적으로 감소(분단성은 양 극단이 남는 예외). 새 변이는 안 만듦.
  • 새 강한 선택: 멸종, 흔한 형태↔드문 형태 역전, 흔한 형태 대체, 변이 감소 → 모두 일어날 수 있음.
  • 선택 유형이 아닌 보기: 획득형질·"쓰다 보니 변함"(라마르크식), 역진화, '다양화 선택'(수업 이름에 없음. 분단성으로 읽어도 봉우리 둘일 때만, 기린 목처럼 한 방향 이동이면 오답). 표현형 무관한 우연한 죽음(산불)은 유전적 부동.
함정 ✗ 내성 S. aureus가 1~5%에서 60~70%로 는 것은 세균의 분단성 선택이다. ✓ 내성 있는 한쪽으로 옮겨 갔으므로 세균의 방향성 선택이다.
함정 ✗ 사람이 항생제를 썼으므로 내성 세균 증가는 인간의 방향성 선택이다. ✓ 빈도가 바뀐 것은 세균 집단이다. 사람은 환경만 만들었다.
함정 ✗ 상대적 적응도는 가장 오래 산 개체를 1.0으로 놓고 비교한다. ✓ 자식을 가장 많이 남긴 개체를 1.0으로 놓는다. 오래 산 D(자손 0)는 0이다.
⑮ 성선택·이형접합자 이점

성선택은 짝짓기 성공 · 이형접합자 이점은 말라리아가 조건 기출 밖

성선택
이성 중 한쪽(보통 암컷)이 짝을 골라 교배 → 선택받은 형질의 대립유전자 빈도 증가(소진화). 교수님은 선택적 교배와 묶어 말함
조건
한쪽 성의 선택이 짝짓기 성공을 가름. 생존률·생식력 증가 자체나 '수컷일 것'이 아님
성적이형성
암수 모양 차이(di 둘, morphism 형태). 한쪽 성의 특정 형질만 골라져 차이가 커짐. 예: 사자 갈기, 공작 꼬리 깃, 사람 몸집

이형접합자 이점(평형 다형성의 한 이유) = 이형접합자 상대적 적응도가 두 동형접합자보다 높음→불리한 대립유전자 S도 AS 안에 실려 유지

낫모양 적혈구빈혈말라리아말라리아 지역
AA없음저항성 없음말라리아로 일찍 죽을 수 있음
AS약함(불완전 우성)저항성(S 하나로 충분)가장 높음
SS심함저항성빈혈로 일찍 죽을 수 있음
  • 말라리아(모기가 옮김) 많은 아프리카는 S 빈도 높음, 없는 미국은 낮음. 인종이 아니라 환경.
  • 선택은 표현형에 작용. 이형접합자 안에 숨는 것은 열성 대립유전자(열성 동형접합자 aa는 드러나 선택받음).
함정 ✗ 성선택이 일어나려면 생존률이나 생식력이 증가해야 한다. ✓ 이성 중 한쪽이 결정한 선택으로 짝짓기에 영향을 미쳐야 한다(수컷일 필요도 없음).
함정 ✗ 성선택으로 커진 형질은 언제나 생존에도 유리하다. ✓ 공작 깃처럼 생존에 불리할 수 있다. 짝을 더 얻어 자식 수가 늘어 유지되고, 암수 차이는 커진다.
함정 ✗ 말라리아가 없어도 AS의 상대적 적응도가 가장 높아 S 빈도가 그대로 유지된다. ✓ 말라리아가 없으면 AS 이점이 사라져 AA가 가장 유리하고 S 빈도는 낮아진다.
