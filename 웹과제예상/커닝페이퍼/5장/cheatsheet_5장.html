① 시험장 체크

이름·비교 단위·조절 대상을 먼저 확인

5장 실제: 17문항·84보기. 부정형 5개, 코돈표 1개. 시간 제한은 미확인.

  • ‘옳지 않은·아닌’ 표시 → 내용의 참·거짓을 판정한 뒤 선택 방향 확인.
  • 한국어·영어·다른 번역명 → ②에서 이름과 현상을 함께 찾기.
  • ‘하나’가 전구체인가, 성숙 mRNA 한 종류인가 → ⑧ ⑬.
  • DNA 접근성/전사 개시인가, 이미 생긴 RNA 가공인가 → ⑫ ⑬.
  • DNA·히스톤·mRNA·단백질 중 직접 변하는 대상 확인 → ⑥ ⑫–⑭.
  • 가닥 종류와 5′·3′부터 쓰기. 코돈표는 mRNA 5′→3′ → ③ ⑤ ⑦ ⑨.
  • 서열 길이와 읽는 틀의 변화 구별. 치환/삽입/삭제 원인 확인 → ⑩.
  • 작동자 DNA와 억제자 단백질, 억제 해제와 최대 발현 구별 → ⑪.
  • 조건이 빠졌으면 가정과 불확실성을 따로 남기기. 절대어 하나만으로 판정하지 않기.

  • 코돈 = mRNA의 염기 3개. 4³ = 64개: 아미노산 지정 61개 + 종결 3개.
  • AUG = 메티오닌·개시. UAA·UAG·UGA = 아미노산 없이 번역 종결.

원핵은 핵막이 없어 전사와 번역이 함께 진행 가능. 진핵 핵 유전자의 RNA 가공은 핵 안, 번역은 핵 밖. 원핵 mRNA에 5′ cap·통상적 인트론 제거를 일반화하지 않기.

  • lacZ·lacY·lacA: 프로모터 하나 → mRNA 하나 → 서로 다른 단백질 3개.
  • lacI는 오페론 바깥의 억제자 암호화 유전자. 억제자는 젖당이 없어도 만들어진다.
  • 표는 포도당 없음으로 고정. 젖당만 있다고 강한 발현을 단정하지 않는다. 억제는 생산량 0을 뜻하지 않는다.

작동자의 억제자 결합 기능만 소실되고 프로모터·구조유전자는 정상이면 젖당 의존적 억제가 풀림. 구성적 발현은 항상 최대 발현과 다름.

함정 ✗ 활성 억제자는 오페론의 유전자들을 발현시킨다. ✓ 활성 억제자는 오페론의 유전자 전사를 막는다.
함정 ✗ 유도자는 억제자를 활성화시켜 전사를 가능하게 한다. ✓ 유도자는 억제자를 비활성화시켜 전사를 가능하게 한다.
함정 ✗ lacI는 lacZYA와 함께 하나의 mRNA로 전사된다. ✓ lacI는 lacZYA와 함께 전사되는 구조유전자에 포함되지 않는다.
