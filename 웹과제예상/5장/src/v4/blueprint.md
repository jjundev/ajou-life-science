## 재출제 유력 기출 10
- 기출 5강 15: 다음 중 DNA 복제의 오류를 수정하는 메커니즘에 대한 설명으로 잘못된 것은? / 정답: DNA 중합효소는 새로운 뉴클레오타이드 사슬을 조립할 때 많은 오류를 범한다 / 복제 정확도와 교정 기작을 묻는 핵심 문항이에요.
- 기출 5강 26: DNA 분자의 코돈 CCU를 코돈 CCC로 변화시킨 돌연변이를 가정하자. 이 두 코돈은 모두 프롤린을 지시한다. 이러한 예를 무엇이라 하는가? / 정답: 유전암호의 중복성 / 동의 코돈과 퇴화성을 직접 묻는 대표 문항이에요.
- 기출 5강 2: 다음 중 전사에 관한 설명으로 옳은 것은? / 정답: 번역될 유전자의 RNA 사본을 생성한다 / 전사의 기본 정의와 진행을 묻는 중요 문항이에요.
- 기출 5강 37: 다음 중 번역 과정에 직접적으로 참여하지 않는 분자는? / 정답: DNA / 전사와 번역의 관여 인자를 구분하는 필수 문항이에요.
- 기출 5강 5: TTACAGGTCC 유전자로부터 만들어진 mRNA는 어느 것인가? / 정답: AAUGUCCAGG / 전사 상보 서열 결정을 묻는 기본 문항이에요.
- 기출 5강 20: 운반 RNA (tRNA)에 대한 설명으로 옳은 것은? / 정답: 전령 RNA (mRNA)의 코돈과 상보적인 안티코돈 부분을 가지고 있다 / tRNA의 코돈 인식 부위를 묻는 대표 문항이에요.
- 기출 5강 24: 같은 사람에게 존재하는 두 종류의 세포(예 : 피부세포와 신경세포)의 차이를 야기하는 것은 무엇인가? / 정답: 다른 종류의 세포는 같은 유전자를 갖는다. 그러나 이 중 발현하는 유전자는 다르다. / 차등적 유전자 발현의 기본 원리를 묻는 핵심 문항이에요.
- 기출 5강 25: 번역틀이동 돌연변이는 ( ) 의 결과로 생긴다. / 정답: 유전자의 암호화 부위에 염기 하나가 삽입 또는 삭제 / 염기 삽입·결실의 영향을 묻는 중요 문항이에요.
- 기출 5강 14: 번역 과정은 최종적으로 ________을(를) 생산한다. / 정답: 폴리펩타이드 / 센트럴 도그마 최종 산물을 묻는 기본 문항이에요.

## 독립 블라인드 검토
독립 리뷰어 블라인드 풀이 결과 15/15 정답 일치(100%), 이의 0건으로 통과했어요.
- 수준 판정: 수준 1 (10개: p1, p2, p3, p4, p6, p8, p11, p12, p13, p14), 수준 2 (4개: p5, p7, p10, p15), 수준 3 (1개: p9).
- 최종 기본 14·심화 1로 생성 목표(기본 12·심화 3) 대비 기본이 2개 많아요. P7(핵산 시료 염기 조성)과 P10(lac 변이주 분석)이 단일 원리 적용(수준 2)으로 간결하게 해결되었으며, 목표 비율을 맞추기 위해 억지 조건이나 계산 단계를 늘리지 않고 원문의 명료성을 유지했어요.
- 이전 v1~v3와의 기출 번호 중복 0건, 발문 중복 0건을 확인했어요.
