P7. [예상] 한 염기 삽입 뒤 사슬 길이

아래 정상 mRNA의 첫 AUG 바로 뒤에 C 하나가 삽입되어 삽입 mRNA가 되었어요. 두 mRNA 모두 첫 AUG부터 세 염기씩 읽고 처음 만나는 종결 코돈에서 번역을 끝내요. 개시 아미노산도 세고, 종결 코돈은 잔기로 세지 않으며 번역 후 절단은 없어요. 정상 사슬과 삽입 사슬의 아미노산 잔기 수를 차례로 바르게 짝지은 것은 무엇인가요?

정상 mRNA: 5′-AUGGGCGCUAACUACUAA-3′
삽입 mRNA: 5′-AUGCGGCGCUAACUACUAA-3′

필요한 코돈의 뜻: AUG=메티오닌, GGC=글리신, GCU=알라닌, AAC=아스파라긴, UAC=타이로신, CGG·CGC=아르기닌, UAA=종결이에요.

  • A. 정상 6개 / 삽입 4개
  • B. 정상 5개 / 삽입 5개
  • C. 정상 5개 / 삽입 3개
  • D. 정상 4개 / 삽입 2개
  • E. 정상 3개 / 삽입 5개
원문 정보 보기1006 정리노트의 번역틀이동 원리로 만든 새 서열 문제예요. 서열과 필요한 코돈 뜻은 문제에 제공했어요.
힌트 보기삽입 뒤에도 예전 코돈 구분을 유지하지 말고 첫 AUG부터 다시 세 염기씩 나눠요.
풀이 보기
  1. 정상은 AUG / GGC / GCU / AAC / UAC / UAA로 읽어 5잔기예요. 삽입 후에는 AUG / CGG / CGC / UAA / CUA / CUA / A가 되며 첫 UAA에서 끝나 3잔기예요.
  2. A. 틀려요. 정상과 삽입 사슬 모두 UAA는 아미노산을 지정하지 않으므로 종결 코돈을 잔기로 더하지 않아요.
  3. B. 틀려요. 삽입으로 읽는 틀이 바뀌어 네 번째 코돈에 UAA가 나타나요.
  4. C. 맞아요. 정상에서는 아미노산 지정 코돈 다섯 개를 읽지만 삽입 후에는 세 개를 읽은 뒤 종결해요.
  5. D. 틀려요. 사슬의 첫 AUG가 지정하는 메티오닌도 잔기 수에 포함해야 해요.
  6. E. 틀려요. 두 서열을 재구획하면 정상은 5개, 삽입은 3개로 보기와 순서가 반대예요.
  7. 수업과의 연결: 정리노트 "한 글자가 빠지면 조가 밀려요"의 원리를 적용해요.

정답: C
