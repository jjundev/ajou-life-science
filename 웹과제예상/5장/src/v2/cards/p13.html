P13. [예상] 전사를 멈춘 뒤에도 늘어나는 단백질

동일한 단백질 S를 만드는 세포군 가와 나에서 시각 0분에 S 유전자의 전사만 완전히 중지했어요. 새 mRNA는 생기지 않으며 남은 성숙 mRNA는 계속 번역돼요. 두 군에서 mRNA 한 분자당 단백질 생성 속도는 같고 일정해요. 실험 중 S는 분해되지 않으며 세포 수도 변하지 않아요. 두 군의 초기 S 총량은 같아요. 0~10분 동안 mRNA는 끊김 없이 감소하며 표는 각 시각의 잔존량을 나타내요. 10분의 단백질 생성 속도와 5~10분의 S 총량 변화에 대한 설명으로 옳은 것은?

세포군별 S의 성숙 mRNA 잔존량
시각가나
0분100100
5분4080
10분2060
  • A. 10분에는 두 군 모두 새 단백질 생성이 없으며, S 총량도 5분과 같다.
  • B. 10분의 단백질 생성 속도는 가가 더 크며, 두 군의 S 총량은 5~10분에 증가한다.
  • C. 10분의 단백질 생성 속도는 나가 더 크며, 두 군의 S 총량은 5~10분에 감소한다.
  • D. 10분의 단백질 생성 속도는 두 군에서 같으며, 두 군의 S 총량은 5~10분에 증가한다.
  • E. 10분의 단백질 생성 속도는 나가 더 크며, 두 군의 S 총량은 5~10분에 증가한다.
원문 정보 보기기출 원문이 아닌 새 예상 문제예요. 1008 정리노트의 mRNA 수명과 단백질 생산 관계에 가상 실험 조건을 적용했어요. 표의 값은 생성한 자료예요.
힌트 보기새 mRNA가 생기지 않는 것과 기존 mRNA가 번역되지 않는 것은 달라요. 한 시각의 생성 속도와 그동안 쌓인 단백질 총량도 구별해요.
풀이 보기
  1. 전사는 중지됐지만 남은 mRNA는 번역돼요. 10분에 mRNA가 더 많은 나에서 단위 시간당 새 S 생성이 더 커요. 5~10분에도 두 군 모두 mRNA가 남아 번역하고 S는 분해되지 않으므로 S 총량은 계속 늘어요.
  2. A. 틀려요. 전사를 중지해도 기존 mRNA가 남아 있으므로 새 단백질 생성은 계속돼요.
  3. B. 틀려요. 총량 증가에 대한 설명은 맞지만, 10분의 mRNA는 나에 더 많으므로 생성 속도도 나가 더 커요.
  4. C. 틀려요. 생성 속도가 줄어도 S가 분해되지 않고 새로 만들어지므로 총량은 감소하지 않아요.
  5. D. 틀려요. mRNA 한 분자당 생성 속도가 같아도 mRNA 잔존량이 다르므로 군 전체 생성 속도는 달라요.
  6. E. 맞아요. 나의 많은 잔존 mRNA는 더 큰 생성 속도를 만들며, 양쪽 모두 분해 없이 합성을 이어가므로 총량이 증가해요.
  7. 수업과의 연결: 정리노트 "엑손 조합과 mRNA의 수명"의 원리를 적용해요.
