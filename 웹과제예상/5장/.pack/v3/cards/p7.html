P7. [예상] 같은 DNA에서 서로 다른 작업을 시작해요

세포가 염색체 DNA를 복사하는 작업과, 특정 유전자의 RNA 사본을 만드는 작업을 구분하려고 해요. 두 작업의 시작과 관련된 DNA 부위를 바르게 짝지은 것은 무엇인가요?

  • A. DNA 복사 — 프로모터 / RNA 사본 생성 — 복제원점
  • B. DNA 복사 — 안티코돈 / RNA 사본 생성 — 프로모터
  • C. DNA 복사 — 복제원점 / RNA 사본 생성 — 프로모터
  • D. DNA 복사 — 복제원점 / RNA 사본 생성 — 종결 코돈
  • E. DNA 복사 — 프로모터 / RNA 사본 생성 — 안티코돈
원문 정보 보기1001 정리노트의 복제 효소 토픽에 명시된 복제원점과 1006 정리노트의 프로모터를 비교한 새 예상 문제예요.
힌트 보기만드는 산물이 DNA인지 RNA인지 먼저 나눠요.
풀이 보기
  1. A. 틀려요. 복제원점과 프로모터의 대응이 서로 뒤바뀌었어요.
  2. B. 틀려요. 안티코돈은 tRNA의 일부이며 DNA 복제 시작 부위가 아니에요.
  3. C. 맞아요. DNA 복제는 복제원점에서 시작하고, 전사 시작에는 RNA 중합효소가 결합하는 프로모터가 관여해요.
  4. D. 틀려요. 종결 코돈은 번역을 끝내는 신호이며 RNA 사본 생성을 시작하는 부위가 아니에요.
  5. E. 틀려요. 프로모터는 전사 시작에 관여하고 안티코돈은 tRNA에 있으므로 두 대응 모두 맞지 않아요.
  6. 수업과의 연결: 정리노트 "전체 복제와 유전자 전사·번역 구별하기"와 정리노트 "헬리케이스·프라이메이스·DNA 중합효소"의 복제원점 설명을 연결해요.

정답: C
