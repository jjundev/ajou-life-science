# 12장 웹과제 예상 v1 설계

1112·1117 정리노트와 1117 장 마감 검토에서 확인한 강의노트 12장 1~6쪽, 12.1~12.3을 사용한다. 12장 정본·raw·본문 피드백은 미등록/미작성이다. 이전 장 1~3의 정본 집계로 유형을 참고했다. 공통 웹과제 안내는 장별 수업 뒤 배운 내용을 점검한다고 안내한다. 1117 녹화·웹과제 일정 발언은 15·17·18장 대상이고, 수업 시작의 ‘오늘 문제’는 평가와 장이 불명이다. 13장 도입은 제외한다.

## 목표와 실제

- 부정형 최소 4(설계 5), 그림 3, 표 1. ㄱㄴㄷ 및 장섞기는 필수 0이며 이번에도 쓰지 않는다.
- 기출 풀에서 기본 발문을 보존하면서 숫자·조건만 바꿔 보기를 다시 계산할 대상이 없다. p5는 쌍둥이, 계산은 0이다. 3:2는 수송 방향을 판별하는 근거로 사용한다.
- 장별 실제 난이도 관찰이 없어 기본 12·심화 3을 생성 목표로 삼았다. 독립 판정은 수준 1 7문항, 수준 2 6문항, 수준 3 2문항(9·15번)으로 기본 13·심화 2다. 13번은 한 경로의 차단 효과를 묻는 수준 2다. 추가로 시험한 복합 신호안은 운동뉴런의 발화 조건이 빠져 기존 검증본으로 복원했다. 6번은 그림의 하강 구간과 이온 이동을 직접 대응하는 수준 1, 10번은 새 사례에 용어를 적용하는 수준 2다.
