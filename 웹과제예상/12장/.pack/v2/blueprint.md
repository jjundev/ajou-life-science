# 12장 웹과제 예상 v2 설계

1112·1117 정리노트와 1117 장 마감 검토에서 확인한 강의노트 12장 1~6쪽, 12.1~12.3을 사용한다. 12장 실제 웹과제 정본·raw·본문 피드백은 미등록/미작성이다. 1~3장 정본 46문항의 유형 통계를 참고했다. v1에서 사용한 기출 5문항(`12강 4, 1, 40, 37, 5`)은 p1–p5에서 모두 제외하고, 새 문제 p6–p15는 v1에서 다루지 않은 주제(독소 작용점, Cl⁻ 평형전위 억제, 혈액뇌장벽, 해마 손상, 뇌간·뇌사/식물인간, 분리뇌, 언어 영역·뇌 영상, 눈 초점 조절, 캡사이신·통각)와 불응기 파형으로 차별화한다. 13장 호흡계 도입과 골격계는 제외한다.

## 회상·비교 연습

- p7 / 1112 s4-transmitters / 근육 수용체 차단(쿠라레형)과 척수 억제 뉴런 방출 차단(파상풍 독형)의 작용 단위 분리 / 관찰 표 → 작용 위치 / 같은 '운동 이상'이라도 흥분 차단(이완)과 억제 차단(과수축)의 작용점 구분
- p8 / 1112 s3-excite-inhibit / Cl⁻ 평형전위와 막전위 비교를 통한 억제 판별 / 전위 조건 → 이온 이동·발화 여부 / 과분극 유무와 억제 성립 조건 분리
- p12 / 1117 s3-hemispheres / 시야 기준과 눈 기준, 좌·우반구 기능과 교차 지배 분리 / 그림 조건 → 언어·손 반응 / 분리뇌에서 정보 이동 경로와 출력 손의 대응 확인
- p14 / 1117 s5-eye / 강의노트 용어 '모양체근'과 수업 용어 '섬모체근' 전환 / 그림(수정체 두께) → 근육 수축 상태·거리 / 같은 근육의 동의어 회상 및 수축–구형 방향 점검

## 목표와 실제

- 부정형 최소 4(설계 6: p3, p4, p6, p11, p13, p15), 그림 3(p6, p12, p14), 표 1(p7). ㄱㄴㄷ·장섞기·계산은 최소 0이며 이번 세트에도 쓰지 않는다(12장 기출·노트에 수치 계산 문항 없음).
- 장별 실제 난이도 관찰이 없어 기본(수준 1~2) 12문항·심화(수준 3) 3문항을 목표로 설계했다. 독립 풀이 판정은 수준 1 8문항(p1–p5, p11, p13, p15), 수준 2 4문항(p6, p9, p10, p14), 수준 3 3문항(p7, p8, p12)으로 기본 12·심화 3이며 목표와 일치한다(p11만 설계 2→독립 1, 기본 범주 동일).

## 경계 주제

없음. 13장 호흡계 도입과 골격계를 포함할 대상 웹과제 근거가 없다.
