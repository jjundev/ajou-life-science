# 12장 웹과제 예상 v3 설계

1112·1117 정리노트와 1117 장 마감 검토에서 확인한 강의노트 12장 1~6쪽, 12.1~12.3을 사용한다. 12장 실제 웹과제 정본·raw·본문 피드백은 미등록/미작성이다. 1~3장 정본 46문항의 유형 통계를 참고했다. v1·v2가 쓴 기출 10문항(12강 4·1·40·37·5·26·9·38·3·17)은 p1–p5에서 제외했다. 새 문제는 두 버전이 다루지 않은 장면(세 자극 기록, 활동전위 중 농도 차, 뉴런 그림, 분비 유무에 따른 약물 비교, 두 근육의 운동뉴런 기록, 감각 신호의 길, 대뇌 옆모습, 기저막 손상 위치, 두 감각세포의 분비 변화, 어두운 곳의 시각)으로 구성한다. 1124의 1112 노트 보완(활동전위 중 이온 농도 차 유지)을 p7에 반영했다. 13장 호흡계·순환계와 골격계는 제외한다.

## 회상·비교 연습

- p4 / 1112 s3-release / 채널을 여는 조건(막전위 ↔ 리간드) 비교 / 그림 위치 → 여는 조건 / 작용 위치와 개폐 조건 구별. 이전 v1 p9는 차단 지점의 자료 해석이라 질문 방향과 자료가 다름
- p8 / 1112 s0-neuron / 부위 이름을 그림 위치로 바꿈 / 위치 → 기능 / 명칭을 가린 도식 회상
- p9 / 1112 s4-removal / 분비가 없는 조건을 더함 / 관찰값 → 작용 위치 / 이전 v1 p7의 재흡수 억제 하나에서 두 작용의 비교로 바꿈
- p13 / 1117 s4-hearing / 소리 크기(v1 p15)에서 음높이·손상 위치로 바꿈 / 그림 → 들리지 않는 음 / 위치와 빈도의 비교 단위 구별
- p14 / 1117 s4-hearing·s5-photoreceptors / 두 감각세포의 전달물질 분비 방향 / 자극 → 분비 변화 / 세포별 변환 방향 비교

## 목표와 실제

- 부정형 최소 4(설계 5: p4·p5·p8·p11·p14), 그림 3(설계 5: p4·p6·p8·p12·p13), 표 1(설계 2: p9·p10). 그림은 12장 노트의 도식 비중이 커서 늘렸고 모두 위치·기록을 읽어야 답이 정해진다.
- 계산 0: 12장 기출과 노트에 수치 계산 문항이 없다. 기출숫자로 바꿀 기출도 없어 p5는 쌍둥이로 했다(`exam_counts` 그대로 2·쌍둥이 3). ㄱㄴㄷ·장섞기는 선택 유형이라 쓰지 않았다.
- 장별 실제 난이도 관찰이 없어 기본(수준 1~2) 12·심화(수준 3) 3을 생성 목표로 삼았다. 설계는 수준 1 5문항(p1·p2·p4·p5·p8), 수준 2 7문항(p3·p6·p7·p11·p12·p13·p14), 수준 3 3문항(p9·p10·p15)이다. 독립 풀이 판정은 수준 1 7문항(p1·p2·p4·p5·p8·p11·p14), 수준 2 6문항(p3·p6·p7·p12·p13·p15), 수준 3 2문항(p9·p10)으로 기본 13·심화 2다. p15는 세 조건이 노트에 그대로 있어 2로 판정됐고(1·2회차 일치), 난이도만 올리는 조건을 덧붙이지 않고 목표 차이로 공개한다. 위 표의 수준 열은 설계값이다.

## 경계 주제

없음. 13장 내용을 포함할 12장 웹과제 근거가 없다. 1117 강의의 녹화·웹과제 일정 발언은 15·17·18장 대상이다.
