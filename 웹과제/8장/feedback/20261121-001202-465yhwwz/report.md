# 8장 웹과제 등록 후 문제 생성 검토

## 결론과 범위

추가할 만한 연습은 **관찰 결과에서 무엇까지 판정할 수 있는지**다. q06의 표는 교배 방향과 기록이 실제로 있는 단계를 읽어야 한다. q02는 서열 차이를 곧바로 생식적 격리나 종 계통의 확정으로 이어도 되는지 묻는 변형에 적합하다. q04의 RNA 세계는 실제 문항 근거로 허용하는 기존 범위 예외를 쓰면 된다.

응시일 2026-11-12와 14문항은 intake가 기록한 사용자 확인에 근거한다. 완전 검증은 14문항을 통과했다. 캡처 선택 14건의 제출 시점과 공식 답은 미확인이다. bank 전체와 원본 PDF 2·6·7·11쪽을 다시 확인했고 다른 화면은 전사 검증 기록을 참조했다. 1029·1103·1105 복습문제와 예상 v1–v3은 응시 전 Git 기록에 있다. 1103·1105 현재 노트 본문은 11월 14일에 변경됐다. 1103 반감기와 서열 해석은 응시 전 efac144d에도 존재한다. 실제 사용 여부는 미확인이다.

## 학습 가설

캡처 표시 14개가 근거 검토 답과 일치한다. q02의 해석 조건과 공식 채점 미확인을 고려해 개인 숙달이나 취약점을 추정하지 않는다. 단계 기준 적용을 확인하려면 새 교배 사례에서 관찰한 마지막 단계, 수정 여부, 문제가 생긴 세대를 보기 없이 설명하게 할 수 있다. 기존 사례 암기나 보기 소거와 구분하는 질문이며, 이번 검토에서는 실시하지 않았다.
