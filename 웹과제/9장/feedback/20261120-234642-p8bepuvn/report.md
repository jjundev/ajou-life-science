# 9장 웹과제 문항 생성 규칙 재검토

## 결론과 근거 범위

9장에 맞춰 문항의 제시 방식과 배합을 조정할 근거가 있다. 우선 제안은 비교 기준을 기억에서 꺼내는 작은 텍스트 변형이다. 공통 분류 체계와 문항 수를 바꿀 근거는 부족하다.

11월 19일 응시와 전체 14문항은 이 대화에서 사용자가 확인했다. 문제은행의 완전 검증을 다시 실행해 통과했다. 공식 정답과 캡처의 제출 시점, 실제 학습 자료 사용 여부는 미확인이다. 1105·1110 복습팩과 예상 v1–v3은 응시 전에 처음 커밋됐다. 원문 전체와 기존 문항의 14행 대조, 출처별 위치, 경쟁 설명을 포함한 학습 가설은 [기존 전수 대조 보고서](../20261120-231257-5_lx8m8t/report.md)를 근거로 삼았다. 그 보고서 작성 이후 바뀐 블라인드 검사 관련 판단은 아래의 현재 상태를 적용한다.

## 출제와 기존 연습 비교

| 관찰 | 실제 9장 | 비교와 한계 |
|---|---|---|

| 제공 자료 | 그림·표 판독·계산 각각 0/14. q05·q06·q07의 박스는 텍스트다. | 예상 v1–v3은 각 15문항 중 그림 태그 4·3·3개, 표 태그 매번 3개. 기존 카드의 정확도나 학습 효과는 이 차이로 판단할 수 없다. |
| q08 조직/체강 | 해면동물의 조직 부재와 편형동물의 체강 부재를 구분한다. | 1110 노트에는 해면동물과 진정한 조직이 나오고 P8 해설은 체강의 뜻을 다룬다. 두 기준을 한 사례 대비에 배치할 여지가 있다. 편형동물의 무체강 근거는 강의노트 PDF 6쪽이며 강의에서 설명되지 않은 세부 범위는 기존 표시를 따른다. |
| q09 포함 관계 | 도식 없이 좌우대칭동물·양막류·영장류의 포함 방향을 정한다. | 예상 v1 p14는 네 집단을 도식에 매핑하고, v3 p10은 분기도의 묶음을 해석한다. 전자의 이름–도식 매핑도 회상을 요구하지만 제공된 도식에서 출발한다. 노트의 여러 절에 걸친 관계를 이름만으로 이어 붙이는 연습이 조사한 자료에서 가장 덜 직접적이다. |
| q05·q10 식물군 | 관다발·종자·씨방의 조건을 텍스트로 적용한다. | 1110 P21과 예상 v1 p12가 이미 같은 판별 기준을 표로 연습한다. q05 선택은 분석 답과 맞고 q10은 달라, 개인의 선택 이유는 독립 확인 전까지 미확인이다. |
| q04·q07·q14 | 각각 독립 대사계와 개별 효소, 균사를 닮은 외형과 분류 확정, 반응물과 실험 결론의 범위에서 해석이 갈린다. | 생성 문항의 독립 검토 사례로 적합하다. 공식 답과 개인의 오개념을 이 자료로 추정하지 않는다. |

유형 집계는 중복 가능하다. 기출 재사용률, 학습 효과, 다음 회차의 배합은 추정하지 않았다.

## lateral · 설계 전제 뒤집기

| 전제 | 검토한 반대 방향 | 판단 |
|---|---|---|
| 도식으로 포함 관계를 연습하면 충분하다 | 제공 자료를 줄이고 분류 이름에서 연결을 복원한다. | 채택 후보. q09에서 필요한 과정이다. |
| 그림·표를 넣어야 조건을 조합하게 된다 | 텍스트만으로 각각의 조건을 적용하게 한다. | 채택 후보. q05·q06이 직접 보여 준다. 자료 판독 자체가 목표라면 기존 그림과 표는 유효하다. |
| 정답이 일치하면 문항 검토를 통과시킨다 | 같은 답을 골라도 경쟁 보기가 성립하면 이의를 남긴다. | 적용 가치가 있다. 예상문제의 기존 이의 절차와 복습팩 작업 트리의 변경에서 성립하는 방식이다. |
| 실전 느낌을 살리려면 원문의 모호성도 가져온다 | 원문은 비평 자료로 쓰고, 생성 채점 문항에서는 성립 범위를 적는다. | 모호성을 그대로 채점 훈련에 쓰는 방향은 탈락. 검토에서 해석별 판정을 설명하는 데는 쓸 수 있다. |
| 9장 비율을 공통 규칙에 반영한다 | 9장 관찰에 보존하고 같은 장의 다음 설계에서 활용한다. | 전 장 비율 변경은 탈락. 한 회차의 자료로 다른 장의 그림·계산 요구를 판단할 수 없다. |

형식이 바뀌어도 적용해야 할 판별 기준을 고정하면, 기존 설명을 재사용하면서 도식이 제공하던 단계를 학습자가 직접 수행하게 만들 수 있다. 반대로 단서 부족을 재현하면 학습자의 판별 과정과 출제 문구의 결함이 섞인다.

## 변경 우선순위와 확인 기준

| 순서 | 수정 후보 | 확인 기준 |
|---|---|---|
| 1 | `webquiz-observations.md`에 9장 관찰을 추가하고 `webquiz-style.md`의 기존 ‘비교 단위·분류 경계’에 텍스트 포함 관계 사례를 추가한다. `bio-review-pack`의 `variants.md`와 `bio-webquiz-forecast`의 blueprint가 이미 제공하는 칸을 쓴다. | 다음 생성 카드에서 독립 풀이자가 상위 집단, 중간 고리, 하위 집단의 포함 방향을 말하고 역방향 보기를 반례로 배제한다. 설계표의 최소 풀이 단계와 맞는지 확인한다. 새 유형·필드 없이 수행할 수 있다. |
| 2 | 다음 9장 예상의 새 문제 슬롯에서 그림·표 일부를 텍스트 조건으로 대체하는 구성을 시험한다. q08은 근거와 수업 범위를 확인했을 때만 조직/체강 대비에 쓴다. q10은 같은 표를 반복할 우선순위가 낮다. | 표현 전환 전후의 풀이 기준이 같고, 전환 후에는 제공 자료가 미리 보여 주던 관계를 학습자가 복원하는지 비교한다. 새 배합의 이유와 실제 수를 blueprint에 남긴다. |
| 3 | 복습팩의 문항 이의 경로는 해당 변경이 이미 작업 트리에 있다. 예상문제는 기존 이의 절차를 쓰고, 시험 예상은 기존 `content_scope_style`과 독립 풀이에 적용한다. | `test_pack_run.py` 19개가 통과했다. 동일 답에 경쟁 보기 이의를 붙이면 카드 수정 대상으로 전달되는 테스트를 포함한다. 실제 새 카드가 유일 답을 얻는지와 학습 효과는 별도 확인이 필요하다. |

이번 재검토의 변경 파일은 이 보고서다. 기존 작업 트리의 스킬 변경은 재검토 시점 상태로 관찰했다. 분석·제안의 대상은 이후 생성이며 기존 9장 원문과 비교 대상 자료는 그대로 분석 근거로 사용했다.
