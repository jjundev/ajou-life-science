## 1. 핵심 결론과 증거 범위

**현재 자료의 주요 개념 설명은 충분하다. 우선할 일은 설명의 증량보다, 낯선 구조식·다른 명칭에서도 같은 판별 기준을 꺼내는 생성 연습과 모호성의 요약 보존이다.**

- 대상은 `web-20260917-ch01`, 17문항이다. `questions.json`의 전체 문항 수와 원본 화면의 페이지/17, 최고 점수 17 표시가 일치한다. 캡처는 파일명 및 화면의 9월 17일 12:11~12:12 표시로 확인했다. 응시 완료·제출 후 결과 화면은 확인하지 못했다.
- 읽기 검증: `.venv-question-bank/bin/python -B -m scripts.question_bank validate '웹과제/1장/questions.json' --complete` → 종료 코드 0, `Valid: 17 questions (complete)`.
- 전 문항의 `observations.phase`는 `pre_submission`, `official_answer`는 null이다. 분석 답은 17개 모두 `reasoned`이다. **선택 표시·근거를 검토한 분석 답·공식 정답을 구별한다.** 이 보고서는 성적표가 아니다.
- `intake.md`, `note-feedback.md`, `웹과제예상/1장/`은 현재 없다. 누락 입력 때문에 실제 문항 분석을 중단할 상태는 아니지만, 예상 세트의 사전 적중률은 산출할 수 없다. 이번 보고서를 `note-feedback.md`로 자동 취급하지 않는다.
