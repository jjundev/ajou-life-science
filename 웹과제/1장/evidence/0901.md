## §1 생물의 특징

> 강의노트 1.1.1

생명은 한 문장으로 정의하기 어렵습니다. 대신 **무생물과 구분되는 특성들**로 접근합니다.

### §1-1 무엇이 생물인가 — 여덟 가지 특징

| 특징 | 내용 |
|---|---|
| **계층구조** | 세포 → 개체군 → 군집 → 생태계 → 생물권 (§2-1) |
| **화학적 지령** | DNA · RNA · 단백질을 통해 정보를 저장하고 실행함 |
| **물질대사** | 광합성 · 세포호흡 등의 화학 활동 (§1-2) |
| **에너지 이동과 물질 순환** | 태양에너지 → 1차생산자 → 소비자·분해자 → 재순환 |
| **항상성** | 내부 환경을 일정하게 유지 (§1-3) |
| **생식과 발생** | 생식·유전은 **모든 생물**, 발생은 **다세포 생물** |
| **생물학적 진화** | 공통조상의 후손이지만 극적인 다양성을 보임 |
| **분류** | 3영역과 계로 나뉨 (§2-2) |

⚠️ **이 목록에 "세포소기관의 존재"는 없습니다.** 19번 문항이 이 지점을 노립니다. 모든 생물이 **세포**로 이루어진 것은 맞지만, **막으로 둘러싸인 세포소기관은 진핵생물에만 있습니다.** 원핵생물에는 없으므로 생물 전체의 특징이 될 수 없습니다.

⚠️ **공통조상의 근거는 "생김새가 같다"가 아니라 "화학이 같다"입니다.** 세균부터 사람까지 전부 DNA로 정보를 저장하고, 같은 20가지 아미노산으로 단백질을 만들고, 같은 유전암호를 씁니다. 생식 방법이나 세포벽 유무는 생물마다 제각각이라 근거가 되지 못합니다.

📝 **관련 문항**: 2, 19

### §1-2 물질대사와 에너지 흐름

**물질대사**는 세포 안에서 일어나는 화학 활동 전체를 말합니다. 두 방향이 있습니다.

| 방향 | 무엇 | 예 |
|---|---|---|
| **합성** | 작은 것을 이어 큰 것을 만듦 | 고분자 합성, 광합성 |
| **분해** | 큰 것을 잘라 에너지를 얻음 | 세포호흡 |

그 결과 생긴 노폐물은 몸 밖으로 내보냅니다.

⚠️ **물질대사는 물 없이 일어나지 않습니다.** 21번 문항의 함정입니다. 생체 반응은 전부 수용액에서 일어납니다 — 반응에 참여하는 분자들이 물에 녹아야 서로 만날 수 있기 때문입니다. 자세한 이유는 [`0903.md`](0903.md) `§2-2 극성 용매` 를 보세요.

**에너지는 흐르고, 물질은 순환합니다.**

```
  sunlight -> producer -> consumer -> decomposer
                  ^                        |
                  +------------------------+
                     matter recycles
```

에너지는 태양에서 들어와 한 방향으로 흐르며 흩어지지만, 물질(탄소·질소 등)은 분해자를 거쳐 다시 1차생산자에게 돌아갑니다.

📝 **관련 문항**: 21

### §1-3 항상성

**항상성**은 환경 변화를 **탐지**하고, **조절 반응**을 통해 내부 환경을 일정하게 유지하는 능력입니다.

세 단계가 다 있어야 합니다 — 감지 → 판단 → 반응. 체온, 혈당, 체액 농도가 대표적인 조절 대상입니다.

📝 **관련 문항**: 39

## §2 생명의 계층구조와 분류

### §2-1 계층구조

생명은 아래에서 위로 겹겹이 쌓인 구조를 이룹니다.

```
  cell  ->  individual  ->  population  ->  community  ->  ecosystem  ->  biosphere
```

| 단계 | 정의 |
|---|---|
| 세포 | 생명의 기본 단위. 모든 생물은 세포로 구성됨 |
| 개체 | 하나의 생물 |
| **개체군** | **같은 지역에 사는 같은 종의 개체 모임** |
| **군집** | 그 지역 **여러 개체군의 모임** (여러 종) |
| **생태계** | 군집 + **무생물 환경**(빛·물·토양 등) |
| 생물권 | 지구상 생태계 전체 |

⚠️ **개체군과 군집을 가르는 기준은 "종이 하나냐 여럿이냐"입니다.** 16번 문항이 "같은 종류(종)들의 집단"이라고 못 박은 것이 그 힌트입니다. 생태계는 여기에 **무생물까지** 포함한다는 점이 또 하나의 경계입니다.

📝 **관련 문항**: 16

### §2-2 3영역과 4계

먼저 **핵막의 유무**로 크게 둘로 나눕니다.

| 구분 | 영역 (Domain) | 계 (Kingdom) |
|---|---|---|
| **원핵생물** (핵막 없음) | 진정세균 · 고세균 | — |
| **진핵생물** (핵막 있음) | 진핵생물 | 원생생물 · 식물 · 균 · 동물 |

영역은 셋, 계는 넷입니다. 원핵생물 쪽 두 영역이 계로 세분되지 않는다는 점에 주의하세요.
