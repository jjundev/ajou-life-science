# 12장 웹과제 피드백

## 1. 핵심 결론·증거 범위

- Blackboard 평가명은 **12장**이다. 2026-11-26 12:07–12:10 KST에 촬영한 원본 17장에 단일 선택형 16문항·79보기, 최고 16점, 10분 제한과 자동 제출 안내가 있다. s01·s17의 페이지 번호와 intake의 생성 시각 기록을 확인했다. q06의 두 화면 중 s06은 무선택, s07은 B 선택이다. 모든 선택은 제출 전 관찰이다. 최종 제출 답·실제 점수·공식 답은 미확인이다.
- 정본 `questions.json`은 `validate --complete`를 통과했다. 13문항에서 캡처 선택과 분석 답이 일치했고 q06·q09·q15에서 달랐다. q04와 q06은 원문 해석에 유의해야 한다. 이 분류는 채점을 대신하지 않는다.
- 1112·1117 복습팩과 12장 예상 v1–v3의 저장소 기록은 캡처보다 앞선다. 복습팩 최초 기록은 `e1d792b5`(11/12), `78c74f05`(11/17)이고, 예상 세트는 `1a78d8c8`(v1·11/18), `71daae23`(v2·11/24), `beda6618`(v3·11/24)이다. v2 시험형의 형식 수정 `f24a07bf`도 11/24다. 정본 웹과제 등록 `25ec90ba`는 캡처 후다. 1112·1117의 기존 본문 감사표와 장마감은 자료 미작성 상태였으므로, 사전 자료에 실제 피드백 적용 기록이 없었던 것은 당시 입력과 일치한다. 사용자에게 어떤 버전·문항을 풀었는지 확인한 진술은 없다.
- 보강 우선순위는 **변연계 전체를 기능 단서로 회상하기(q15)**, **뇌 단면에서 지시선 끝·구조의 범위를 구분하기(q06)**, **통로 조작 결과를 활동전위의 위치·시간 변화로 설명하기(q13·q16)**다. q09의 지름/수초 분리 비교와 q01·q02·q05·q07·q08·q10·q11·q12·q14의 핵심 판별 설명은 이미 실려 있다. q09는 기존 지름 비교를 먼저 연결하고, 1112 P12·P27의 풀이에서 ‘채널이 결절에만 있다’는 표현을 바로잡는 편이 좋다.

## 2. 사용 자료

아래 경로는 저장소 루트 기준이다. 복습문제·문제설명 P번호는 날짜별로 읽고, 예상문제는 버전별로 읽는다. 해시와 사용 위치는 [근거 인벤토리](#근거-인벤토리)에 있다. 날짜와 평가 상태는 원본 화면과 intake, 생성물의 선행 여부는 Git 커밋 기록으로 확인했다. 채팅의 12장 요청은 분석 범위의 출처다. 선택 근거·학습 이력·공식 결과에 관한 사용자 진술은 이 실행에서 확인하지 않았다.

## 6. 스킬 변경안

### 1순위 · 변연계를 기능에서 이름으로 찾는 연습

- **근거.** q15(s16), 1117 `#s2-limbic`·`#s3-lobes`, 1117 P3·P13·P36과 실제 카드 v1 p14·v2 p10·v3 p12. 기존 문서는 둘 이상의 구성 부위를 설명하고 영어 이름도 병기한다. 교재 p.272의 ‘기능적 신경망’이 신경망과 개별 엽을 구별하는 짧은 정의를 뒷받침한다.
- **현행 규칙과 최소 변경.** `content-rules.md` 「명칭 회상과 비교 단위」와 `note-feedback.md`의 감사 경로가 이미 있다. 다음 1117 본문 보강 시 `#s2-limbic` 정의에 여러 구조의 기능적 신경망이라는 기준을 한 문장으로 정리하고 `#s3-lobes`의 체성감각 역할에 연결한다. 다음 생성판의 `blueprint.md` 「회상·비교 연습」과 p6–p15 중 한 자리에서 기능·구성 예→신경망 이름을 묻는다. 원문의 양육·정서 유대 문장과 보기 배열은 재사용하지 않는다.
- **검증.** 노트 감사표 q15행에 실제 문장·앵커를 기록하고 `check_html.py --manifest … --note … --review …` 뒤 본문 충족도를 검토한다. 예상판은 `check.py --strict` 및 블라인드 검토로 단일 판별, 제목·그림·힌트의 누설, 노트 근거와 새 발문을 점검한다. 공통 원칙은 ‘비교하는 기능·구조의 범위’를 명시하는 것이다. 변연계나 이 카드 개수를 타 장 기준으로 삼지 않는다.

### 1순위 · 뇌 단면의 지시선 끝과 포함 범위

- **근거.** q06(s06/s07), 1117 `#s2-brainstem`·`#s2-thalamus`·`#s7-next`, 장마감 §3, 교재 p.271 그림 12.11·12.12, 강의노트 p.4. 기존 복습 P26 해설의 소뇌 대비는 노트에서 짧은 연결로 재사용할 수 있다. v2 p11·v3 p12는 역할 또는 대뇌 엽 판독을 연습한다.
- **현행 규칙과 최소 변경.** `webquiz-style.md` 「그림」「비교 단위·분류 경계」와 `card-brief.md` 10–15행에 범위·판별·답 누설 규칙이 있다. 향후 1117 `#s2-brainstem` 주변에 강의노트·교재 출처를 붙여 소뇌의 위치와 운동 조정 기능을 짧게 보충한다. 새 그림을 넣는 경우 한 지시선에는 한 구조의 내부를 지정하고, 상위 영역은 별도 테두리·괄호로 표시한다. 뇌교·연수·소뇌와 시상·시상하부 중 보기 판별에 실제 필요한 구조만 그린다. 당시 강의에서 생략된 소뇌는 보충으로 표시한다.
- **검증.** 독립 풀이에서 라벨 끝→구조→기능을 한 줄씩 설명하게 한다. 원본 모호성과 생성 도식의 명료성은 각각 점검하고, 원본 q06의 공식 판정은 보류한다. 원천 그림을 가린 경우 새 문제의 기호를 추측만으로 고를 수 있는지 확인한다. 그림 단독이면 브라우저에서 축소 시 지시선 간격과 선택 위치도 본다.

### 2순위 · 막전위 조작의 출발 상태와 곡선에서 달라지는 결과

- **근거.** q03·q08·q13·q16, 1112 `#s2-action`·`#s1-resting`·`#s1-channel-pump`, P22·P30, v1 p6·v2 p6·v3 p7. 정상 곡선과 채널 역할의 설명은 충분하다. q13은 활동전위 정점 뒤 K⁺ 전류 감소에서 하강 시간을, q16은 휴지 부근 K⁺ 투과성 증가에서 전위 방향을 묻는다.
- **현행 규칙과 최소 변경.** `webquiz-style.md`의 상황 전이 및 비교 단위 규칙으로 충분하다. 다음 1112 본문 점검에서 `#s2-action`의 기존 하강 설명과 `#s1-resting`의 평형전위 설명을 짧은 대비로 연결하거나 다음 12장 변형 한 문항에서 정상 파형 판독에서 통로 조작→하강 시간 예측으로 옮긴다. 새 도식과 질문 방향을 함께 바꾸고 blueprint에 이전 카드·변경 조건·목적을 기록한다. 평형전위 계산 추가나 실제 q13 문구 복제는 필요 없다.
- **검증.** 조작 시점과 달라지는 결과(하강 속도·지속 시간 또는 휴지 부근 전위)가 명시되고, 수업 모형에서 독립 풀이 정답이 하나인지 확인한다. `check.py --strict`는 유형·구조·중복을 확인하며 생리적 타당성은 수업 근거와 독립 풀이로 검토한다.

### 2순위 · 잘 설명된 자료는 연결 위주로 유지

- **q09·q10.** `#s2-conduction`과 v1 p8은 지름/수초의 독립 비교를 이미 충족한다. 이 둘을 먼저 연결한다. 1112 복습문제 P12·P27 풀이(503·1152행) 및 문제설명 P27(1914·1920·1926행)의 ‘결절에만’은 해당 노트 598행과 충돌한다. 다음 해당 자료 갱신에서 해설 문장에 한해 결절의 전압개폐성 통로가 **집중**된다는 표현으로 맞추고, 활동전위의 재생 위치는 결절로 유지한다. 원문 보기와 기존 답은 그대로 두며, 교재 p.265와 노트의 비교 문장을 대조한다. v3 p8의 도식 위치 회상을 재사용할 수 있다. `note-feedback.md` 감사표에는 기존 판별 문장을 인용한다. q09의 개인 가설은 선택지 없는 두 비교를 직접 확인할 때까지 보류한다.
- **q04.** `#s1-protection`과 v2 p9에서 혈액→뇌 이동의 대조는 유지한다. 이후 1117 본문·해설을 손볼 때 뇌 모세혈관 벽 ‘내피세포’와 강의노트 ‘상피세포’ 표기를 출처와 함께 연결하고, 새 보기에서 출발 위치와 도착 위치를 명시한다. 인용 원문과 bank는 그대로 보존한다. 완료 기준은 문장만 읽어도 혈액→뇌 방향의 밀착 구조와 제한을 설명할 수 있는지다.
- **장 관찰.** `webquiz-style.md` §5가 장별 관찰 기록 경로를 이미 지정하고 `webquiz-observations.md`에는 12장 절이 없다. 추후 적용 요청이 오면 §3 관찰(16문항·부정형 5·그림 수록 5/필수 4·계산/필수 표/합답 0)과 q04·q06의 한계만 12장 항목의 후보로 넘긴다. 예상 세트의 표 1–2문항은 생성 목표였다. 실제 표가 0이었다는 사실은 다음 목표를 고를 때 참고이며 공통 의무를 바꿀 근거가 아니다.
