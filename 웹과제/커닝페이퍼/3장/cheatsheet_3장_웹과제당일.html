① 시험장 체크

기출과 다르게 나올 때

  • 보기 번호 말고 단어로 찾는다(보기 순서가 바뀜).
  • 옳지 않은·거리가 먼 발문부터 표시한다.
  • 조건 세 쌍 확인: 유사/감수 · I/II · 상동/자매.
  • "모두·항상·늘"이면 반례부터 찾는다.
  • 그림은 결정 단서부터: 짝을 지었나, 동원체가 갈라졌나.
  • "~하는 시기는?"은 ② 표에서 현상으로 찾는다.
  • "모두 맞다"는 나머지 보기를 하나씩 확인한 뒤에만.

④ 염색체 그림

붙어 있으면 자매, 따로면 상동

  • A와 a = 대립유전자 관계. A, B, C = 서로 다른 유전자.
  • 사람 n = 23: 상염색체 22 + X 또는 Y. 22 + Y는 정자만(난자는 22 + X).

동원체 = 중심절방추사 = 방추체 미세소관
4분염색체 = 4분체 = 2가염색체원발암 유전자 = 원암유전자
발암 유전자 = 암·종양 유전자세포질 분열: 동물 분열홈 / 식물 세포판

⑧ 조절·암

멈추는 것, 미는 것, 막는 것

확인점
다음 단계로 못 가게 멈추는 곳: G1→S, S 끝난 뒤(G2 전), M(방추사 부착)
사이클린
농도가 오르내림. CDK는 양이 일정, 사이클린이 붙어야 작동
외적 조절
성장인자·호르몬. 반드시 수용체에 결합해야 작동
원발암 유전자
정상 촉진 유전자 → 돌연변이 → 발암 유전자: 신호 없이 계속 촉진
종양 억제
억제·수선(p53, BRCA1). 망가지면 암 확률↑
접촉저해
정상세포의 성질. 암세포는 잃음
양성/악성
양성은 제자리 덩어리, 악성은 침투. 전이 = 퍼지는 과정
암 발생
조절에 반응 안 할 때. 돌연변이 여러 개 누적
⑨ 함정

자주 나오는 틀린 문장

함정 ✗ 감수 I과 II 사이에 DNA가 복제된다. ✓ 감수 I과 II 사이에는 DNA 복제가 없다. ✗ 제2감수분열에서 염색체 수가 반으로 준다. ✓ 제1감수분열에서 반으로 준다(II는 그대로). ✗ 재조합은 후기 I("제1감수분열의 초기")에 일어난다. ✓ 재조합은 전기 I에 일어난다. ✗ 2n=4이면 생식세포 조합은 16가지다. ✓ 쌍이 2개라 2² = 4가지다. ✗ 한 사람의 정자는 모두 유전적으로 같다. ✓ 한 사람의 정자도 유전적으로 서로 다르다. ✗ 접촉저해는 암세포의 특성이다. ✓ 접촉저해는 정상세포의 특성이다.
