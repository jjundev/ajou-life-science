③ ATP

ATP 구조와 에너지가 나오는 순간

  • 인산기 하나가 떨어질 때 음전하끼리의 반발이 줄어 에너지 방출
  • 쓰는 곳: 동화 반응(작은 것 → 큰 것), 능동수송(저농도 → 고농도), 근육 수축, 발광
  • 리보스라서 RNA 뉴클레오타이드에 인산기 3개가 붙은 모양
함정 ✗ 아데노신과 아데닌은 같은 것이다. ✓ 아데노신 = 아데닌 + 리보스. ✗ ATP는 인산기를 얻을 때 에너지를 낸다. ✓ 인산기를 잃고 ADP가 될 때 에너지가 나온다. ✗ 물질이 이동하면 늘 ATP가 든다. ✓ 확산(고농도 → 저농도)은 에너지가 필요 없다. 능동수송만 필요.
