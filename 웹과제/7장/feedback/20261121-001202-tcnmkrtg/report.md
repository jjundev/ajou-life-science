# 7장 웹과제 등록 후 문제 생성 검토

## 결론과 범위

추가할 만한 연습은 **같은 사례에서 관찰한 증거와 그 사례에서 가능한 진화 기작을 구별하기**다. q07·q11·q12가 근거다. 하디–바인베르크 계산은 이미 여러 연습에서 다룬다. 다음 7장 예상은 짧은 기본 계산을 두고, 겹치는 복합 계산 슬롯 일부를 증거와 기작 또는 텍스트 선택 양상에 배정할 수 있다.

응시일 2026-11-12와 13문항은 intake가 기록한 사용자 확인에 근거한다. 완전 검증은 13문항을 통과했다. 캡처 선택 13건의 제출 시점과 공식 답은 미확인이다. bank 전체와 원본 4·5·9·10·11쪽을 다시 확인했고 다른 화면은 전사 검증 기록을 참조했다. 1027·1029 복습문제는 10월 27일·29일, 예상 v1·v2·v3 설계는 11월 3일·3일·10일 Git 기록에 있다. 실제 사용 여부는 미확인이다.

## 학습 가설

q11의 화면 선택은 B(창시자 효과), 근거 검토 답은 D(생물지리학적 증거)다. 고립 단서를 보고 기작을 먼저 떠올렸거나, 질문의 끝을 건너뛰었거나, 최종 제출 전 선택일 수 있다. 새 사례에서 관찰 자료의 종류를 먼저 설명하게 하고 소수 정착 기록을 더 주었을 때 어떤 기작을 검토할 수 있는지 물으면 구분할 수 있다. 모두 미확인이다. 문구 해석이 갈리는 q01·q02·q08·q09는 오개념 근거로 쓰지 않았다.
