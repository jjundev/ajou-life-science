# 0915 독립 재풀이 검산

공식 정답·풀이·해설을 제공받지 않은 상태에서 p1–p40을 다시 풀었다. 저작자와 분리된 내용 검산이며 개인 능력 진단이 아니다. 입력은 `blind-0915/questions.md`, 그 안의 p36·p37 SVG, 허용된 0915·0910 정리노트, 강의노트 2장 PDF, 교과서 02장 PDF로 제한했다. 문제은행, 기존 복습문제·문제설명, manifest, fragments, key-check, variants는 읽지 않았다.

근거 약칭: **강의 pN**은 `강의노트/2장 세포호흡과 광합성.pdf`의 PDF 쪽(1–5)이다. **0915/0910 + 토픽명**은 허용된 HTML 정리노트의 해당 토픽이다. **교재 pN**은 `교과서/생명과학_기초와_응용_2판/02장_세포호흡과_광합성.pdf`의 인쇄 쪽이다. 교재 p49–51은 실제 페이지 렌더를 확인했다. p36·p37 SVG도 실제 래스터 렌더로 경로·위치·라벨을 확인했다. 추출 SVG에는 외부 CSS가 없어 그대로 렌더하면 도형이 검게 메워졌다. 따라서 파일을 수정하지 않고 메모리 안에서 선·텍스트 스타일만 보완해 원래 좌표와 라벨을 읽었다. HTML의 inline SVG에 의존해야 하는 문항은 없었다.
