2. 세포호흡과 광합성
    (너무 세세한 암기보다는 전체적인 원리 - ‘전자의 흐름 순서’ - 위주로)

2.1 에너지, 효소
2.1.1 에너지, 생명 그리고 열역학 법칙

Ÿ 에너지는 다른 형태와 상태로 존재한다
- 운동에너지(kinetic energy) : 파동, 전자, 원자, 분자 기질, 물체와 같은 움직임의 에너지
(전기에너지, 복사 에너지, 열에너지, 소리와 움직임의 에너지)
- 퍼텐셜(위치)에너지(Potential energy): 움직이지 않는 위치 또는 원자가 특별하게 배열되어
있을 때 나타나는 저장된 에너지 (화학에너지, 핵에너지, 중력 에너지, 저장된 역학에너지)
Ÿ 살아있는 생명체에서 에너지 전환 : 생명체는 당 분자를 분해해서 위치에너지를 운동에
   너지로 전환
Ÿ 이화작용(catabolic reaction) :당과 같은 복합체 분자를 분해
Ÿ 동화작용 (anabolic reaction) : 간단한 기질을 복합체 분자로 조립하기 위해 에너지
   필요 (예: 광합성, 아미노산을 단백질로 합성)
Ÿ
Ÿ 세포는 발열반응과 흡열반응을 짝지우기 위해 ATP를 사용한다
Ÿ ATP의 형성과 가수분해는 생물학적 반응에서 가장 중요하다
Ÿ ATP 가수분해에 의해 구동되는 세포 반응의 예 : 동화반응, 단백질 활성, 용질 수송


2.1.2 생물학적 반응에서 효소의 역할

Ÿ 효소(Enzymes)
- 생물학적 반응을 촉진시키는 촉매로 단백질로 구성
- 반응의 속도는 106 ~1012 배 더 빨라진다
- ase로 끝나는 이름을 갖는다. 예, 단백질 분해효소: Protease

Ÿ  활성화 에너지(Activation energy) - 반응을 시작하기 위하여 초기에 필요한 에너지
Ÿ  효소는 활성화 에너지를 감소시킴으로써 반응을 가속시킨다
Ÿ  효소는 반응물과 결합한 후 변하지 않은 채로 분리된다
Ÿ  기질 : 효소가 촉매하는 특정한 반응 분자나 분자 그룹
Ÿ  활성부위 : 기질분자와 결합, 또 기질분자를 인지하는 효소 부위
Ÿ  효소 특이성 : 단일 유형의 분자반응이나 밀접하게 관계된 분자반응을 촉진시키는 특성
Ÿ  효소 보조인자 (Enzyme cofactors) - 많은 효소들이 촉매반응을 위하여 반드시 필요로
   하는 무기물 혹은 단백질이 아닌 유기물질
- 무기보조 인자들: Mg, Zn, Mn, K, Cu, Fe 등의 금속성 이온들
- 비타민 등의 유기보조 인자들: 조효소(coenzyme).

Ÿ 효소는 특정 온도나 pH에서 최고의 활성을 갖는다
- 일반적으로 최적온도는 40℃~50℃ (역동적인 운동이 가장 크지만 효소의 풀림이 일어나지
않은 온도 )
- 효소의 활성에 최적 pH가 존재하는데, 대부분이 pH 6~8 범위임

2.2 화학에너지의 수확: 세포호흡
    2.2.1 에너지, 생명 그리고 열역학 법칙
Ÿ 광합성에 의하여 획득한 에너지는 식물 자신과 동물, 다른 생물에 의해 ATP 생성에 사용
- 이때 산화-환원 반응에 의한 전자의 흐름에 의하여 에너지를 공급받는다
Ÿ 짝지어진 산화-환원 반응은 에너지 대사에서 전자의 흐름을 만든다

Ÿ    산화(Oxidation) - 어떤 물질로부터 전자를 제거하는 것
Ÿ    환원(Reduction) - 어떤 물질에 전자가 첨가되는 것

Ÿ    전자는 연료물질로부터 최종 전자수용체로 흐른다
Ÿ    광합성(Photosynthesis) - 태양 에너지를 수집하여 복잡한 유기분자의 화학에너지로 전환
     시키는 과정
Ÿ    세포호흡(Cellular respiration) - 유기분자로부터 산소로 전자를 전달하는 반응과 ATP를
     만드는 반응을 포함

Ÿ 세포호흡의 3단계
1. 해당과정(Glycolysis)
2. 피루브산 산화와 시트르산 회로
3. 전자 전달계와 산화적 인산화



2.2.2 해당과정
Ÿ    해당과정의 반응은 에너지 요구 단계와 에너지 방출 단계를 포함한다

Ÿ    해당과정: 포도당 + 2 ADP + 2 Pi + 2 NAD+
            → 2 피루브산 + 2 NADH + 2 H+ + 2 ATP

- 에너지 요구반응: 2분자의 ATP가 가수분해되어 포도당이 불안정한 인산화 유도체로 전환
- 에너지 방출반응: 4ATP가 생성
   → 2ATP가 얻어진다

Ÿ    전자운반체 : NAD+ (Nicotinamide adenine dinucleotide)
Ÿ    기질수준 인산화(Substrate-level phosphorylation): 기질의 인산기를 ADP로 옮겨 ATP를
     생성하는 효소 촉매 반응

2.2.3 피루브산 산화와 시트르산 회로

Ÿ 피루브산 산화(Pyruvate oxidation)
- 피루브산이 세포액에서 미토콘드리아 기질로 이동
- 피루브산의 COO- 가 CO2 로 제거되고, 아세틸기는 CoA로 옮겨져 아세틸-CoA가 되어 시
트르산 회로에 주입
- 이때 방출된 2개의 전자는 NAD+ 가 받아들여 NADH가 됨

Ÿ 시트르산 회로는 아세틸기를 CO2로 완전히 산화시킨다
Ÿ 시트르산 회로(Citric acid cycle)
1 acetyl-CoA + 3 NAD+ + 1 FAD + 1 ADP + 1 Pi + 2 H2O
          → 2 CO2 + 3 NADH + 1 FADH2 + 1 ATP + 3 H+ + 1 CoA

Ÿ    탄수화물, 지질, 단백질은 산화과정의 전자공급원으로 작용한다

    2.2.4 전자전달계와 산화적 인산화
Ÿ 전자전달계에서 전자는 미토콘드리아 내막의 단백질 복합체들을 통해서 흐른다
전자는 NADH와 FADH2 로부터 전자전달계에 주입
- 전자가 전자전달계를 통하여 순차적으로 흘러 최종적으로 산소(O2)에 전달

Ÿ 유비퀴논과 복합체 I, 복합체Ⅲ, 복합체Ⅳ
- 전자흐름에 의하여 생긴 에너지를 이용하여 양성자(H+)를 기질에서 미토콘드리아 내막을
가로질러 수송

Ÿ 양성자 구동력(Proton-motive force)
- 전자전달에 의하여 미토콘드리아 기질과 막간 구획에 사이에 양성자의 농도기울기에 의하
여 내막을 경계로 전기화학적 농도 차이를 만든다

Ÿ 화학삼투설 (Chemiosmotic hypothesis) - 1961년 Peter Mitchell(영국) :
전자전달계가 H+ 농도기울기를 발생시키고, 이것이 ATP 합성효소에 의하여 ATP 합성을 위
한 에너지를 제공한다는 가설

Ÿ 산화적 인산화(Oxidative phosphorylation)
- 막 사이 구획의 양성자가 ATP 합성효소를 통하여 농도기울기를 따라 기질 안으로 이동
- 이러한 양성자의 흐름은 ATP 합성을 위한 에너지로 이용되어 ADP에 Pi를 첨가시켜 ATP
를 합성

Ÿ    포도당이 이산화탄소와 물로 완전히 산화되면서 32개의 ATP 분자를 만든다

Ÿ  세포호흡은 포도당의 화학에너지 중 30% 이상을 ATP에 보존한다
 세포의 포도당 산화 효율 = 34%. (자동차 에너지 효율: 약 25%)
- 이때 ATP 형태로 포획되지 않은 화학 에너지는 열로 방출되어 체온 유지에 이용



2.2.5 발효
Ÿ    발효는 산소가 부족할 때 ATP 생산이 유지되도록 한다
Ÿ    발효 (Fermentation) - 해당과정 중에 생성된 NADH가 전자전달계로 유입되는 것이 아
     니라 유기물질을 환원시킨다

 젖산발효
- 해당과정에서 생성된 NADH를 이용하여 피루브산을 젖산으로 환원시킨다
- 산소가 부족할 경우 동물근육 세포, 젖산균

Ÿ 알코올 발효
- 효모 (Saccharomyces cerevisiae) 등의 미생물에서 일어난다
- CO2 가 생성되고, NADH가 NAD+ 로 산화되면서 에탄올 생성
- 맥주, 포도주, 빵의 제조




2.3 광 합 성
    2.3.1 광합성의 개관

Ÿ 광합성 생물
- 1차 생산자 ; 빛 에너지를 화학에너지로 전환하여 복잡한 유기분자에 저장
- 독립영양생물(Autotroph) ; CO2 로부터 필요한 유기분자를 만드는 생물
- 광독립영양생물(Photoautotroph) ; 에너지원으로 빛을 사용하는 독립영양생물
- 종속영양생물(Heterotroph) : 생존을 위하여 유기분자를 필요로 하는 소비자와 분해자

Ÿ    전자는 광합성에서 핵심역할을 한다

Ÿ 광합성의 두 단계 반응
1. 광 의존 반응 - 빛 에너지를 흡수하여 ATP와 NADPH 형태의 화학에너지로 전환
2. 광 독립 반응 - ATP와 NADPH를 이용한 CO2 고정반응으로, 전자와 H+ 가 CO2에
  첨가되는 환원 반응에 의하여 (CH2O)n의 탄수화물이 생성

Ÿ    진핵생물에서 광합성은 엽록체에서 일어난다
Ÿ    기공(Stoma) - CO2 가 들어오고 O2가 밖으로 나가는 장소
Ÿ    광 의존반응(명반응) - 색소, 전자운반 전달체, ATP 합성효소가 있는 틸라코이드 막과
     스트로마 라멜라에서 일어난다
Ÿ    광 독립반응(암반응) - 스트로마에서 일어난다

Ÿ 엽록체의 구조
- 외막: 엽록체의 표면을 완전히 감싸고 있는 것
- 내막: 외막 바로 밑에 위치함
- 스트로마(Stroma): 내막 안의 유동액 부위
- 그라나(Grana): 틸라코이드 다발
- 스트로마 라멜라(lamellae): 틸라코이드 내강을 연결하는 공간

2.3.2 광합성의 광 의존반응

Ÿ    광의존반응(Light-dependent reaction) - 빛의 흡수과정, NADPH 및 ATP 생성과정
Ÿ    광합성 중에 빛에너지는 색소분자의 전자에 의해 흡수된다

Ÿ 엽록소(Chlorophyll)와 카로티노이드(carotenoid)
- 광합성 과정 중에 빛을 흡수하며, 틸라코이드 막에 묻혀있다
- 이때 엽록소가 초록색 계열의 빛을 반사하기 때문에 초록색으로 보인다
- 흡수 스펙트럼(Absorption spectrum): 각 파장에서 흡수된 빛의 양을 곡선으로 나타낸 것
- 작용 스펙트럼(Action spectrum) ; 각 파장이 광합성에 관여하는 정도를 나타내는 그림

Ÿ  광합성 색소는 엽록체의 광계로 조직화되어 있다
 광계(Photosystem)
- 빛을 흡수하는 색소분자들과 단백질이 다른 분자들과 함께 뭉쳐 있는 집합체
- 광계는 안테나 복합체와 반응중심으로 구성

안테나 복합체(Antenna complex): 빛 수확 복합체로서 많은 색소 분자가 존재

Ÿ 광자 형태의 빛 에너지의 흐름
- 안테나 복합체의 색소분자에 흡수 - 빛 에너지가 유도공명에 의하여 반응중심의 엽록소에
도달 - 전자가 전자전달계로 이동

Ÿ     물로부터 광계를 거쳐 NADP+로 이르는 전자의 흐름은 NADPH와 ATP 합성이 일어나게
      한다
    - 전자는 전자전달계를 따라 흐르면서 H+ 농도기울기를 생성
 - 전자는 마지막 전자 수용체인 NADP+에 전달되어 NADPH를 생성
- 양성자(H+ )가 틸라코이드 내강에서 스트로마로 농도기울기를 따라 흐르면서 ATP 합성
  효소에 의하여 ADP와 Pi로부터 ATP를 합성.
- 이를 광인산화라 한다



2.3.3 광합성의 광독립반응

캘빈회로(Calvin cycle) - NADPH와 ATP를 이용하여 CO2 를 고정하는 반응
- 엽록체의 스트로마에서 일어난다

Ÿ     캘빈회로는 NADPH, ATP, CO2를 사용하여 탄수화물을 생성한다
Ÿ     캘빈회로의 반응단계
    - 1단계: 탄소고정(CO2 fixation)
      : 5탄당인 RuBP에 CO2가 첨가되어 2분자의 3-인산글리세르산(3PGA) 생성
    - 2단계: 환원(Reduction)과 당 생성 : NADPH와 ATP를 이용하여 -3PGA를 G3P로 전환
          2분자의 G3P가 6탄당인 포도당을 만들기 위해 사용
    - 재생(Regeneration) 단계: RuBP를 다시 생성

Ÿ    캘빈회로가 6번 순환하면 포도당과 같은 6탄당 1 분자가 생성



2.3.4 광호흡과 C4 회로


Ÿ 광호흡(Photorespiration)
- 루비스코(Rubisco)의 활성부위에 O2가 결합하면 카복실화효소               대신에   산소화효소
(Oxygenase)로 작용 -> 독성물질 생성, 식물 생장 저해

Ÿ    높은 온도 조건 - 기공이 닫히면 잎에서 산소가 축적되고 CO2 농도는 감소 - 따라서 광
     호흡속도가 증가 - 쌀, 보리, 밀, 콩. 토마토, 감자 심각한 피해

Ÿ    C4 회로는 산소화효소 활성이 없는 카복실화효소를 사용함으로서 광호흡을 극복한다
