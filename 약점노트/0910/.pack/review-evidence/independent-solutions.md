## p16 — 3번

펌프는 기질→막간, 합성효소 경유 귀환은 막간→기질이다.

- 1번: 퍼냄: 막 사이 공간에서 기질 / 귀환: 기질에서 막 사이 공간 → 불성립. 퍼냄과 귀환 방향이 모두 반대다.
- 2번: 퍼냄과 귀환 모두 ATP 합성효소가 맡는다. → 불성립. 퍼냄은 ETC 펌프가, 귀환은 ATP synthase가 맡는다.
- 3번: 퍼냄: 기질에서 막 사이 공간 / 귀환: ATP 합성효소를 거쳐 기질로 → 성립. 두 방향과 귀환 통로가 정상 호흡 모형과 일치한다.
- 4번: 귀환은 인지질 이중층을 단백질 없이 자유롭게 지난다. → 불성립. H+는 하전 이온이라 소수성 지질층을 자유 통과하지 못한다.

유일성: 이 조건에서 하나. 출처: 기존 정리노트 s5-atp-synthase. 새 노트 충분성: 대기.

## p17 — 2번

단기·펌프지속·누출무시 조건에서 막간 H+축적→pH하강→기질과 차이증가이다.

- 1번: H⁺가 줄고 pH가 올라간다. → 불성립. 막간 H+가 늘어야 하며 pH는 내려가므로 두 방향이 반대다.
- 2번: H⁺가 늘고 pH가 내려가며 기질과의 pH 차이가 커진다. → 성립. H+축적과 pH역관계·기질과의 차이를 모두 맞췄다.
- 3번: H⁺가 늘고 pH도 올라간다. → 불성립. H+와 pH는 함께 증가하지 않는다.
- 4번: H⁺가 기질과 즉시 같은 농도가 된다. → 불성립. 귀환이 막혀 있고 누출도 무시하므로 즉시 평형화하지 않는다.

유일성: 이 조건에서 하나. 출처: 기존 정리노트 s5-atp-synthase. 새 노트 충분성: 대기.

## p18 — 1번

직접 약물 표적은 ATP synthase H+통로이며 ETC에는 이후 간접 역압 영향이 가능하다.

- 1번: 산화적 ATP 합성은 바로 억제되며 전자전달계 단백질을 직접 막은 것과는 구별한다. → 성립. ATP 합성이 억제되는 직접 결과와 ETC 직접차단의 구별이 맞다.
- 2번: 전자전달계의 모든 H⁺ 펌프가 약물에 직접 막혔다. → 불성립. 약물 직접 표적을 ETC 펌프 전체로 바꾸어 주장했다.
- 3번: 전자전달은 어떤 시간이 지나도 반드시 정상 속도로 유지된다. → 불성립. 통로 차단 뒤 기울기 증가가 ETC를 느리게 할 수 있어 영구 정상속도 보장은 없다.
- 4번: ATP 합성효소를 막아도 산화적 ATP 합성은 같은 속도로 유지된다. → 불성립. 합성에 필요한 H+ 흐름을 막았으므로 같은 속도 합성이 유지되지 않는다.

유일성: 이 조건에서 하나. 출처: 기존 정리노트 s5-etc,s5-atp-synthase. 새 노트 충분성: 대기.


p17은 단기·펌프 지속·누출 무시 조건이 분명해 ECT의 장기 억제 반론으로 중복 정답이 생기지 않는다. 막간 pH 자체는 하강하고 pH 차이는 증가한다.
