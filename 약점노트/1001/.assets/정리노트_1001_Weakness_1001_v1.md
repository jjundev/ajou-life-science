## 1. 점액 배출의 인과

<a id="s0-mucus"></a>

### 점액은 없어진 걸까, 못 움직이는 걸까

*1001 공부 · 4장 p8 · 교재 p78*

**쉽게 말하면**

물기 적은 끈끈한 막은 작은 털로 밀어내기 어려워요. 먼지를 붙잡아도 밖으로 못 보내면 그 자리에 쌓여요.

![물기 감소 / 점액 끈끈 / 이동 저하](figures_1001/fig-s0-mucus.svg)

*각 상태의 차이를 순서대로 비교해요.*

**정확히 말하면**

공부 기록에서는 가래를 만들지 못하는 것인지, 밖으로 내보내지 못하는 것인지 막혔어요. 기도의 **점액(mucus)**은 먼지와 미생물을 붙잡고, **섬모(cilia)**는 점액을 목 쪽으로 이동시켜 배출을 도와요.

1. 수업의 기도 모형에서 염소 이온 채널 기능이 저하되면 기도 표면으로의 이온 이동과 이에 따르는 물 이동이 줄어요.
2. 표면 점액의 물기가 줄어 지나치게 끈끈해져요.
3. 섬모가 점액을 옮기기 어려워져 점액과 이물질이 축적돼요.

작은 사례: 먼지를 잡은 점액이 있어도 이동이 잘 되지 않으면, 먼지 제거는 끝난 것이 아니에요. 낭포성 섬유증은 이 과정으로 이해해요.

[기존 노트의 관련 설명](../../../복습노트/1001/정리노트_1001_Chromosome_Changes_and_DNA_Replication.html#s2-recessive-disease)

**꼭 기억해요**

점액을 전혀 만들지 못한다는 설명과 구별해요. 강의노트 4장 p8의 염소 이온 과다 배출 문구는 수업 전사 및 기존 정리노트와 충돌해요. 여기서는 수업 전사의 채널 기능 저하 설명을 따라요. 교재 인쇄 p78은 염소 이온 채널을 통한 수송 결함과 점액 축적을 확인해요.

**페이지 요약**

물기 감소 / 점액 끈끈 / 이동 저하. 점액은 없어진 걸까, 못 움직이는 걸까를 재확인해요.

## 2. 재료와 복제 산물

<a id="s1-bases"></a>

### T와 U는 이름까지 연결하기

*1001 공부 · 5장 p1 · 교재 p101*

**쉽게 말하면**

서로 비슷한 두 글자판은 글자 하나가 달라요. 어느 판을 쓰는지 정한 뒤 이름을 붙여요.

![DNA: T / RNA: U / 공통: A G C](figures_1001/fig-s1-bases.svg)

*서로 다른 비교 대상을 나란히 놓아요.*

**정확히 말하면**

공부 중 T의 이름을 잠시 찾았고, 뒤에서 RNA의 네 염기를 바르게 말했어요. **타이민(thymine, T)**은 DNA의 보통 염기, **우라실(uracil, U)**은 RNA에서 T 대신 사용하는 염기예요. DNA는 A·T·G·C, RNA는 A·U·G·C예요.

RNA 프라이머도 RNA이므로 주형 DNA의 A 맞은편에는 U가 와요. 반대로 DNA를 새로 합성할 때 주형 A 맞은편에는 T가 와요. A·G는 퓨린, C·T·U는 피리미딘이에요.

[기존 노트의 관련 설명](../../../복습노트/1001/정리노트_1001_Chromosome_Changes_and_DNA_Replication.html#s3-dna-structure)

**꼭 기억해요**

이름이 잠시 안 떠오른 사실을 염기 전체의 오개념으로 확대하지 않아요. T라는 글자를 보면 타이민과 DNA, 우라실이라는 이름을 보면 U와 RNA를 함께 떠올려요.

**페이지 요약**

DNA: T / RNA: U / 공통: A G C. T와 U는 이름까지 연결하기를 재확인해요.

<a id="s1-density"></a>

### 옛것과 새것이 함께 있다는 말의 단위

*1001 공부 · 5장 p1 · 교재 p96–97*

**쉽게 말하면**

두 줄짜리 끈을 벌려 한 줄마다 새 줄을 붙여요. 두 번 반복하면 묶음마다 남은 옛 줄 수가 달라져요.

![처음 HH / 1회 HL HL / 2회 HL HL LL LL](figures_1001/fig-s1-density.svg)

*각 상태의 차이를 순서대로 비교해요.*

**정확히 말하면**

기록은 옛것과 새것이 함께 있다는 데까지 설명했지만, 띠를 분자별 가닥 구성으로 구별하는 과정은 확인되지 않았어요. 이를 확정 오답으로 세지 않고 재확인해요. **반보존적 복제**는 딸 DNA 한 분자마다 바로 직전 부모 분자의 가닥 하나와 새 가닥 하나가 짝이 되는 방식이에요.

그림의 H는 무거운 ¹⁵N 가닥, L은 가벼운 ¹⁴N 가닥을 뜻해요.

처음 ¹⁵N/¹⁵N DNA 한 분자를 ¹⁴N 배지에서 복제해요. 한 번 뒤에는 ¹⁵N/¹⁴N 두 분자라 모두 중간 밀도예요. 두 번 뒤에는 ¹⁵N/¹⁴N 두 분자와 ¹⁴N/¹⁴N 두 분자라 중간 밀도와 가벼운 밀도가 절반씩이에요.

보존적 모형이라면 첫 복제 뒤 무거운 분자와 가벼운 분자가 따로 나와요. 분산적 모형도 첫 복제에서 중간 띠를 예측하므로, 첫 세대만으로 반보존적 모형을 유일하게 결정하지 않아요. 두 번째 세대의 두 띠가 추가 구별 기준이에요.

[기존 노트의 관련 설명](../../../복습노트/1001/정리노트_1001_Chromosome_Changes_and_DNA_Replication.html#s4-meselson-stahl)

**꼭 기억해요**

배지에 ¹⁴N이 있다고 옛 ¹⁵N 가닥이 즉시 ¹⁴N으로 바뀌지는 않아요. 남는 단위는 부모 이중가닥 분자 전체가 아니라 각 가닥이에요.

**페이지 요약**

처음 HH / 1회 HL HL / 2회 HL HL LL LL. 옛것과 새것이 함께 있다는 말의 단위를 재확인해요.

## 3. 복제 시작부터 봉합까지

<a id="s2-origin"></a>

### 시작 위치와 움직이는 경계 구별하기

*1001 공부 · 5장 p2 · 교재 p98–99*

**쉽게 말하면**

처음 문을 연 자리는 그대로예요. 더 넓게 열면서 양옆의 경계는 멀어져요.

![위치: 원점 / 경계: 분기점 / 분자: 프라이머](figures_1001/fig-s2-origin.svg)

*서로 다른 비교 대상을 나란히 놓아요.*

**정확히 말하면**

공부 중 복제원점은 시작점이고 분기점은 움직이는 경계라고 고쳐 말했어요. 다만 뒤에서 프라이머를 만드는 시작점을 원점이라고 부르며 다시 연결했으므로 두 의미를 재확인해요.

**복제원점(origin)**은 DNA 복제가 시작되는 DNA상의 위치이고, **복제분기점(fork)**은 주형 두 가닥이 벌어지는 Y자 경계예요. 양방향 복제의 한 원점에서는 두 분기점이 반대쪽으로 진행할 수 있어요.

RNA 프라이머는 합성을 시작할 3′-OH를 제공하는 짧은 분자예요. 지연가닥에서 분기점이 열릴 때마다 새 프라이머를 놓아도, 그때마다 새로운 복제원점이 생기는 것은 아니에요.

[기존 노트의 관련 설명](../../../복습노트/1001/정리노트_1001_Chromosome_Changes_and_DNA_Replication.html#s5-replication-machinery)

**꼭 기억해요**

복제의 시작 위치와 조각 합성의 시작 재료를 구별해요. 원점은 위치, 분기점은 경계, 프라이머는 분자예요. 정정 경로는 기록만으로 확인되지 않았어요.

**페이지 요약**

위치: 원점 / 경계: 분기점 / 분자: 프라이머. 시작 위치와 움직이는 경계 구별하기를 재확인해요.

<a id="s2-extension"></a>

### 5′에서 3′으로 자란다는 말 풀어 보기

*1001 공부 · 5장 p1–2 · 교재 p97–98*

**쉽게 말하면**

줄의 끝에 새 조각을 하나 붙이면 끝도 한 칸 옮겨 가요. 다음 조각은 새로 생긴 끝에 붙어요.

![기존 3′-OH / 새 재료 / 새 3′-OH](figures_1001/fig-s2-extension.svg)

*각 상태의 차이를 순서대로 비교해요.*

**정확히 말하면**

원래 20번에서 주형 읽기 방향은 바르게 말했지만, 새 뉴클레오타이드가 3′-OH에 붙는 문장에서 망설였어요. 뒤에서 수긍한 사실은 인정하되 현재 독립 적용 성공으로 세지 않아요.

DNA 중합효소는 **기존 새 가닥의 3′-OH**와 들어오는 dNTP의 5′ 쪽 인산을 연결해요. 들어온 뉴클레오타이드의 3′-OH가 다음 연장의 끝이 돼요. 따라서 새 가닥은 **5′→3′**으로 늘고, 주형은 역평행이므로 **3′→5′**으로 읽혀요.

작은 사례: 5′-AC-3′에 G 하나가 붙으면 5′-ACG-3′이 돼요. 기존 C의 3′ 끝에 G가 붙고, 다음 끝은 G의 3′-OH예요. 필요한 상보성은 주형 염기가 결정해요.

선도·지연가닥의 각 조각 모두 같은 연장 규칙을 따라요. 지연가닥은 분기점 반대쪽으로 조각을 만들지만 3′→5′으로 합성되는 것은 아니에요.

[기존 노트의 관련 설명](../../../복습노트/1001/정리노트_1001_Chromosome_Changes_and_DNA_Replication.html#s5-replication-machinery)

**꼭 기억해요**

원래 20번은 인쇄 답 (1)과 교재의 3′-OH 원리가 충돌하는 자료예요. 기존 문제설명에 오류가 공개되어 있어요. 망설임을 인쇄 답을 따른 오답으로 단정하지 않아요.

**페이지 요약**

기존 3′-OH / 새 재료 / 새 3′-OH. 5′에서 3′으로 자란다는 말 풀어 보기를 재확인해요.

<a id="s2-enzymes"></a>

### 시작·연장·교체·봉합을 나누기

*1001 공부 · 5장 p2 · 교재 p98–100*

**쉽게 말하면**

임시 시작 조각에서 길게 잇고, 임시 조각을 바른 재료로 바꿔요. 재료가 다 있어도 연결이 끊긴 곳은 따로 이어야 해요.

![시작 / 연장 / 교체 / 닉 연결](figures_1001/fig-s2-enzymes.svg)

*각 상태의 차이를 순서대로 비교해요.*

**정확히 말하면**

기록에서는 DNA 중합효소 I·III, 프라이메이스의 정체와 닉을 다시 확인했어요. 뒤에서 역할을 정정했지만 해설·모형 참고 여부가 불명확하므로 짧은 재확인을 해요.

| 대상 | 역할 |
|---|---|
| 헬리케이스 | 두 주형 가닥을 벌려요. |
| 프라이메이스(primase) | RNA 프라이머를 만드는 효소예요. |
| DNA 중합효소 III | 수업의 대장균 모형에서 새 DNA를 주로 연장해요. |
| DNA 중합효소 I | 같은 모형에서 RNA 프라이머를 제거하고 DNA로 교체해요. |
| DNA 연결효소(ligase) | 닉의 당-인산 골격 결합을 만들어요. |

선도가닥의 시작 RNA 프라이머도 최종 DNA에 그대로 남는 것이 아니에요. 선도·지연 모두 프라이머는 교체 대상이에요. 여기서는 수업의 세균 복제 모형을 사용하며, 선형 진핵 염색체 끝 처리의 세부를 같은 표로 설명하지 않아요.

**닉(nick)**은 염기가 다 채워져 있어도 이웃 뉴클레오타이드 사이 골격의 인산다이에스테르 결합 하나가 빠진 상태예요. 염기 자체가 빠진 빈자리를 채우는 일과 닉을 잇는 일을 구별해요.

[기존 노트의 관련 설명](../../../복습노트/1001/정리노트_1001_Chromosome_Changes_and_DNA_Replication.html#s5-finishing)

**꼭 기억해요**

프라이머는 RNA 분자, 프라이메이스는 이를 만드는 효소예요. I과 III의 번호별 분담은 수업의 원핵세포 모형이며 모든 생물의 공통 효소 번호가 아니에요. 연결효소는 염기를 골라 새 가닥을 길게 만드는 효소가 아니에요.

**페이지 요약**

시작 / 연장 / 교체 / 닉 연결. 시작·연장·교체·봉합을 나누기를 재확인해요.

## 4. 발현과 사슬의 단위

<a id="s3-expression"></a>

### 복제와 발현은 산물로 구별하기

*1001 공부 · 5장 p3 · 교재 p101*

**쉽게 말하면**

책 전체를 복사하는 일과 필요한 부분을 옮겨 읽는 일은 달라요. 무엇이 새로 만들어졌는지부터 확인해요.

![복제: DNA / 전사: RNA / 번역: 사슬](figures_1001/fig-s3-expression.svg)

*각 상태의 차이를 순서대로 비교해요.*

**정확히 말하면**

기록에서는 DNA 복제와 RNA 사본 만들기가 따로인지 질문했고, 문제를 읽으며 DNA 합성은 복제라고 고쳐 말했어요. 유전자 문제에서는 단백질이라는 단어만 고르는 요령도 말했으므로, 산물과 관계를 확인하는 기준으로 바꿔요.

| 과정 | 정보원과 직접 산물 |
|---|---|
| DNA 복제 | DNA를 주형으로 DNA를 만들어요. 분열 준비에서는 유전체 전체를 복사해요. |
| 전사(transcription) | 해당 DNA 영역 한 가닥을 주형으로 RNA를 만들어요. |
| 번역(translation) | mRNA 정보를 읽어 아미노산을 이은 폴리펩티드를 만들어요. |

복제와 발현은 서로 다른 과정이에요. 특정 유전자가 발현될 때마다 DNA 전체를 먼저 복제해야 하는 것은 아니에요. 단백질 암호화 유전자의 정보는 아미노산을 어떤 순서로 이을지를 지정해요.

[기존 노트의 관련 설명](../../../복습노트/1001/정리노트_1001_Chromosome_Changes_and_DNA_Replication.html#s7-expression)

**꼭 기억해요**

단백질이라는 단어가 들어 있다고 모두 맞는 설명은 아니에요. 예를 들어 단백질을 DNA 뉴클레오타이드로 만든다는 문장은 재료가 틀려요. 기능성 RNA를 산물로 하는 유전자도 있으므로 모든 유전자가 단백질을 만든다고 일반화하지 않아요.

**페이지 요약**

복제: DNA / 전사: RNA / 번역: 사슬. 복제와 발현은 산물로 구별하기를 재확인해요.

<a id="s3-chain"></a>

### 사슬 하나와 단백질 한 분자 구별하기

*1001 공부 · 5장 p3 · 기존 노트 s7-gene-concept*

**쉽게 말하면**

한 줄짜리 부품만으로 작동하는 것도 있고 여러 줄을 모아 쓰는 것도 있어요. 같은 줄을 여러 개 쓴다고 설명서 종류가 늘지는 않아요.

![사슬 수: 4 / 사슬 종류: 2](figures_1001/fig-s3-chain.svg)

*서로 다른 비교 대상을 나란히 놓아요.*

**정확히 말하면**

기록의 폴리펩티드 여러 개가 단백질을 이룬다는 말을, 여러 사슬이 반드시 필요하다는 뜻으로 고정하지 않도록 재확인해요. 이를 확정 오답으로 세지는 않아요.

**폴리펩티드(polypeptide)**는 아미노산 한 사슬이고, 기능하는 **단백질(protein)**은 사슬 하나 또는 여러 개로 이루어질 수 있어요. 수업의 헤모글로빈 모형은 α 사슬 두 개와 β 사슬 두 개로, 사슬은 네 개지만 사슬 종류는 두 가지예요.

수업의 1유전자 1폴리펩티드 역사적 모형에서 α와 β는 서로 다른 유전자 정보에 대응해요. 같은 종류의 사슬 두 개는 같은 종류의 정보를 여러 번 사용해 만들 수 있어요. 이 비교는 사슬 수와 종류를 구별하기 위한 것이며 실제 α글로빈 유전자 사본 수를 계산하는 문제가 아니에요.

[기존 노트의 관련 설명](../../../복습노트/1001/정리노트_1001_Chromosome_Changes_and_DNA_Replication.html#s7-gene-concept)

**꼭 기억해요**

각 사슬을 별도 유전자로 본다는 말을 물리적인 사슬 개수만큼 서로 다른 유전자 종류가 필요하다는 뜻으로 읽지 않아요. 모든 단백질에 여러 사슬이 필요한 것도 아니에요.

**페이지 요약**

사슬 수: 4 / 사슬 종류: 2. 사슬 하나와 단백질 한 분자 구별하기를 재확인해요.
