# 1장 웹과제 분석과 정리노트 생성 방식 개선안

분석일: 2026-09-17. 대상: `웹과제/1장/raw/`의 스크린샷 19장에 담긴 17문항.

이 문서는 시험 복기와 생성 방식의 **제안**이다. 기존 정리노트, 생성 규칙, 스킬, 퀴즈 엔진은 수정하지 않았다.

## 1. 결론

기존 정리노트에는 17문항의 핵심 주제와 상당수 정답 근거가 이미 있다. 가장 큰 개선점은 설명의 양을 늘리는 것이 아니라, **배운 개념을 낯선 보기·그림·사례에서 구별하는 훈련**을 생성 과정에 넣는 것이다.

특히 다음 네 가지가 필요하다.

1. 개념의 정의뿐 아니라 **포함되는 것과 제외되는 것**을 나란히 설명한다.
2. 분자와 세포 그림을 보고 **판별 근거를 찾아 이름을 붙이는 문제**를 만든다.
3. 기출 정답뿐 아니라 **모든 보기의 참·거짓과 틀린 부분의 수정**을 검토한다.
4. 회차별 기록 위에 **장 전체를 다시 묶는 시험 대비 과정**을 둔다.

단, 모든 문제를 노트 탓으로 돌릴 수는 없다. 17번의 핵양체와 9번의 아미노산 기본구조는 원천 MD에 있다. 실제 선택까지 이어지지 않은 원인은 이해, 회상, 그림 해석, 시간 압박 등 여러 가능성이 있으므로 선택 기록만으로 단정하지 않는다.

STT 전체 회차와 모든 ELI5 화면을 완전 감사한 것은 아니다. ELI5 점검은 내용 소스 확인이며 실제 화면 사용성 검증은 포함하지 않는다. 0901은 STT 없는 결석 재구성 노트다.

스크린샷은 **제출 전 응시 화면**이다. 초록색 원과 ‘선택함’은 사용자가 고른 보기이며 정답이나 채점 결과가 아니다. 이후 답 변경과 최종 점수는 확인되지 않는다. 아래의 ‘판정 답’은 자료에 근거한 분석자의 판단이며 공식 정답표가 아니다.

교재 쪽수는 이 문서에서 **인쇄 쪽수**를 쓰고 필요할 때 분할 PDF 쪽수를 병기한다. 이 교재 파일에서는 확인한 구간의 인쇄 쪽수 = 분할 PDF 쪽수 + 1이다.

## 5. 문항별 보기 감사와 생성 방식에 주는 교훈

### Q1. 원자핵은 무엇으로 구성되는가

- A 중성자와 양성자: 출제 의도상 정답.
- B 양성자, C 중성자: 일반적인 원자핵 구성 설명으로는 각각 불충분하다.
- D 전자와 양성자, E 전자: 전자를 핵의 구성원으로 넣은 것이 틀리다.
- 근거: 강의노트 p.1, 0903 §1-1의 원자 구조식. 보통의 수소 원자핵처럼 중성자가 없는 예외를 ‘모든 원자핵’이라는 절대명제로 확대하지 않는다.
- 개선: 핵/전자, 양성자/중성자/전자, 원자번호/질량수의 판별표. 원래 답의 번호를 외우지 않도록 보기 순서 변경.

### Q2. 내막계에 속하지 않는 것은 무엇인가

- A 원형질막: 내막계에 포함된다. ‘세포 겉면에 있으니 내막계가 아니다’는 이름에 끌린 오개념이다.
- B 골지복합체, C 소낭, D 소포체: 내막계 구성원이다.
- E 리보솜: 정답. 단백질 합성에 참여하지만 막 구조가 아니다.
- 근거: 0908 STT 46:40–48:05에서 핵막·소포체·골지체·세포막·소낭을 묶고 리소좀의 포함 이유도 설명한다. 0908 §5-2에도 세포막 포함이 있다.
- 실제 노트 위험: 0908 ‘30초 요약’은 내막계 항목에 `리보솜 → 조면소포체 → 골지체 → 소낭 → 세포막`을 적었다. 이것은 단백질 분비 경로로는 이해할 수 있지만 **내막계의 구성원 목록으로 읽으면 리보솜을 포함시키게 된다.**
- 개선: ‘내막계의 구성원’과 ‘분비 단백질이 거치는 경로’를 별도 행으로 둔다. 경로에 참여한다는 것과 그 계의 구성원이라는 것을 구별한다.

### Q3. 물의 특성과 관계가 먼 설명

- A 얼음의 밀도가 낮아 뜸: 맞다.
- B 작은 기화열: 틀린 핵심 단어다. 물은 기화열이 크며, 증발할 때 열을 가져가 냉각에 기여한다.
- C 응집력·표면장력: 맞는 방향의 설명이다.
- D 극성 물질을 녹이는 용매: 맞는 설명이다.
- E 분자 사이 결합력과 큰 비열: 수소결합과 연결한 설명이다.
- 근거: 강의노트 p.2, 0903 §2. 기화열과 비열 설명은 충분하다. 표면장력은 MD에서 응집력과 같은 수준으로 독립 설명하지 않아 보강 여지가 있다.
- 개선: ‘높은 비열→온도 변화 완화’, ‘높은 기화열→증발 냉각’을 나란히 둔다. 오답을 보고 **작은→큰**으로 고치는 연습을 붙인다.

### Q4. 미토콘드리아와 엽록체의 공통 특징

- A 고대 원핵생물에서 유래: 강의의 세포내공생설에 부합한다.
- B 세포에서 독립적으로 성장하고 수를 늘림: 출제 문맥에서는 기존 소기관의 성장·분열, 즉 반자율성을 가리키는 것으로 해석된다.
- C 세포내막계의 일부분: 판정 답. 막이 있다는 사실과 내막계 소속은 다르다.
- D 자체 리보솜과 원형 DNA: 수업에서 제시한 세포내공생의 근거다.
- E 이중막: 강의노트 p.5–6과 일치한다.
- 근거: 0908 §5-3, 0910 도입부와 §1-1. 0910 STT 00분대에서 자체 DNA·리보솜 및 스스로 분열한다는 설명을 확인했다.
- 표현 주의: B를 ‘숙주 세포 밖에서 완전히 독립생활 가능’으로 읽으면 과도하다. 공식 정답·채점은 없으므로 그 해석 여지를 감추지 않는다. 학습 문장은 **자체 DNA·리보솜과 분열 능력이 있으나 숙주에 의존하는 반자율적 소기관**으로 쓰는 것이 낫다.
- 개선: 내막계/비내막계, 막 유무/막 개수, 자체 DNA/리보솜, 분열 능력을 한 비교표에 넣는다. ‘이중막이라서 내막계’라는 추론을 차단한다.

### Q5. 리소좀을 연구하기 가장 좋은 세포

- E 식균작용을 하는 백혈구: 섭취한 물질의 소화가 활발하므로 가장 적합하다.
- A 근육세포·C 산소 부족 근육세포: 에너지 대사 조건에 눈길을 돌리는 보기다. 리소좀의 대표 기능을 직접 보여주는 선택지는 E다.
- B 세균: 전형적인 막성 리소좀을 가진 진핵세포가 아니다.
- D 식물 잎세포: 강의에서는 식물의 액포와 동물의 리소좀 역할을 대비한다.
- 근거: 0908 §5-2는 백혈구가 삼킨 세균과 리소좀이 만나는 사례를 직접 설명한다. 교재 p.20도 식세포 사례를 제시한다.
- 개선: `소기관→기능`에 더해 `기능이 특히 많이 필요한 세포→소기관`으로 거꾸로 묻는다. 근육에 리소좀이 전혀 없다는 식으로 오답을 설명하면 안 된다.

### Q6. 미지 물질 ‘가생이’를 살아 있는 세포로 판단하는 조건

- a 막으로 둘러싸인 내부 환경, b 유전물질과 증식 능력, c 물질대사: 이 문항에서 묻는 세포의 기본 조건이다.
- d 핵막: 원핵세포도 있으므로 공통 필수 조건이 아니다.
- 조합 A(b,c,d)는 d 포함·a 누락, B(a,b,c)는 정답, C(a,b)는 c 누락, D(c,d)는 d 포함·a,b 누락이다.
- 근거: 0901 §1과 0908 §4, 강의노트 p.1·5.
- 개선: 조합 보기를 먼저 보지 않고 a–d 각각을 판단하게 한다. 질문의 대상이 ‘생물 일반’, ‘전형적 세포’, ‘진핵세포’ 중 무엇인지 명시한다. 개별 분화세포까지 모두 스스로 증식한다는 절대명제로 확장하지 않는다.

### Q7. 세포소기관 설명 중 옳지 않은 것

- A 활면소포체의 지질 합성: 맞다.
- B 핵공으로 염색체가 자유롭게 드나듦: 틀리다. 핵공의 물질 이동과 염색체를 혼동한 것이다.

### Q8. 소수성 아미노산이 접힌 단백질 어디에 있을까

- 근거: 0908 §4에는 제시된 네 구조가 모두 같은 표에 있다. 강의노트 p.5와 교재 p.17 그림 1.19에도 함께 나온다.

- 개선: ‘결정적 단서’와 ‘공통으로 존재해 구별에 약한 단서’를 나눈다. 후보를 고른 뒤 **나머지 조건과 충돌하는가**를 확인하는 연습을 붙인다.

## 6. 현재 생성 방식의 구체적인 개선 지점

### 6.1 한 문항의 정답 근거에서 모든 보기의 판별 근거로

현재 `정리노트/CLAUDE.md` §11은 why를 필수로 두지만 trap은 ‘고를 법한 오답’에만 달도록 한다. 기존 취지인 오개념 방어는 좋다. 다만 실제 웹과제에는 참인 설명 여러 개 중 한 개만 틀리게 만든 문제가 많다.

제안: **작성·검토 데이터에서는 모든 보기를 감사**한다. 각 보기에 참/거짓, 근거 위치, 거짓이면 최소 수정 문장을 기록한다. 화면에는 핵심 설명을 먼저 보여주고 나머지는 펼쳐 읽게 해 길이를 조절한다. 모든 해설을 본문에 중복 저장할 필요는 없다.

Q14처럼 ‘정답 B를 고를 수 있다’와 ‘A·C·D·E도 근거로 설명할 수 있다’를 별개의 검사로 둔다.

### 6.2 30초 요약에도 정확성 검토 적용

현재 0908 내막계 요약은 경로와 분류가 겹친다. 본문이 정확해도 시험 직전에 읽는 요약이 다르게 해석되면 실전에서는 취약하다.

제안 형식:

| 개념 | 빠른 판별 | 혼동 방지 |
|---|---|---|
| 내막계 | 핵막·소포체·골지체·소낭·리소좀·세포막 등의 연결 체계 | 리보솜은 단백질을 만들지만 구성 막은 아님; 미토콘드리아·엽록체도 제외 |
| 원핵세포 | 핵양체, 핵막 없음 | 세포벽만으로 식물이라고 판정하지 않음 |
| 아미노산 | 중앙 C에 아미노기·카복실기·H·R | 이온형이나 회전된 그림도 같은 뼈대 |
| 기화열 | 액체→기체에서 열 흡수 | 비열과 구분, ‘작은 기화열’ 반박 |

이는 수정안 예시이며 기존 요약을 이 문서에서 실제로 교체한 것은 아니다.

### 6.3 ‘개념이 있음’과 ‘보기가 바뀌어도 풀림’을 분리

기존 테스트 생성기는 문항 번호 집합, 필수 필드, 참조 절, 회차 경계 등을 확인한다. 그런 검사는 유지할 가치가 있지만 이해·추론을 검사하지는 못한다.

이미 study-note-eli5에는 원문 범위 고정, 사실 단위 연결, 그림 근거, 해설을 가린 풀이 검토라는 좋은 계약이 있다. 이를 새로 별도 체계로 중복 구현하기보다 **원천 노트와 실제 웹과제까지 연결**하는 방향을 권한다.

검사를 세 층으로 구별한다.

1. 구조 검사: 문항·그림·보기 누락, 출처, 링크, 답과 본문 분리.
2. 의미 검사: 노트의 보이는 설명만으로 정답 선택과 모든 보기의 판별이 가능한가.
3. 학습 확인: 사용자가 실제로 풀고, 이유를 설명할 수 있는가. 작성자의 자체 판정이나 자동 테스트 통과로 대체하지 않는다.

ELI5가 쉬운 말로 바꿀 때도 ‘핵양체’, ‘아미노기’처럼 문제를 가르는 원어를 남겨야 한다. 현재 0903·0908 자료가 최신 계약의 모든 검사를 통과한다고 이번 조사에서 확인한 것은 아니다.

### 6.4 강의 발언의 중요도와 시험 대비 우선순위를 따로 기록

현재 절차는 교수님이 반복·강조한 함정을 모으고, ‘8개 미만이면 STT를 제대로 읽지 않은 것’이라는 수량 기준도 둔다. 반면 시험에는 짧게 언급된 분류나 그림 판독도 나온다.

제안: 고정 함정 개수 대신 **이번 범위의 혼동 관계가 근거와 함께 검토되었는가**를 본다. 교수 강조 횟수, 과거 출제, 실제 웹과제 출제, 그림 판별 필요를 각각 별도 근거로 기록한다. 강조가 많다는 사실만으로 다음 출제를 확정하지 않는다.

### 6.5 미강의 상태와 시험 필요도를 분리

현재 본문을 실제 회차 진도에 맞추는 원칙은 유지한다. 그러나 `아직 강의하지 않음`, `명시적으로 생략함`, `앞으로 다룰 예정`은 다른 상태다.

예를 들어 1강 32·40의 막수송은 0910에서 ‘수송은 생략’이라고 했는데 이후 회차 대기로 남아 있다. 이번 17문항에는 직접적인 막수송 문제가 없었으므로 이번 오선택 원인으로 세지 않는다. 다만 앞으로 장이 끝날 때에도 무기한 대기시키면 대비 범위가 불분명해진다.

제안: 장 마감 시 남은 항목을 `시험 범위 확인됨 / 보충 학습 권장 / 제외 근거 있음 / 범위 불명`으로 다시 검토한다. 노트에 못 넣는 내용은 출처를 붙인 보충으로 처리하며, 생략을 자동으로 시험 제외로 바꾸지 않는다.

현재 §3의 보충 정의도 ‘STT에 없다’에서 곧바로 ‘강의노트에도 없고 교과서에만 있다’고 이어진다. 실제 출처를 확인해 **STT 없음·강의노트 있음**, **교재에만 있음**, **외부 참고**를 구분하는 편이 정확하다.

## 7. 권장 생성 절차

### 회차마다

1. STT와 강의노트에서 실제 진도와 모든 주요 사실을 확인한다.
2. 각 개념에 정의·기전·조건 외에 **혼동 대상·포함/제외·역질문**을 검토한다. 개념과 무관한 형식은 억지로 채우지 않는다.
3. 화학구조·소기관·과정처럼 그림이 본질적인 개념은 그림 목록에 올린다. 정답 이름을 가린 상태에서 어떤 특징으로 판별할지 적는다.
4. 과거 문항과 실제 웹과제 원문을 원래 보기·순서·그림과 함께 보존한다. 출처가 다른 같은 번호는 다른 ID로 둔다. 예: `past-ch1-q18`, `web-20260917-ch1-q01`.
5. 관련 문항의 모든 보기를 판별하고, 해설에서만 필요한 사실이 드러나면 학습 본문 또는 보충으로 올린다.
6. 각 핵심 혼동 묶음에 작은 변형 문제를 붙인다. 명칭 바꾸기, 참/거짓 뒤집기, 사례 바꾸기, 그림 표현 바꾸기 중 필요한 형태를 선택한다. 생성 문제는 원문과 구별해 표시한다.
7. 30초 요약을 별도로 역검토한다. 긴 본문의 조건을 떨어뜨리지 않았는지, 기능 경로를 구성원 목록으로 바꾸지 않았는지 확인한다.

### 한 장을 마쳤을 때

1. 여러 회차의 1장 부분만 모아 **장 단위 개념 목록**을 만든다. 0910처럼 두 장이 섞인 회차도 1장 부분을 빠뜨리지 않는다.
2. 분류표와 그림 판별 문제를 묶는다. 회차 MD의 본문을 복제하기보다 원천 절로 연결하고 통합 비교·응용에 집중한다.
3. 실제 시험에 맞춘 혼합 연습을 제공한다. 이번 사례를 기준으로는 17문항·11분 모의를 만들 수 있지만 다음 시험의 설정이 확인되면 그 값에 맞춘다.
4. 정답 표시 없는 상태에서 먼저 풀이한다. 틀렸거나 확신 없는 문항은 시간 제한 없이 근거를 말해 보게 해 회상 부족과 설명 부족을 구별한다.
5. 틀린 문항은 개념 이름으로만 기록하지 말고 `분류 경계 / 결정 단서 누락 / 그림 판독 / 조건 변화 / 부정형 독해 / 시간` 같은 원인 후보를 남긴다. 확인되지 않은 원인은 추정으로 둔다.

### 웹과제 직후

이번처럼 원본→선택→분석 답→근거→기존 노트의 충분성→새 변형 한 개를 연결해 복기한다. 이미 풀어본 실제 문항은 수정 후 새 문제 대비력을 평가하는 독립 시험으로 쓸 수 없으므로, **아직 보지 않은 변형 문제**도 따로 검토한다.

## 8. 2장에 적용할 수 있는 예시

아래는 출제 예측이나 실제 기출이 아니라 **생성 방식의 예시**다. 0910·0915에서 다룬 공간·물질·방향 관계를 이용한다.

| 혼동 묶음 | 학습 본문에 필요한 대비 | 변형 질문 예시 |
|---|---|---|
| 전자전달계 / ATP 합성효소 | 전자는 에너지를 제공하고, H+ 기울기를 먼저 만든 뒤 ATP 합성으로 연결 | ‘전자전달계가 ADP에 인산을 직접 붙인다’를 고쳐 설명하기 |
| 기질 / 막간공간 | H+를 퍼내는 방향과 돌아오는 방향 구별 | 그림의 안팎 표기를 바꾸어도 펌프·귀환 화살표를 그릴 수 있는가 |
| 비순환 전자 흐름 / 캘빈 회로 | 틸라코이드 막 / 스트로마, 입력·출력·운반체 | ATP·NADPH를 만드는 단계와 쓰는 단계를 서로 바꾼 보기 판별 |
| 산소 / 이산화탄소 | 각각 관여하는 과정과 역할 구별 | 이름이 아니라 전자수용체·탄소 공급원이라는 역할로 선택 |
| 효소 / 기질 / 활성화에너지 | 반응 속도와 평형·에너지 차이 구별 | ‘효소가 생성물의 최종 에너지를 낮춘다’의 틀린 부분 수정 |

실제 문제로 만들 때는 적용 조건과 강의 범위를 다시 확인하고, 정답·오답 보기 모두 출처에 연결한다.

## 9. 세 가지 선택지와 추천

| 방식 | 장점 | 한계 |
|---|---|---|
| 최소 보완 | 0908 내막계 요약, 핵양체 판별, 아미노산 그림, 소수성 배치를 먼저 보강 | 이번 약점은 해결하지만 다음 장에 같은 문제가 반복될 수 있음 |
| **회차 노트 + 장 마감 검토** | 현재 회차 기록을 유지하면서 비교·그림·변형·실전 확인을 추가 | 장 종료 시 한 번 더 검토해야 함 |
| 파이프라인 전체 재설계 | 모든 출처와 문제를 체계적으로 관리 가능 | 한 번의 시험을 근거로 시작하기에는 변경 범위가 큼 |

추천은 **두 번째 방식**이다. 먼저 첫 번째의 구체적 보완점을 규칙의 예시로 삼아 적용하고, 2장 웹과제 이후 실제 효과를 다시 평가한다.

제안하는 변경 위치:

- `정리노트/CLAUDE.md`: 모든 보기 감사, 조건·제외·그림 판별, 요약 정확성, 출처별 보충 분류라는 내용 규칙.
- `.agents/skills/summary-note/SKILL.md`: 원문 보존→보기 감사→변형 문제→장 마감 검토 순서. `.claude` 쪽 진입점과 연결 상태도 확인해 중복 규칙을 만들지 않음.
- `정리노트/_template.html`: 실제 적용 단계에서 원문/변형 표시, 근거 펼치기, 필요하면 제한시간 연습을 검토. 현재 엔진 수정 금지 규칙이 있으므로 별도 변경 범위로 명시.
- `scripts/new_note_test.py`: 실제 웹과제 출처 ID·그림·보기 수 등 구조 검사 확장. 의미 검토를 단순 키워드 테스트로 대체하지 않음.
- `study-note-eli5`: 기존 사실·문항·그림·해설 없는 풀이 계약을 재사용하고, 시험 판별 용어가 쉬운 설명에서 빠지지 않도록 점검.

성공 기준은 노트가 더 길어지거나 테스트 수가 늘어나는 것이 아니다. **사용자가 해설 없이 낯선 보기를 판별하고, 어떤 단서 때문에 그 답인지 설명할 수 있는가**다.
