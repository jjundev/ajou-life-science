`정리노트/CLAUDE.md` 전문:

```markdown
# 정리노트 작성 규칙

이 디렉터리의 회차 노트를 만들거나 고칠 때 반드시 따른다.

## 1. 파일 = 강의 회차

- 파일명은 `MMDD.md` / `MMDD.html`. 날짜 하나가 강의 한 회차다.
- 강의는 주 2회(화·목). 여러 회차가 모여 교재 한 장(章)을 이룬다.
- **본문에는 그 회차에 실제로 강의한 것만 쓴다.** 다음 회차 내용을 당겨오지 않는다.

## 2. 경계 처리

강의가 개념 중간에서 끊기면 그 자리에 이음매 블록을 둔다. 내용은 쓰지 않고 이름만 예고한다.

> ✂️ **여기서 강의가 끊겼습니다** — "(교수님의 마지막 발언 인용)"
> 다음: (다음에 나올 항목 나열) · `MMDD.md`

직전 회차를 교수님이 도입부에 복습하면 문서 앞쪽에 거울상 블록을 둔다.

> ## ⏪ 지난 회차 복습 (교수님이 도입부에 짚은 것)
> (요점 3~5줄) · 원 강의: `MMDD` · 📝 관련 문항 N, N

## 3. 무엇을 본문에 넣는가 — STT 기준

- 해당 회차 STT에 **한 번이라도 언급**된 개념 → 본문.
- STT에 **전혀 없는데 문제에는 나오는** 개념 → 문서 맨 끝 `## 📎 강의 밖 보충 — 문제 대비용` 섹션.
- 보충 섹션에는 반드시 경고를 단다: 교수님이 강의하지 않았고 강의노트에도 없으며 교과서에만 있다는 것.

이 기준이 필요한 이유: 강의노트 PDF는 목차 뼈대일 뿐이다. 전기음성도·옥텟·pH 같은 것이 15개 강의노트 전체에 한 번도 안 나온다. 강의노트만 믿으면 안 되고, STT가 주 자료다.

## 4. 밀도

각 개념은 다음을 갖춘다. 한 줄 요약체는 금지한다(그건 강의노트가 이미 하고 있다).

- 정의와 **성립 조건**
- **인과** — 왜 그렇게 되는가
- `⚠️` **오개념 방어** ← 이 노트의 존재 이유
- `> 💡 **교수님**` 인용 — 비유·암기법
- `📝 **관련 문항**: N, N`

`⚠️` 블록의 재료는 STT에서 교수님이 **반복했거나, 되물었거나, "헷갈린다"고 말한 지점**이다. 노트를 쓰기 전에 STT를 훑어 이것부터 전수 수집한다.

문서 맨 위에는 `## ⏱ 30초 요약` 표를 둔다. 시험 직전에 이것만 본다.

## 5. 교수님 잡담

개념에 걸린 것만 남기고 나머지는 버린다. 판별 기준은 "이 비유를 지우면 개념 이해가 나빠지는가"다.

## 6. md와 html의 분업 — 중복 0

| | `MMDD.md` | `MMDD.html` |
|---|---|---|
| 30초 요약·본문·✂️·📎·매핑표 | ✅ 유일 원천 | ❌ |
| **정답 + 근거 + 오답 진단** | ❌ | ✅ 유일 원천 |
| **구조 시각화 (토글·슬라이더)** | ❌ | ✅ |
| ASCII 다이어그램 | ✅ 보조 | ❌ |

- md 매핑표는 **문항 번호 / 무엇을 묻는가 / 노트 절 / 함정 여부**까지만. 정답을 쓰지 않는다. 접어두는 것으로도 부족하다 — 스크롤하다 펼치면 끝이다.
- html은 본문을 복사하지 않는다. 해설에서 `→ MMDD.md §N-N 참조`로 넘긴다.
- 이 규칙이 무너지면 두 파일이 서로 다른 말을 하기 시작하고, 노트는 자산이 아니라 부채가 된다. `tests/test_note_MMDD.py`가 기계로 막는다.

## 7. HTML 제약

- `file://`로 여는 로컬 파일이다. **외부 `fetch()`는 CORS로 차단된다.** 문항 데이터를 별도 JSON으로 뺄 수 없다 — `<script>` 안에 인라인한다.
- 외부 CDN·빌드 도구 금지. 이미지 파일 참조 금지 — 그래픽은 인라인 SVG로 직접 그린다.
- 교과서 스캔본 crop 금지(저작권 + 토글 불가). SVG로 그리면 저작권 문제가 없고 인터랙션도 된다.
- 재사용 형태는 "엔진 + 데이터 분리"가 아니라 **"파일 복사 후 상단 데이터 블록만 교체"**다.

## 8. ASCII 다이어그램과 기호

- 코드블록 **안에는 영문·기호·숫자만** 쓴다. 한글은 폰트마다 폭이 달라 정렬이 깨진다. 한글 설명은 코드블록 바깥 줄로 뺀다.
- **md 전체에서 원문자(①~⑤, ➀~➄)를 쓰지 않는다.** 목록 번호는 `(1) (2) (3)`. 정답이 새는 형태는 반드시 보기 기호를 동반하므로, 원문자를 통째로 금지하는 것이 가장 싼 유출 방지 장치다. 테스트가 강제한다.

## 9. git

`정리노트/`, `tests/`, `docs/plans/` 만 add 한다. `교과서/`는 절대 add 하지 않는다 — `.gitignore`의 `교과서/장별/` 규칙이 폴더명 변경으로 죽어 있어 197MB가 딸려 들어간다.
```

```python
def _read(path):
    with open(path, encoding="utf-8") as f:
        return f.read()


def _body(md):
    """본문 영역만 잘라낸다.

    ✂️ 이음매 · 📎 보충 · 부록 매핑표는 본문이 아니다. 이 세 섹션에는
    다음 회차 개념이 이름으로 등장하는 것이 정상이므로 경계 검사에서 제외한다.
    문서를 뒤에서부터 짓는 도중(매핑표만 있고 본문이 없는 상태)에도
    올바르게 빈 본문을 돌려준다.
    """
    idxs = [md.find(m) for m in ("## ✂️", "## 📎", "## 부록") if md.find(m) >= 0]
    return md[:min(idxs)] if idxs else md


class TestNoteMarkdown(unittest.TestCase):
    """0903.md 가 본문 SSOT 역할과 회차 경계 규칙을 지키는지 검증"""

    @classmethod
    def setUpClass(cls):
        if not os.path.isfile(MD_PATH):
            raise unittest.SkipTest("정리노트/0903.md 가 아직 없습니다.")

    def test_mapping_table_has_40_rows(self):

        nums = {int(m) for m in re.findall(r"^\|\s*(\d+)\s*\|", self.md, re.M)}
        self.assertEqual(nums, set(range(1, 41)))

    def test_no_answers_in_markdown(self):
        """정답은 html 전용 — md에 보기 기호가 나타나면 분업 규칙 위반

        '정답은 0903.html 에 있습니다' 같은 안내 문구는 필요하므로 '정답'이라는
        단어 자체는 막지 않는다. 대신 원문자(①~⑤, ➀~➄)를 md에서 전면 금지한다.
        정답이 새는 형태는 반드시 보기 기호를 동반하므로 이것으로 충분히 잡힌다.

class TestCrossReferences(unittest.TestCase):
    """두 파일 사이 참조 정합성"""

    @classmethod
    def setUpClass(cls):
        if not (os.path.isfile(MD_PATH) and os.path.isfile(HTML_PATH)):
            raise unittest.SkipTest("두 파일이 모두 있어야 검증할 수 있습니다.")
        cls.md = _read(MD_PATH)
        cls.html = _read(HTML_PATH)

    def test_html_refs_point_to_real_md_sections(self):
        """html의 ref 문자열이 md에 실제로 존재하는 절인지"""
        refs = set(re.findall(r'ref:\s*"([^"]+)"', self.html))
        for ref in refs:
            if ref.startswith("📎"):
                continue
            self.assertIn(ref, self.md, f"html의 ref '{ref}' 가 md에 없습니다")

    def test_html_does_not_duplicate_body_text(self):
        """html이 본문을 복사하지 않았는지 — 본문 장문 문장이 html에 나타나면 위반"""

        long_lines = [ln.strip() for ln in body.splitlines()
                      if len(ln.strip()) >= 40 and not ln.strip().startswith(("|", "#", ">", "-", "`"))]
        for line in long_lines:
            self.assertNotIn(line, self.html,
                             f"html이 md 본문을 복사했습니다: {line[:40]}...")
```

```javascript
/* ── 시각화 1: α/β 포도당 ── */
let isBeta = false;
function drawGlucose(){

    : "<b>α-포도당</b> — OH가 고리 <b>아래</b>. α-1,4 결합으로 이어지면 <b>녹말</b>(식물 저장)이나 "
      + "<b>글리코겐</b>(동물 저장)이 됩니다. 아밀레이스가 이 결합을 끊어 엿당으로 만듭니다.";

/* ── 시각화 2: 포화/불포화 ── */
function chainPoints(nDouble){
  const nC = 18, seg = 14, kinkAt = [5, 9, 13].slice(0, nDouble);
  let x = 18, y = 55, dir = 0;
  const pts = [[x, y]];
  for (let i = 1; i <= nC; i++){
    if (kinkAt.includes(i)) dir += 28;
    const a = (dir + (i % 2 ? -12 : 12)) * Math.PI / 180;
    x += seg * Math.cos(a); y += seg * Math.sin(a);
    pts.push([x, y]);
  }
  return pts.map(p => p.map(v => v.toFixed(1)).join(",")).join(" ");
}
function drawFat(){
  const n = +$("#dbl").value;
  $("#chain").setAttribute("points", chainPoints(n));
  const phase = n === 0 ? "상온에서 <b>고체</b> — 지방(버터·동물성)"
              : n === 1 ? "꺾이기 시작합니다 — 중간"
              : "상온에서 <b>액체</b> — 기름(올리브유·식물성)";
  $("#fatInfo").innerHTML =
    `이중결합 <b>${n}개</b> · ${n === 0 ? "<b>포화</b>지방산" : "<b>불포화</b>지방산"}<br>` +
    `유동성 ${"●".repeat(n + 1)}${"○".repeat(3 - n)} → ${phase}` +
    (n > 0 ? "<br>꺾인 자리에 틈이 생겨 촘촘히 쌓이지 못합니다. 추운 지방 생물일수록 "
           + "불포화 비율이 높아 세포막이 얼지 않습니다." : "");
}
$("#dbl").addEventListener("input", drawFat);
drawFat();
```
