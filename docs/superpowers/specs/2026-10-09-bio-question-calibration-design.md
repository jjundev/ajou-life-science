# 생명과학 출제 경향·난이도 조정 설계

## 목표와 결정 상태

두 생성 스킬의 공통 출제 기준을 조정하되, 장별 근거로 유형 배합을 결정한다. 예상문제는 실전 수준의 짧은 적용을 중심으로, 복습 변형은 기본과 심화를 함께 제공한다. 기존 흐름의 제한된 변경이다.

2026-10-09 grill-yourself 설계의 #7(공통 기준 조정 + 장별 배합), #8(예상 기본 12·심화 3)은 사용자가 후속 writing-plans 단계로 이동하면서 **confirmed by default**로 확정했다. 구현 실행은 아직 요청되지 않았다.

## 증거 경계

- 기존 webquiz-style.md의 1~3장 46문항 집계는 유지한다.
- 4장은 별도 원본 관찰로 기록한다: 15문항, 부정형 4(1·2·7·10), 유전 확률·비율 5(5·6·9·13·14), 그림 3(9·11·12), 표 1(15), ㄱㄴㄷ 0. 유형은 중복 가능하다.
- 근거는 `웹과제/4장/intake.md`와 거기에 연결된 raw 15장이다. 전체 15문항은 사용자 확인값이다.
- 공식 답 미확인·기출 재사용 미집계·정본 bank 미등록을 명시한다. 선택 표시로 정답이나 난이도를 판정하지 않는다.
- 4장 관찰을 기존 확정 집계에 합산하지 않는다. 다른 장의 계산 비중이나 난이도를 4장과 같다고 추정하지 않는다.

## 난이도와 배합

- 수준 1: 정의·관계·도식을 직접 식별. 예: EFG→GFE 역위 판별.
- 수준 2: 한 가지 원리를 적용하거나 짧은 추론 수행. 예: Ff×Ff 확률, 기본 가계도 추론.
- 수준 3: 여러 조건·원리를 연결하거나 추가 조건부 계산 수행. 예: 정상 자녀의 보인자 확률 2/3.
- 그림 유무·부정형·보기 개수는 난이도를 자동으로 높이지 않는다.
- 예상 기본 목표: 15문항 중 수준 1~2를 12개, 수준 3을 3개. 생성 정책이며 실제 출제 통계가 아니다.
- 4장 참고 목표: 부정형 4, 계산 5, 그림 3, 표 해석 1. 다른 장은 범위와 증거로 목표를 정한다. ㄱㄴㄷ·장 섞기는 의무 최소 0이다.
- 기존 기출 5·새 문제 10, 기출 모드 2/2/1(기존 예외 포함), 정답 A~E 각 3개를 유지한다. 기출 난이도를 먼저 분류하고 새 문제로 배합을 맞춘다.
- 복습 partC는 10~15개, 수준 1~2 약 75~80%, 나머지 수준 3을 목표로 한다. 작은 세트의 정수 반올림에 따른 차이는 보고한다.
- 복습에서 ㄱㄴㄷ·장 섞기·낯선 참 진술은 선택 유형이다. 기존 근거·범위·낯선 참 진술의 오답 한정 규칙은 유지한다.
- 근거 있는 문항으로 목표를 맞출 수 없으면 범위 밖이나 반복 문항으로 채우지 않고 차이와 이유를 보고한다.

## 설계·작성·리뷰 계약

- 예상 blueprint의 문항 표에 `수준`과 `최소 풀이 단계`를 추가한다. 복습 variants 표에는 기존 열 뒤에 같은 두 열을 추가한다.
- 기본·심화는 위 수준으로 구분한다. 새 pack.json 필드·난이도 배지·카드 재정렬을 추가하지 않는다. 복습 manifest의 기존 level 1~3을 사용한다.
- 작성자는 가까운 개념을 한 부분 바꾼 오답을 우선한다. 새 버전의 차별화가 난이도 상승을 뜻하지 않도록 한다.
- 블라인드 리뷰어는 문제와 정리노트만 보고 답·이의·풀이 단계·수준을 출력한다. 예상 수준이나 정답표는 보여 주지 않는다.
- 메인은 독립 판정과 설계표를 비교한다. 원문은 수정하지 않고 분류를 재검토하며, 생성 문항은 교체·수정하거나 배합 차이를 보고한다. 기존 최대 2회 리뷰 제한을 유지한다.
- 결과 안내·보고에서 기본/심화 개수, 목표와 실제 유형 수, 근거 부족과 차이를 공개한다. 확정 통계와 생성 목표를 혼동하지 않는다.

## 구현 범위와 검증

출제 지침·설계표·작성/리뷰 지침·기존 문서 계약 테스트를 동기화한다. check.py는 이미 types_required를 읽으므로 변경하지 않는다. 난이도 자동 판정도 추가하지 않는다.

기존 원문 포함·번호 보존·기출 대조·유일 정답·범위 제한·채점·브라우저 검증 규칙을 유지한다. 기존 복습팩, 예상 v1~v4, 풀이기록, question-bank 스키마와 추출 스킬은 수정하지 않는다. 4장 정본 게시, 새 예상 세트 생성, 커밋/푸시는 별도 요청 사항이다.

문서 계약 테스트와 기존 검사로 정책 전달 및 호환성을 확인한다. 이 검사로 교육적 난이도가 증명됐다고 주장하지 않는다. 실제 난이도는 이후 새 세트 생성 시 블라인드 풀이로 확인한다.
