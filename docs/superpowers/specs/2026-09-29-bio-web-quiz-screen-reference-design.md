# 2·3장 웹과제 화면용 판별표 PDF 설계

## 목적

2026년 10월 1일 2·3장 웹과제에서 태블릿 또는 노트북 화면에 띄워 빠르게 참조할 PDF를 만든다. 각 장 풀이 시간은 15분이다. 1장 웹과제에서 부정형 발문 8/17문항과 그림·적용 문제가 확인되었으므로, 긴 정의보다 장소·흐름·분리 대상 등 혼동되는 보기의 판별 근거를 우선한다.

## 결과물

- 16:10 가로 화면 비율의 PDF, 정확히 2쪽. 1쪽은 2장, 2쪽은 3장.
- 각 쪽은 상단의 장 제목과 3개 세로 구역으로 구성. 한눈에 보이는 구역명, 15pt 이상 본문, 높은 대비를 사용한다.
- 2장: 세포호흡의 장소·ATP 수지·전자 흐름, 발효, 명반응과 캘빈 회로의 산물·투입물, 짧은 판별 함정.
- 3장: 자매염색분체·상동염색체 그림, 세포주기, 유사분열·감수Ⅰ·감수Ⅱ의 분리 대상, DNA 양·조합 수, 암 관련 판별 함정.
- 정답 번호·문항 전문·출제 확률은 싣지 않는다. 4장 유전도 포함하지 않는다.
- PDF만 전달하되 재생성 가능한 제작 스크립트는 저장소에 둔다.

## 품질 기준

1. 화면 맞춤 보기에서 PDF가 정확히 2쪽이며, 각 쪽의 큰 제목·구역명이 즉시 식별된다.
2. 모든 한글·첨자·화살표가 빠짐없이 렌더링되고 텍스트 추출에도 핵심 용어가 남는다.
3. 글자·도식·구역이 겹치거나 잘리지 않는다. 본문 최소 15pt.
4. 2·3강의 서로 다른 기출 유형에서 위치·흐름·분리 대상·계산의 근거를 PDF에서 찾을 수 있다.
5. 낮은 우선순위 세부사항을 넣기 위해 글자를 줄이지 않는다.
