# lac 설명 보강과 어려운 개념 작성 기준

## 목적
1006 lac 오페론을 필요성, 억제 해제, 최초 젖당 유입까지 연결해 설명한다. 앞으로 생명과학 정리노트에서도 이해가 막히기 쉬운 개념에 한정해 이 설명 방식을 적용한다. 기존 노트와 작성 흐름을 보완하며 새 생성 시스템은 만들지 않는다.

## 1006에서 보일 설명
- 젖당이 없을 때 관련 단백질을 계속 많이 만들면 에너지와 아미노산이 낭비된다.
- 전사를 억제해 생산을 줄이고, 알로락토스가 억제자의 구조를 바꾸면 작동자에 잘 붙지 못해 전사가 증가한다.
- 억제 상태에서도 기저 발현으로 소량의 LacY와 LacZ가 만들어진다. LacY는 최초 젖당 유입을, LacZ는 알로락토스 생성을 가능하게 한다.
- 소량 생산, 젖당 유입, 알로락토스 생성, 억제 해제, 생산 증가 순서를 읽을 수 있다.
- 포도당이 없는 설명 조건을 유지한다. OFF를 생산량 0으로 오해하지 않게 한다.
- 기저 발현은 확인한 1006 STT에 없으므로 출처가 있는 보충으로 구분한다. 교수님 말씀으로 넣지 않는다.

## 앞으로의 적용 기준
다음 중 하나에 해당하고 기존 설명만으로 인과가 연결되지 않을 때 적용한다.
1. 사용자가 이해 어려움을 직접 지적했다.
2. 이중 부정, 여러 단계의 인과, 순환처럼 보이는 시작 조건, 중요한 숨은 조건 때문에 정의만으로 이해하기 어렵다.

필요 상황, 해결하려는 문제, 핵심 원리, 작은 사례, 오해하기 쉬운 조건을 기존 토픽 안에 짧게 통합한다. 이미 충분한 설명은 반복하지 않는다. 단순 용어, 명칭, 목록에는 추가하지 않는다. 생물학의 필요성은 기능과 효과로 설명하고 의도적 설계나 근거 없는 진화 이야기를 쓰지 않는다. 이해의 인과적 공백을 메우는 수업 밖 사실도 보충으로 허용하되 실제 출처를 밝힌다. 출처를 확인할 수 없으면 단정하지 않는다.

## 범위와 검증
1006 정리노트 HTML, 파생 MD, 해당 manifest와 새 변경 기록, bio-review-pack의 SKILL.md 및 작성·리뷰 규칙을 수정한다. 다른 날짜 노트, 복습문제, 문제설명, 별도 인터랙티브 자료는 수정하지 않는다. 구조 검사, HTML–MD 검증, 데스크톱·모바일·다크모드 표시 및 기존 위젯 동작으로 확인한다. 커밋과 푸시는 이번 계획 작성에 포함되지 않는다.
