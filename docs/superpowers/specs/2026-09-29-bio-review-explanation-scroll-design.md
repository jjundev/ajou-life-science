# 복습문제 해설 번호와 자동 스크롤 설계

## 의도와 범위

기존 복습문제 HTML 8개와 향후 생성되는 복습문제에서, 답을 고른 직후 내 선택과 정답 선지를 비교하기 쉽게 한다. 선택지 카드 아래 펼쳐지는 해설의 맨 앞에 반복되는 `(1)`, `(2)`, `A.` 같은 식별자만 화면에서 제거한다. 선지 본문과 해설 문장 중간의 번호, 오른쪽 풀이 도움의 정답 표시는 유지한다.

## 동작

- 처음 답을 선택하면 기존처럼 내 선택과 정답의 해설을 펼친다.
- 펼침으로 인한 레이아웃 변경을 반영한 뒤, 왼쪽 `.content` 스크롤 영역에서 두 선지 카드 전체가 보이면 합친 범위를 중앙에 둔다.
- 고른 선지가 정답이면 펼쳐진 그 카드 전체를 기준으로 중앙에 둔다.
- 펼친 카드 둘과 사이의 선지가 화면보다 길면 두 선지 버튼이 한 화면에 보이도록 우선 배치한다. 버튼 둘도 함께 들어갈 수 없으면 내 선택 버튼을 중앙에 둔다. 화면 높이의 물리적 한계를 넘는 콘텐츠를 축소하거나 접지는 않는다.
- 페이지 로드 때 저장된 답을 복원하거나, 채점 뒤 해설을 접거나 다시 펼치거나, `다시 풀기`를 누를 때는 자동 스크롤하지 않는다.
- 모호한 문항에서는 기존 `출제 의도상 답`을 정답 선지 위치로 취급한다.

## 구현 경계

공통 `.agents/skills/bio-review-pack/assets/review-interaction.js`에서 해설 DOM 표시와 첫 답 선택 뒤 스크롤을 처리한다. 원본 해설 텍스트는 HTML과 모델 검증의 입력으로 보존하고, 브라우저에서 표시할 때만 선두 식별자를 제거한다. 실패 시 정적 원본으로 복구하는 기존 경로도 보존한다. `review_interaction.py --write`로 현재 HTML 8개에 공통 런타임을 재설치하면 향후 조립 경로와 동작이 일치한다. Markdown, 문제 내용, 채점 모델, localStorage 형식은 바꾸지 않는다.

## 검증

정답·오답, 떨어진 선지, 긴 해설, 좁은 화면, 문자형 보기, 모호한 문항, 저장 답 복원, 다시 풀기, 해설 재토글을 실제 브라우저에서 확인한다. 해설 선두 번호만 사라지고 문장 안의 참조 번호는 유지돼야 한다. 공통 Python·Node 테스트와 8개 HTML 모델 검사를 통과해야 한다.
