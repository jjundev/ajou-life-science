# Study Note ELI5 — 확정 설계

상태: 2026-09-10 대화에서 인터뷰 종료. 이 문서는 구현 계획과 함께 전달하는 설계 스냅샷이다. 계획 작성은 구현·커밋 승인이 아니다.

## 목적과 확정 결정

생명과학 정리노트의 전체 학습 내용을 보존하면서, 배경지식이 없는 학생이 그림으로 이해하고 정확한 용어로 설명하며 원본 문제에 적용할 수 있는 HTML 가이드를 만든다.

- #7: `study-note-eli5`만 강화한다. 일반 `eli5`는 변경하지 않는다. 기본값으로 확정.
- #8: 정리노트 전체를 보존한다. 복습·보충·범위 경계까지 처리한다. 기본값으로 확정.
- 자동 검사는 구조·연결·검토 기록을 확인한다. 의미의 정확성이나 학습자의 이해를 자동으로 증명한다고 표현하지 않는다.

## 전역 제약

- 원본 전체 보존. 문제에 직접 나오지 않는 개념도 설명한다.
- 전체 길이 제한 없음. 카드와 분량을 늘려 조건·예외·수치·방향을 보존한다.
- UTF-8, 오프라인 단일 HTML, inline CSS/SVG. 외부 CDN·네트워크 요청·빌드 도구 없음.
- 정리노트 MD와 원본 퀴즈 HTML은 원천 자료이고 ELI5는 파생 학습 가이드다.
- 원본과 답지의 충돌은 조용히 고치지 않는다. 원문 주장·판단 근거·처리 결과를 표시한다.
- 범위 밖 내용은 설명·풀이로 당겨오지 않는다. 보류 사유와 필요한 후속 학습을 표시한다.
- 필수 사실은 개념 설명에 존재해야 한다. 정답 해설에만 있는 사실은 설명 완료로 세지 않는다.
- 중요한 조건은 기본 화면에 표시한다. 정답과 추가 예시는 접을 수 있으며 인쇄 시 펼친다.
- 문항 식별자는 출처와 번호를 묶는다. 생성 질문은 원본 문항과 구분한다.
- 원본과 생성물 변경 시 이전 검토 기록을 재사용하지 않는다.
- 일괄 재생성, 자동 알림, 학습 계정·성적 저장, 자유서술 자동 채점은 이번 범위 밖이다.

## 원본과 누락 방지

1. 주 노트, 동반 퀴즈, 필요한 참고 자료의 경로·역할·해시·읽기 상태를 기록한다. 파일 이름만으로 범위를 판단하지 않는다.
2. 주 노트의 모든 비어 있지 않은 줄을 구간으로 분할해 처리한다. 제목·표·그림·경고·복습·문항 매핑·범위 경계도 빠짐없이 분류한다.
3. 각 구간에서 독립적으로 빠지거나 틀릴 수 있는 학습 사실을 추출한다. 한 사실 안에는 주장과 성립 조건·기준 단위를 함께 둔다.
4. 생성 전에 사실 목록과 문항 범위를 확정한다. 생성 뒤 누락 발견 시 근거와 함께 보완하고 검토를 무효화한다. 검사 통과 목적으로 사실을 삭제하거나 범위를 축소하지 않는다.
5. 각 사실을 실제 HTML 설명 위치에 연결한다. 한 설명이 여러 사실을 다룰 수 있지만 사실별로 의미 보존을 검토한다.
6. 원본 → HTML 방향으로 누락을, HTML → 원본 방향으로 추가·과장·모순을 확인한다. 원본 자체의 오류도 충돌 기록으로 다룬다.

자동 줄 범위 검사는 의미 단위 추출의 완전성을 증명하지 않는다. 작성자가 구간을 모두 비학습 구간으로 표시하는 오류, 문장에 식별자만 붙이는 오류는 별도 원본 대조로 잡는다. 해시는 우발적인 오래된 기록을 감지하며 악의적 변조 방지 장치가 아니다.

## 학습 흐름

1. 전체 지도: 현재 개념과 앞서 배운 개념의 관계.
2. 개념 설명: 비유 → 그림·흐름 → 정확한 설명 → 조건·예외·비유의 한계.
3. 회상: 개념 묶음마다 1~3개. 이름 붙이기, 방향 그리기, 차이 설명, 틀린 문장 고치기 중 적합한 형식을 사용한다. 답은 기본적으로 숨긴다.
4. 원본 문제: 답·근거·고를 법한 오답 진단, 관련 개념 링크. 원본 보기가 없으면 임의로 복원하지 않는다.
5. 오답 복습: 용어 / 개념 혼동 / 과정·방향 / 조건·단위 중 해당 설명으로 이동한다. 맞혔어도 이유를 설명하지 못하면 복습 대상으로 삼도록 안내한다.
6. 다음 학습: 먼저 기억을 꺼낸 뒤 막힌 설명을 읽는다. 첫 학습 → 다음 학습 시작 → 주간 누적 점검을 안내하되 시간·알림·저장 기능은 만들지 않는다.

회상 질문은 생성 질문이라고 표시한다. 질문을 모든 사실마다 의무적으로 추가하지 않는다. 원본 문항 수와 섞지 않는다. 우선순위는 읽는 순서를 정하며 범위를 줄이는 용도로 사용하지 않는다.

## 검증·인계 기준

- 기계: 자료 해시, 원본 구간 분할, 식별자 중복, 사실 연결, 본문 존재, 문항 범위·보류, 개념 연결, 검토 대상 버전 확인.
- 의미: 사실별 보존 근거, 원본 구간 재대조, 추가·왜곡 검토, 충돌·보류 처리.
- 화면: 큰 화면·좁은 화면·인쇄, 답 숨김·펼침, 내부 이동, 읽을 수 있는 SVG 라벨.
- 실패·미해결 항목이 있으면 검토 필요로 보고한다. 구조 검사 통과를 완전성 보장으로 표현하지 않는다.
- 첫 실사용 검증은 현재 `0910.md`와 연결 자료를 사용한다. 기존 ELI5를 덮어쓰지 않는 새 파일에 생성한다. 현재 원본 파일을 다시 읽어 범위를 확정하고, 현재 테스트의 숫자를 그대로 정답 근거로 사용하지 않는다.
