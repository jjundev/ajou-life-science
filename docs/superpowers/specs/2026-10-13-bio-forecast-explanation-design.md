# 웹과제 예상문제·해설 자동 생성 설계

2026-10-13 대화에서 확정한 설계를 구현 계획과 함께 읽을 수 있도록 기록한다. 이 문서의 저장은 구현 시작을 뜻하지 않는다.

## 목표와 범위

`/bio-webquiz-forecast N [lite]`를 호출하면 새 예상 세트를 생성·검증한 뒤 `bio-problem-explain`을 자동 사용하여 같은 장·버전의 해설을 생성·검증·발행한다. 기존 흐름의 확장이다. 두 HTML이 모두 검증·발행되어야 전체 완료로 보고한다.

- 입력: 방금 생성한 `웹과제예상/N장/복습문제_N장_웹과제예상_vK.html`의 명시 경로.
- 해설 대상: `p1–p15` 전체. `o1·o2`는 개요이므로 제외한다.
- 해설 구성: `understand → recall → start → solve → verify → pitfall → retry`, 기존 요약·로컬 자원·문항별 이동을 재사용한다.
- 근거: 해당 버전의 `src/vK/blueprint.md`, `pack.json`, 관련 정리노트·교과서·강의노트와 기출 원문. 예상·변형 문항을 실제 출제 원문으로 표시하지 않는다.
- 파일명·장 폴더·pack.json의 장·버전이 일치해야 한다. 문항 누락·중복·알 수 없는 카드는 오류다.
- 기존 날짜형 입력, 최신 선택, `all`의 복습노트 범위를 유지한다. 예상문제는 명시 경로로만 선택한다.

## 출력

같은 `웹과제예상/N장/` 폴더에 다음을 저장한다.

- 기존 예상문제: `복습문제_N장_웹과제예상_vK.html`.
- 해설: `문제해설_N장_웹과제예상_vK.html/.md`.
- 그림: `figures_문제해설_N장_웹과제예상_vK/`.
- 검토·로컬 자원: `자료_문제해설_N장_웹과제예상_vK/`.
- 제목: `생명과학 N장 웹과제 예상 vK 문제해설`.
- 읽음 상태의 템플릿 RANGE 값: `bio-problem-explain-forecast-N장-웹과제예상_vK`.

기존 복습문제 해설의 이름과 동작은 유지한다. 해설 생성기가 예상문제 원본에 링크를 자동 삽입하지 않는다.

## 실행과 실패 처리

예상문제 작성 → 빌드·검사 → 블라인드 풀이 → 브라우저 확인 → 해설 추출·저작 → source_visual/content/independent/browser 검토 → 해설 발행 → 통합 보고.

자동 연결은 스킬의 에이전트 실행 절차가 맡는다. Python 빌드 명령은 LLM을 호출하지 않는다. `lite`도 해설을 생성하고 네 검토를 모두 수행한다. 해설 저작자와 별도인 리뷰어가 정답·풀이·해설을 보지 않고 독립 검산한다.

검토 실패 시 즉시 최종 보류하지 않고 원인을 수정한다. 최초 검토 이후 수정·재검토는 최대 2회다(최초 1회 + 재검토 최대 2회). 수정 후 build가 검토를 초기화하므로 네 검토를 현재 해시에 대해 다시 승인해야 한다. 정답 충돌을 승인 상태로 바꾸기만 해서 통과시키지 않는다.

- 해설만 잘못되었으면 해설을 수정하고 build/check 및 네 검토 후 발행한다.
- 예상문제 자체가 잘못되었으면 이번 호출에서 생성한 버전의 원본 카드·설계표·정답키를 함께 수정한다. 예상문제 6–8단계를 다시 수행한 다음 새 RUN에서 해설을 재추출·수정·검토한다. 이전 버전은 수정하지 않는다.
- 최초 예상문제 블라인드 수정 한도와 해설 수정 한도를 따로 기록한다. 해설 수정 때문에 문제를 고친 경우는 해설 수정 한도를 1회 소비하며, 중첩 루프로 한도를 새로 시작하지 않는다.
- 최대 2회 후에도 미해결이면 검증된 문제 HTML은 유지하고 해설 발행을 보류한다. 전체는 부분 완료로 보고하며 실패 문항·검토·이유·수정 횟수를 공개한다.
- 개별 단계 완료를 전체 완료로 보고하지 않는다. 참조 파일이나 생성 파일이 검토 후 바뀌면 재검토 전 발행을 막는다.

## 검증과 제외 범위

Python 3.10 이상, 실행기 표준 라이브러리 유지. 테스트는 pytest, 실제 브라우저 검토는 Playwright 또는 사용 가능한 브라우저로 수행한다. 1280×900/375×812 및 light/dark에서 두 HTML의 이동·채점(문제만)·요약·수식·그림·링크를 확인한다. 콘솔 오류·KaTeX 오류·누락 자원·외부 요청·문서 가로 넘침은 0이어야 한다.

기존 세트 일괄 백필, 기존 문제 파일명 변경, 새 실제 수업 세트 생성, 커밋·푸시는 이번 구현 범위에 포함하지 않는다. 연동 수락 검증은 임시 저장소의 합성 15문항으로 진행하며 테스트의 가짜 승인 기록을 실제 학술 검토로 보고하지 않는다.
