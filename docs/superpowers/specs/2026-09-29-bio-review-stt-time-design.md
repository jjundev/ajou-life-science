# 복습팩 학생용 텍스트의 STT 시각 제거 설계

## 목표

기존 복습팩의 정리노트·복습문제 HTML과 대응 MD, 장마감 MD에서 STT 녹음 위치를 나타내는 시각을 제거한다. 새 복습팩에는 같은 표기가 다시 들어가지 않도록 작성 규칙과 기계 검사를 고친다. 교수님 발언의 내용, 수업 날짜, 강의노트·교재 쪽수, 문제 출처는 유지한다.

## 범위와 동작

- `복습노트/*/정리노트_*.html`, `복습문제_*.html`, 대응 `.md`, `장마감_*.md`의 학생에게 읽히는 문장을 대상으로 한다.
- `(0910 22:05–22:22)`, `0910 22:05–22:22에서`, `(P03 04:12)`, 단독 `14:37`처럼 STT 녹음 위치를 나타내는 표기를 문맥에 맞게 제거한다. 숫자만 빼서 조사·문장부호가 깨지면 문장을 다시 쓴다.
- `0910 수업`, `강의노트 3장 p14`, `교재 p.68`, 실제 학습 내용의 시간·기간 표현은 보존한다.
- 원본 `STT/`, 내부 요약·문항 감사·정답 대조 파일의 근거 시각은 보존한다.
- `bio-review-pack`의 섹션·카드 작성 규칙은 학생용 텍스트에 STT 시각을 금지한다. 내부 요약 단계에서는 계속 시각을 기록한다.
- HTML 검사기는 표시 텍스트의 시각 형식을 찾아 실패한다. 결과에는 파일과 위치를 알려 수정할 수 있게 한다. 새 HTML을 MD로 변환한 뒤에도 MD를 검색한다.

## 검증

- 기존 전체 산출물에서 STT 시각 형식을 검색하고 남은 후보를 문맥별로 확인한다.
- HTML 검사기의 양성 사례는 날짜+시각, 시각 범위, 파트+시각, 단독 녹음 시각이다. 음성 사례는 수업 날짜·쪽수·수업 내용의 시간 표현이다.
- 기존 복습팩 검사와 HTML→MD 변환 검사를 실행한다. 기존 팩의 manifest가 없는 경우 일반 HTML 검사와 링크·그림 무결성을 확인한다.
