# 인터렉티브 자료와 정리노트 연결 설계

사용자가 2026-10-14 승인한 설계. 기존 자료 전체 연결(#6)도 확정했다.

- 인터렉티브 저장 성공 후 기존 정리노트 HTML의 관련 설명 바로 뒤에 안내 문장과 링크를 추가한다.
- 문장은 실제 자료에서 관찰하거나 조작할 포인트를 알려 준다. 페이지 끝 목록에만 추가하지 않는다.
- 상대 경로, `target="_blank" rel="noopener noreferrer"`, 표시 문구 없이 자연스러운 안내 문장을 사용한다.
- 기존 본문, 스타일, 위젯, 스크립트와 인터렉티브 파일을 보존한다. Markdown/PDF 동기화와 특정 재생 시점 링크는 범위 밖이다.
- 생성된 안내를 식별하고 재실행 시 중복하지 않는다. 같은 절의 기존 목적지 링크도 인식한다.
- 정리노트, 설명 위치 또는 대상 자료가 없거나 모호하면 해당 연결만 건너뛰고 이유를 보고한다. 자료 저장은 유지한다.
- Node.js 20 이상, CommonJS, 기본 라이브러리만 사용한다. 실제 경로를 보존하여 NFC/NFD 한글 이름 모두 처리한다.
- 기존 12개 정리노트와 43개 인터렉티브 자료 모두 연결한다. 여러 개념에 쓰이는 자료는 필요한 절에서 다시 연결할 수 있다.
- 링크 도구는 원문을 전체 직렬화하지 않고 삽입 구간만 변경한다. 한 노트에 대한 링크는 모아서 한 번 저장한다.
- 커밋·푸시는 실행하지 않는다.

- 2026-10-14 사용자 추가 요청: 안내의 `(새 탭)` 표시를 기존 71개 링크와 생성 도구에서 제거했다. `_blank`와 rel 속성은 유지한다.
