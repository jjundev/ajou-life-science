# 웹과제 예상문제 스킬 (`bio-webquiz-forecast`) 설계

2026-10-08 대화에서 확정한 설계다. 결정 번호는 대화의 표와 같다.

## Intent
2026-10-07 세션에서 손으로 한 작업을 스킬로 만든다. 그 작업은 지난 웹과제 패턴·기출·정리노트로 다음 장 웹과제를 예상하고, 예상 개요와 예상 모의문제를 복습문제와 같은 형식의 HTML로 만들고, 블라인드 검토로 정답이 하나인지 확인하는 일이었다. `/bio-webquiz-forecast <N>`을 부를 때마다 `웹과제예상/<N>장/`에 새 세트가 하나 생긴다. 첫 세트는 `…_v1.html`, 다음은 `…_v2.html`이며 이전 세트는 덮어쓰지 않는다. 같은 장의 세트끼리는 기출 번호와 새 문제 발문이 겹치지 않는다. 실제 웹과제는 약 30%가 기출을 그대로 또는 살짝 고쳐 낸 문제이므로 세트에도 그 몫을 넣는다.

## 확정 사항
| # | 항목 | 값 |
|---|---|---|
| 0 | 접근 | 새 스킬. 조립은 bio-review-pack `assemble.build_review` 재사용. 공용 assets·템플릿은 고치지 않는다 |
| 1 | 위치 | `.agents/skills/bio-webquiz-forecast/`, `.claude/skills/bio-webquiz-forecast` 심볼릭 링크 |
| 2 | 파일명 | slug `웹과제예상_v<K>` → `복습문제_<N>장_웹과제예상_v<K>.html` (documentId = 파일명) |
| 3 | 푼 기록 분리 | body `data-range="<N>장-v<K>"` |
| 4 | 버전 번호 | 기존 최대 + 1, 이미 있는 버전 폴더는 새로 만들지 않는다 |
| 5 | 위치 | `웹과제예상/<N>장/`에 HTML, 원본 `웹과제예상/<N>장/src/v<K>/` (pack.json, cards/, blueprint.md) |
| 6 | 치환 | 정리노트 링크, data-range, 내보내기 숨김 style — 각각 정확히 1회 |
| 7 | 개요 카드 | o1(형식·주제표), o2(막판 체크 + 재출제 유력 기출 10개, 번호·핵심 한 줄·정답) — 보기 없음, 채점 제외 |
| 8 | 내보내기 | 숨김 |
| 9 | 품질 관문 | check.py 통과 + 블라인드 풀이 15/15 일치(이의 0) — lite도 필수 |
| 10 | 모호성 문구 | 카드에 쓰지 않는다 |
| 11 | 커밋 | 제안만 |
| 12 | 2026-10-07 4장 세트 | v1으로 이전 |
| 13 | 세트 크기 | 개요 2 + 문제 15, 정답 A~E 각 3 |
| 14 | v2 이후 차별화 | 같은 발문 금지, 덜 다룬 ★★★·★★☆ 주제 우선, 같은 혼동은 숫자·생물·그림을 바꿔 재출제 |
| 15 | 응시 후 | 계속 생성. `웹과제/<N>장/questions.json` 발문과 같은 문제는 피하고 실제 경향을 개요에 반영 |
| 16 | 장↔기출 | N장 ↔ `기출 <N>강 M` |
| 17 | 기출 출처 | `복습노트/*/복습문제_*.html`의 `data-source="기출 <N>강 M"` 카드(답안지 오류 정정 반영본) |
| 18 | 기출 방식 | 기출그대로(보기 순서만 섞음) / 기출쌍둥이(발문 그대로, 다른 보기가 정답) / 기출숫자(숫자·조건만 바꿈) |
| 19 | 버전 간 기출 | 같은 기출 번호 재사용 금지 |
| 20 | v1 | `legacy: true`, 기출 규칙 검사 생략, `used_exam_sources`: 기출 4강 39·32 |
| 21 | 기출 문항 수 | 5 (그대로 2 · 쌍둥이 2 · 숫자 1) |
| 22 | 유력 목록 | o2에 10개, 정답 포함 |

## 세트 구성
- partA 예상 개요: o1, o2
- partB 기출 재출제 예상: p1–p5 (제목 `PN. [기출 예상]` 그대로, `PN. [기출 변형]` 쌍둥이·숫자)
- partC 새 문제 예상: p6–p15 (제목 `PN. [예상]`)

## 범위 밖
PDF 출력, 실제 결과로 적중률 매기기, 내보내기·풀이기록 수집, bio-review-pack 수정, web-quiz-extract의 기출 번호 자동 기록.
