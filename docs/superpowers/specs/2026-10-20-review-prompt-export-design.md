# 복기 프롬프트 내보내기 설계

## 의도

복습문제(bio-review-pack, 같은 런타임을 쓰는 웹과제예상·약점노트)와 시험예상문제(bio-exam-forecast)의 마지막 화면에 있던 **JSON 내보내기**를 **복기 프롬프트 복사**로 바꾼다. 버튼을 누르면 풀이 결과와 AI 코칭 지시문을 묶은 한국어 마크다운 프롬프트가 클립보드에 복사된다. 사용자는 이를 아무 AI 채팅에 붙여 넣어 보완 학습을 이어 간다. JSON 내보내기는 완전히 제거한다.

## 확정 결정

| # | 결정 | 값 |
|---|---|---|
| 1 | 전달 | 클립보드 복사 → 실패 시 숨긴 textarea `execCommand('copy')` → 그래도 실패하면 프롬프트가 선택된 읽기 전용 textarea 대화상자 |
| 2 | 위치 | 기존 내보내기 자리(복습문제: `body.at-end`의 pager 바, 시험: 제출 후 결과 화면) |
| 3 | 텍스트 추출 | 복습문제는 DOM 강화(보기 노드 이동·접두어 제거) 전에, 시험은 KaTeX 렌더 전에 카드 원문을 캡처 |
| 4 | 구조 | 공통 모듈 `bio-review-pack/assets/review-prompt.js`를 두 런타임에 인라인 |
| 5 | 정오 판정 | 기존 `grade()`와 시험 `attempt`를 재사용 |
| 6 | 문항 내용 | 제목, 문제, 보기 전체, 내 답, 정답, 내 선택·정답의 해설, 진단 외 풀이 줄(수업과의 연결 등). 힌트 제외 |
| 7 | 단답형 pending | 정답과 허용답을 넣고 AI가 먼저 판정 |
| 8 | 지시문 | bio-review-coach 방법론 이식(아래 문구) |
| 9 | JSON | **완전 제거**: 복습문제 폴더 저장·다운로드·스냅샷·도움말 팝업, 시험 JSON 다운로드, `collect_solves.py`, 약점노트 저장 경로 어댑터. 기존 `.assets/풀이기록/*.json` 파일은 그대로 둔다 |
| 10 | 문항 범위 | 오답·애매함·자기채점 대기·미응답·출제 모호는 전문, 확신 정답은 제목만 |
| 11 | 웹과제예상 | 프롬프트 버튼 노출(`forecast-overrides` 숨김 스타일 제거) |
| 12 | 소급 | 복습노트·웹과제예상·약점노트 기존 HTML은 런타임 재주입, 시험예상은 다음 빌드부터 |
| 13 | AI 진행 | 한 번에 한 개념씩 숫자 선택지 대화형 코칭 |

bio-review-coach는 붙여 넣은 복기 프롬프트 또는 기존 풀이기록 JSON을 입력으로 받도록 문서만 고친다.

## 프롬프트 문구(고정)

`{kind}`는 복습문제 `복습문제`, 시험 `시험 예상문제`. 상태 묶음 순서와 제목: `오답`, `애매함 표시(맞혔지만 확신 없음)`, `자기채점 대기`, `미응답`, `출제 모호`. 비어 있는 묶음은 생략한다.

```
# 생명과학 복기 요청

너는 내 생명과학 튜터야. 아래는 내가 방금 푼 {kind}({range})의 풀이 기록이야. 이 기록을 출발점으로 내 약한 개념을 찾아 대화로 보완 학습을 진행해 줘.

## 진행 규칙
1. 먼저 기록에서 보이는 핵심 진단을 짧게 공유해. 확인된 사실(내 선택, 정답)과 네 가설을 구분하고, 정답률만으로 이해도를 단정하지 마.
2. 다시 볼 문항을 개념별로 묶고, 반복되거나 선행 개념인 묶음부터 다뤄.
3. 한 번에 한 개념만 겨냥한 질문을 하나씩 내. 보기는 숫자로 달고, "모르겠다"와 "답은 골랐지만 찍었거나 확신이 없다"를 별도 숫자 보기로 넣어. 나는 숫자만 답해도 돼.
4. 원래 문항을 그대로 다시 묻지 말고, 조건이나 비교 대상을 한 가지만 바꾼 새 질문으로 확인해.
5. 내가 틀리거나 확신이 없으면 맞는 부분과 잘못 연결한 부분을 짚고, 표현을 바꾼 재확인 질문을 한 번 더 내. 설명을 본 뒤 맞힌 것은 "코칭 후 이해"로 기록하고 원래 알던 것으로 치지 마.
6. "출제 모호" 문항은 내 오개념의 증거로 쓰지 마. 해설은 진단 근거로만 쓰고, 이 범위({range}) 수업 밖 내용으로 넓히지 마.
7. "자기채점 대기" 단답형은 먼저 내 답이 정답·허용답과 같은 뜻인지 판정해 줘.
8. 모든 묶음을 다루거나 내가 그만하자고 하면 다음 다섯 항목으로 정리해 줘: 내가 어려웠던 부분 / 코칭한 부분 / 학습한 부분 / 아직 어려운 부분 / 복습해야 할 부분.

## 기록 요약
- 자료: {documentId}
- 문항 {total}개 · 응답 {answered} · 정답 {correct+unsure}(그중 애매함 {unsure}) · 오답 {incorrect} · 미응답 {unanswered}[ · 자기채점 대기 {pending}][ · 출제 모호 {ambiguous}]

### 오답

#### {id}. {title}

## 확신 있게 맞힌 문항
- {id}. {title}

준비됐으면 핵심 진단부터 공유하고 첫 질문을 내 줘.
```

- 단답형: `보기:` 줄 생략, `내 답: "{selected}" / 정답: {canonical} (허용: a, b)`. 미응답은 `내 답: 없음`.
- 다시 볼 문항이 없으면 규칙 2를 `오답·애매함·미응답 문항이 없어. 아래 맞힌 문항이 다룬 개념을 조건을 바꾼 변형 질문으로 하나씩 확인해서, 실제로 이해했는지 찍었는지 가려 줘.`로 바꾸고 `## 다시 볼 문항` 절을 생략한다.
- 사용자 입력·문항 텍스트는 원문 그대로 넣는다(HTML 이스케이프 없음, 대화상자는 `textarea.value`).

## 화면 문구

- 버튼: `복기 프롬프트 복사`
- 복사 성공: `복기 프롬프트를 복사했어요. AI 채팅에 붙여 넣으세요`
- 대화상자로 대체: `자동 복사가 막혀 있어요. 열린 창에서 직접 복사해 주세요`
- 대화상자 제목 `복기 프롬프트`, 안내 `Ctrl+C(⌘C)로 복사해 AI 채팅에 붙여 넣으세요.`, 버튼 `닫기`
- 시험 결과 안내: `새로고침하면 답안이 초기화되므로 복기하려면 먼저 복기 프롬프트를 복사하세요.`
- 시험 다시 풀기 확인: `제출한 답안과 결과를 초기화하고 다시 풀까요? 복기하려면 먼저 복기 프롬프트를 복사하세요.`
