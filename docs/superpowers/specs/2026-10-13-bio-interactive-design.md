# 복습 인터렉티브 자료 스킬 `bio-interactive`

날짜: 2026-10-13
기준 결과물: `복습노트/1001/자료_인터렉티브_03_DNA_구조와_복제_3D/canvas/Main.dc.html` (DNA 구조와 복제 3D)

## Intent
「DNA 구조와 복제 3D」의 화면 셸·원본 형식(`.dc.html`)·단독 HTML 빌드·검사를 템플릿으로 굳히고, 이를 쓰는 프로젝트 스킬을 만든다. 입력은 주제 또는 날짜(MMDD). 날짜면 그날 정리노트를 읽고 인터렉티브로 만들 주제를 스스로 고른다. 출력은 해당 날짜 폴더의 `인터렉티브_NN.html`(단독 실행)과 `자료_인터렉티브_NN/`(원본). `/bio-interactive 1006` 한 번으로 질문 없이 1006 수업 주제 2–4개가 같은 디자인으로 나오고, 각 파일이 검사와 브라우저 확인을 통과하면 끝.
Classification: architectural — 새 스킬·템플릿·빌드/검사 스크립트.

## Behavior when done
- `/bio-interactive 1006`: `복습노트/1006/정리노트_1006_*.md`의 H2·H3와 「직접 해 보기」 블록으로 후보를 매기고, 같은 폴더 기존 `인터렉티브_*.html`·`3D모형_*.html`의 `<title>`과 겹치는 주제는 뺀다.
- 개수: 기준(3점) 이상 후보를 점수 순으로 최대 4개. 2개보다 적으면 남은 후보 중 점수 높은 순으로 2개까지 채운다. 후보가 아예 없으면 「후보 없음」.
- `/bio-interactive 오페론`: 정리노트 본문에서 주제를 찾아 가장 최근 날짜 폴더에 1개 저장. 어느 정리노트에도 없으면 교과서·강의노트로 만들어 `복습노트/주제별/`에 저장.
- 날짜가 범위 폴더(`0922-0924`) 안이면 그 폴더를 쓴다. 날짜 폴더도 `STT/<MMDD> 생명.md`도 없으면 「대상 없음」으로 멈춘다. 폴더는 없고 STT만 있으면 STT·강의노트로 만들고 폴더를 새로 만든다.
- 번호: 폴더 안 `인터렉티브_NN.html`·`자료_인터렉티브_NN/` 중 가장 큰 NN + 1(두 자리). 덮어쓰지 않는다.
- 산출물: `인터렉티브_NN.html`, `자료_인터렉티브_NN/Main.dc.html`, `자료_인터렉티브_NN/canvas.json`(나중에 Design 캔버스로 게시할 때 쓰는 매니페스트).
- 화면: 노트 스타일 상단 바(조작 토글·제목·모드 선택·테마·설명 토글), 너비 조절되는 좌우 패널(1024px 미만은 서랍), 가운데 캔버스(드래그 회전·+/−/시점 리셋), 과정 주제에만 재생 바, 라이트·다크, 동작 줄이기 존중. 오른쪽 패널 끝에 「꼭 기억해요」와 출처 한 줄.
- 검사(`check.cjs`)·내용 검토·브라우저 확인 중 하나라도 실패한 주제는 저장하지 않고 「보류」로 보고. 진행은 단계마다 한 줄, 끝에 한 번 보고, 커밋은 제안만.

## Not in this round
- 기존 `3D모형_1001_…html` 이름 바꾸기 — 링크 보존.
- 범용 엔진·JSON 설정 생성 — 주제마다 모델이 다름.
- 학습 기록·퀴즈 채점 — 요청 없음.
- 로컬 Pretendard 내장 — 기준 결과물이 CDN.
- Design 캔버스 자동 게시 — #11.

## Approach
공통 셸 템플릿 `.dc.html` + 주제 슬롯(장면·문구)만 새로 작성 → `build.cjs`로 단독 HTML.

## Decisions
| # | 결정 | 답 |
|---|---|---|
| 0 | 접근 | 공통 셸 템플릿 + 주제 슬롯 |
| 1 | 이름·위치 | `bio-interactive`, 원본 `.agents/skills/bio-interactive/`, `.claude/skills/bio-interactive`는 심볼릭 링크 |

| 13 | 정리노트에 없는 주제 | 교과서·강의노트로 만들고 `복습노트/주제별/`에 저장 [confirmed] |
