# 생명과학 복습 영상 스킬 설계

작성일: 2026-09-29. 근거: 사용자가 제공한 grill-yourself 설계 및 “화면 디자인도 생명과학의 reviewpack 스킬 템플렛 html을 유지” 요구. 구현 계획과 함께 읽는 보존본이다.

## 목적과 결정

완성된 생명과학 복습노트를 수업을 이미 들은 학생용 복습 영상으로 만든다. 짧은 `SKILL.md`가 콘텐츠 판단을 안내하고, Python 보조 도구가 검증·음성·시간표·캐시·렌더링을 맡는다. HyperFrames와 FFmpeg를 사용하며 별도 영상 엔진은 만들지 않는다.

결정 #0–8은 제공된 설계를 따른다. #9 생명과학 전용, #10 기본 자동 완주(`--review`만 중간 검토), #11 실행당 API 예산 $2는 grill의 미변경 추천값으로 확정된 기본값이다(`[confirmed by default]`). 이것은 이번 계획 작성 중 유료 API 호출을 하라는 지시가 아니다.

## 인터페이스와 범위

`/bio-review-video 0915`, `0915-0917`, `<노트 폴더>`, `--review`, `--resume`, `--revoice --voice Charon`을 지원한다. 일반 정리노트 요청에는 적용하지 않는다. 기존 `bio-review-pack`이 원자료에서 노트를 만드는 역할을 유지한다. 범용 과목 플랫폼, 쇼츠, 아바타, BGM, 자동 게시, 단어별 노래방 자막은 제외한다.

입력은 정리노트 HTML/MD, 그림, 복습문제 HTML/MD, 있으면 장 마감 검토다. 모든 학습 주제·수치·보충·오개념·문항 판별점을 보존하며 반복만 통합한다. HTML/MD 충돌은 기록하고 학습 의미 충돌을 해결하기 전 음성을 생성하지 않는다. 당시 시험 안내와 예고는 학습 내용과 분리하고 과거 안내임을 밝힌다.

## 디자인 계약 — 사용자 추가 요구

색상만 닮게 새로 디자인하지 않는다. 디자인 원본은 아래 **현재 복습팩 HTML 템플릿**이다.

- `.agents/skills/bio-review-pack/assets/note-template.html`: 정리노트 본문·계층·배지·그림·표·수식.
- `.agents/skills/bio-review-pack/assets/review-template.html`: 문제·보기·해설을 보여 주는 장면.

템플릿을 수정하지 않는다. 실행별로 원본 HTML과 CSS 및 해시를 스냅샷하고, CSS를 그대로 재사용하는 영상 어댑터를 만든다. `.topic`, `.layer`, `.layer-title`, `.tag`, `.badge`, `.figure` 등 해당 템플릿 클래스와 시각적 계층을 유지한다. `data-theme="dark"`를 명시해 OS 테마나 localStorage가 화면을 바꾸지 못하게 한다. 상호작용 JS는 그대로 실행하지 않고 필요한 학습 상태를 결정적인 타임라인으로 표현한다.

Pretendard 1.3.9, 배경 `#17171c`, 표면 `#212128`, 본문 `#f2f4f6`, 보조 `#a3abb8`, 선 `#34353d`, 강조 `#3182f6`/`#6ea4ff`, 주의 `#f5a15c`, 교수님 `#b69cff`, 보충 `#5fd39a`, 오류 `#ff6b61`을 현 템플릿에서 확인했다. 이후 새 실행은 당시 템플릿을 스냅샷하며 기존 실행은 고정된 스냅샷으로 재개한다.

1920×1080, 30fps. 영상 어댑터에서 제목·도식·하단 자막의 크기와 위치만 조절한다. 템플릿의 웹용 680px 본문 폭과 인터랙티브 버튼을 영상에 그대로 축소하지 않는다. 의미별 글꼴 위계·구분선·강조·모서리 형태는 유지한다. 긴 설명은 여러 장면으로 나누고 작은 글씨로 압축하지 않는다. 학습 의미가 있는 이동·축적·분기·재생·수량 변화를 사용한다.

## 데이터와 실행

`manifest.json`은 sources(경로/해시/출처), topics(필수 개념과 수치/오개념), scenes(토픽·문항 연결/화면·동작 의도), segments(발화문/핵심 자막/출처)를 가진다. 필수 학습 내용이 연결되지 않으면 완료하지 않는다. 단순 토픽 ID 연결은 의미 검토를 대신하지 못한다.

범위 확인 → 내용 대응표 → 대본·장면 → TTS → 실측 시간표 → 애니메이션 → 렌더링 → 검증 순으로 실행한다. TTS 대기 중 그림/배치를 준비할 수 있지만 시간은 음성 실측 이후 결정한다.

Vertex AI Express, 초기 모델 `gemini-2.5-flash-tts`, 기본 Aoede, 한국어, 승인된 말투를 사용한다. 음성 변경은 요청 때만 한다. 인증은 환경변수 또는 명시한 `.env` 경로이며 비밀을 로그·산출물·스킬에 기록하지 않는다. 공급자/모델을 몰래 바꾸지 않는다. 429 및 일시적 서버 오류는 제한적 백오프와 동시성 감소로 처리한다. 샘플·재시도·전사 검사도 예산에 포함한다. 로컬 예산은 클라우드 청구의 강제 상한이 아니다.

`run.json`에 단계 상태와 해시·산출물·검증을 원자적으로 기록한다. TTS 캐시는 원고/발음/모델/음성/지시/생성 설정, 렌더 캐시는 코드/그림/글꼴/시간표/설정/도구 버전/템플릿, revoice 캐시는 원본 영상 해시/구간 매핑/새 시간표를 포함한다. 성공한 문단·장면은 재사용한다. 파일 존재나 프레임 수만으로 재사용하지 않는다.

새 영상은 HyperFrames 장면별 렌더 후 결합한다. 음성만 교체하면 기존 영상의 문단 경계를 재타이밍하고 새 음성으로 결합한다. 내용/그림이 바뀌거나 읽기 어려운 속도면 해당 장면을 재렌더링한다. NVIDIA에서는 CUDA/NVENC를 우선하고 짧은 실측 후 작업 수를 정한다. CPU 대체 경로를 제공한다. Windows 전역 GPU 설정을 변경하지 않는다.

## 출력과 완료 기준

`복습영상/<범위>/<실행ID>/`에 MP4, 장별 타임코드, 자막을 전달한다. 대본·편집 소스·검증은 하위 폴더에 둔다. 원본과 이전 결과를 보존하며 검증 통과 후에만 최신 포인터를 갱신한다.

검증은 내용 대응/의미 검토, 음성 무음·클리핑·길이·핵심 수치 전사, 모든 장면 화면·자막 경계·대비, 파일 해상도·fps·프레임·음성·전체 디코딩, 문단 동기화로 구분한다. 완성 MP4 재생용 미리보기를 편집 소스 검증으로 대신하지 않는다. 템플릿 원본과 영상 어댑터의 실제 화면 비교를 포함한다.

테스트는 한국어 경로/날짜 범위, 누락 검출, 같은 프레임 수의 변경 캐시, 429 재개, 누적 시간 오차, revoice 원본 보존, 짧은 MP4 전체 디코딩을 포함한다. 가짜 API와 기존 음성으로 테스트하고 불필요한 API 비용을 만들지 않는다.
