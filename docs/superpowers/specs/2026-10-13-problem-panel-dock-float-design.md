# 문제 패널 붙이기·띄우기

## Intent
문제해설 페이지(`bio-problem-explain` 템플릿)의 문제 패널(`#panel-prob`, [문제 | 원문] 탭)을 세 방식 중 하나로 둔다: 왼쪽에 붙이기(지금처럼 목차와 본문 사이), 오른쪽에 붙이기(본문과 요약 사이), 띄우기(화면 위에 뜬 스티커 메모 같은 창 — 머리 띠를 끌어 옮기고 오른쪽 아래 모서리로 크기 조절). 패널 머리 버튼이나 끌어서 붙이기로 바꾸고, 방식과 띄운 창의 위치·크기를 기억한다. 완료: 1280·1024에서 세 방식이 모두 동작하고 보기 클릭·판정 카드 이동·너비 조절·375 접힘·인쇄가 그대로 동작한다.

Classification: architectural — 화면 위에 떠서 옮기고 크기를 바꾸는 창은 지금 패널 시스템(grid에 붙는 패널)에 없다.

## Behavior when done
- 패널 머리: [문제 | 원문] 탭 오른쪽에 아이콘 버튼 3개(왼쪽에 붙이기 · 오른쪽에 붙이기 · 띄우기), 현재 방식은 `aria-pressed="true"`·강조색.
- 상단 바: 왼쪽에 붙임 `[목차] [문제]  브랜드  테마  [요약]`, 오른쪽에 붙임 `[목차]  브랜드  테마  [문제] [요약]`, 띄움은 왼쪽 자리. 버튼 아이콘 띠는 붙은 쪽 칸.
- 왼쪽: 지금과 같다(`목차 | 문제 | 본문 | 요약`), 너비 손잡이는 오른쪽 경계.
- 오른쪽: `목차 | 본문 | 문제 | 요약`. 문제·요약은 따로 열고 닫는 별개 패널이고 동시에 열 수 있다. 손잡이·테두리는 왼쪽 경계, 끌기·화살표 방향은 요약 패널과 같다.
- 띄우기: 패널이 grid에서 빠지고 본문이 넓어진다. 본문 위에 그림자·둥근 모서리 카드로 뜬다. 처음엔 너비 420px, 높이 `min(560px, 70vh)`, 상단 바 아래 16px·오른쪽 가장자리에서 24px. 머리 띠 빈 곳 또는 이동 버튼을 끌면 옮겨지고, 모서리 손잡이로 크기 조절(최소 280×200). 항상 상단 바 아래·화면 안에 머문다(창을 줄이면 안으로 밀려 들어오고 크기도 줄어든다). 키보드: 이동 버튼에서 화살표 16px / Shift 64px, 모서리 손잡이에서 화살표로 크기.
- 끌어서 붙이기: 띄운 창을 끄는 중 포인터가 화면 왼쪽·오른쪽 끝 32px 안에 들어오면 붙을 자리에 강조색 반투명 띠(미리보기)가 보이고, 놓으면 그쪽에 붙는다. 띄운 위치·크기는 다음을 위해 남는다.
- 끌어서 띄우기: 붙인 패널의 머리 빈 곳을 24px 넘게 끌면 떨어져 나와 포인터 아래의 띄운 창이 되고 계속 끌 수 있다. 탭·버튼 클릭은 끌기로 잡지 않는다.
- 상단 바 `문제` 버튼: 어느 방식이든 열기/닫기만. 다시 열면 직전 방식.
- 저장: 방식·띄운 창 x/y/w/h·붙였을 때 너비를 localStorage에. 첫 방문은 왼쪽·열림. 값이 없거나 이상하면 왼쪽.
- 공간 부족(`fit`): 띄운 창은 폭 계산·자동 숨김에서 빠진다. 붙인 방식은 지금 규칙(목차 → 요약 → 문제).
- 보기 클릭: 판정·알림·패널 안 보기 스크롤·본문 판정 카드 이동이 세 방식 모두 같다.
- 좁은 화면(<1024)·인쇄: 지금과 같다(문제 패널·버튼 숨김, 문항 안 '문제 보기').

## Not in this round
- 띄운 창이 본문 판정 카드를 자동으로 피하기 — 사용자가 옮기면 된다.
- 좁은 화면 띄우기 — 인라인 접힘이 낫다.
- 위·아래 가장자리 붙이기, 브라우저 밖 창(`window.open`·Document PiP).
- bio-review-pack 레이아웃.

## Approaches
| Option | Approach | Chosen |
|---|---|---|
| A | `#panel-prob` 한 요소 + `.layout[data-prob-dock="left\|right\|float"]`로 CSS가 grid 칸 / `position: fixed` 전환 | ✔ — DOM 이동이 없어 탭·보기 클릭·`mountPanes`가 그대로 |
| B | 띄울 때 비모달 `<dialog>`로 내용 이동 | — 내용이 두 곳을 오간다 |
| C | Document PiP / `window.open` | — Chromium 전용, `file://` 제약 |

## Decisions
| # | Decision | Answer |
|---|---|---|
| 0 | 접근 | A |
| 1 | grid | 5칸, 문제 패널 칸 2 또는 4 |

| 6 | 크기 조절 | 직접 만든 모서리 손잡이(pointer + 화살표) |

| 10 | 오른쪽에 붙일 때 | 문제·요약 별개·동시 열림, `본문 \| 문제 \| 요약`, `문제` 버튼은 `요약` 왼쪽 [confirmed] |
