# 복습문제 채점 효과와 선택지 강조 설계

## 목표와 범위

기존 복습문제 HTML 8개와 앞으로 생성하는 복습문제 HTML에서, 답을 처음 선택할 때 화면 중앙 상단에 짧은 채점 효과를 보여주고 선택 보기와 정답 보기를 테두리로 구분한다. 기존 문제, 정답, 해설, 점수 기록, 보기별 해설 접기·펼치기는 유지한다.

## 사용자 동작

- 정답 선택: 폭죽을 연상시키는 작은 색상 입자와 `정답이에요` 문구를 화면 중앙 상단에 약 1초 동안 표시한다.
- 오답 선택: 흔들림과 X 표시를 담은 짧은 붉은 효과와 `다시 확인해요` 문구를 같은 위치에 표시한다.
- 정답 보기에는 두꺼운 파란 테두리를, 잘못 고른 보기에는 두꺼운 붉은 테두리를 표시한다. 정답을 고른 경우 한 보기에 `내 선택 · 정답`을 함께 표시한다.
- 효과가 사라져도 선택지 테두리와 기존 글자 라벨은 남는다. 다시 풀기는 테두리를 제거한다.
- 답을 제출한 후 보기를 눌러 해설을 접고 펼칠 때에는 효과를 재생하지 않는다.
- 저장된 답을 새로고침으로 복원할 때에는 효과를 재생하지 않는다.
- 모호한 문항은 기존 `단일 정답 판정 주의` 상태를 유지하고 정오답 효과를 재생하지 않는다. 출제 의도상 답은 파란 테두리, 고른 보기는 중립 테두리로 표시한다.

## 표시·접근성 제약

- 효과는 고정 위치의 단일 DOM 영역을 재사용한다. 연속으로 다른 문제에 답하면 앞선 효과의 종료 타이머를 취소하고 새 효과만 표시한다.
- 효과가 본문 스크롤과 클릭을 막지 않는다. 모바일 좁은 화면, 상단 바, 라이트·다크 테마에서 읽을 수 있어야 한다.
- `prefers-reduced-motion: reduce`에서는 움직이는 폭죽·흔들림을 없애고 짧은 정적 문구만 표시한다.
- 채점은 기존 문항 안의 `role=status` 영역에서 읽히므로 효과 영역에는 추가 라이브 리전을 두지 않는다. 색상만으로 결과를 알리지 않는다.
- 인쇄에서는 효과 영역과 선택지 강조 테두리를 숨긴다. JavaScript가 실패하거나 꺼진 경우 기존 정적 문제와 풀이를 읽을 수 있어야 한다.
- 서버, 외부 애니메이션 라이브러리, 소리, 점수 화면을 추가하지 않는다.

## 코드 경로

- `.agents/skills/bio-review-pack/assets/review-interaction.css`: 효과 영역, 애니메이션, 상태별 선택지 테두리, 동작 줄이기·인쇄 규칙.
- `.agents/skills/bio-review-pack/assets/review-interaction.js`: 기존 `grade`, `paint`, 최초 답 선택 경로를 사용해 효과를 표시한다.
- `.agents/skills/bio-review-pack/scripts/review_interaction.py`: 현재 내장 CSS/JS 설치 방식을 유지하며 새 자산을 기존 HTML 8개에 다시 설치한다.
- `.agents/skills/bio-review-pack/tests/browser_check_review.py`: 실제 브라우저에서 결과별 효과, 복원·다시 풀기·연속 답변·모바일·동작 줄이기·인쇄를 확인한다.
- `복습노트/{0901,0903,0908,0910,0915,0917,0922,0929}/복습문제_*.html`: 생성 자산을 내장한 산출물. 각 문서의 문제·풀이 모델은 그대로 둔다.

## 검증 기준

정답, 오답, 모호 문항 각각의 화면 상태와 효과 시점을 확인한다. 8개 날짜의 모든 객관식이 초기화되고 정답·선택 테두리 규칙이 작동하는지 검사한다. 정리노트 HTML과 복습문제 Markdown은 변경하지 않는다.
