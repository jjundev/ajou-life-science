# 학습만화 비유·캐릭터·참조 연결 구현 계획

> **For agentic workers:** Use executing-plans for implementation; independent skill review follows.

**Goal:** 혼동을 비유와 캐릭터 대화로 해소하고 원본에서 정확한 만화 페이지로 연결한다.
**Architecture:** Python 표준 라이브러리 CLI를 유지한다. v2 콘티, 관리 참조 블록을 제외한 내용 지문, 발행 후 별도 재시도 가능한 연결기를 추가한다.
**Tech Stack:** Python 3.10+, HTML/CSS, Playwright, 내장 image_gen.
**Spec:** 이 대화에서 승인한 「만화 참조 연결과 비유·캐릭터 중심 설명」 설계.

## Global Constraints
- 페이지별 4~8컷, 원본 디자인 유지, 대사·정확한 표기는 HTML.
- 학생＋안내자 기본, 단일 설명자 허용. 비유 대응·한계 필수.
- 원본은 안내·링크만 변경. 파일과 해시 모두 비교하며 같은 탭으로 연결.
- 기존 v1 발행자료 보존, 새 실행으로 v2 전환. 자동 커밋·푸시 없음.

## Review Focus
- 참조 블록만 추가해도 재검토·재발행이 막히지 않아야 한다.
- 일반 본문·도해 변경과 조작된 관리 블록을 원본 변경으로 잡아야 한다.
- 같은 파일의 서로 다른 해시, 중복 ID, 없는 앵커를 안전하게 구별한다.
- 실제 한 페이지 샘플은 전체 강의 제작·보류와 명확히 구별한다.
- 대사와 등장인물 변경이 프롬프트와 검토 지문을 무효화한다.

- [x] 참조 연결 테스트: dry-run, 멱등성, 페이지 해시, 원본 바이트 보존, 쓰기 실패·본문 변경. 실패 확인 후 구현.
