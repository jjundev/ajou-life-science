> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 4장 웹과제 예상 HTML을 복습문제 HTML(`복습노트/*/복습문제_*.html`)과 같은 템플릿·채점 상호작용으로 다시 만든다. 결과물은 `웹과제예상/복습문제_4장_웹과제예상.html`이다.

**Architecture:** 복습팩 조립기 `.agents/skills/bio-review-pack/scripts/assemble.py`의 `build_review(m, run_dir)`를 그대로 호출한다. 이 함수가 `review-template.html`(한 카드씩 넘기는 화면, 목차·풀이 패널, 다크 모드)을 채우고 `review_interaction.install`로 보기 클릭 채점을 붙인다. 입력은 `웹과제예상/src/4장/pack.json`(manifest 일부 필드)과 `cards/<id>.html` 카드 조각이다. 얇은 빌드 스크립트 `scripts/build_webquiz_forecast.py`가 정리노트 링크만 0929 노트로 바꿔 저장한다. 카드는 두 종류다. 보기 없는 개요 카드 `o1`·`o2`는 채점에서 빠지고(`skipped`), 예상 모의문제 `p1`~`p15`는 채점된다.

**Tech Stack:** Python 3 stdlib(`unittest`, `json`, `re`), bio-review-pack 스크립트(`assemble`, `manifest`, `review_interaction`, `check_html`), 앱 내장 브라우저(상호작용·모바일·다크 확인).

**Spec:** 별도 설계 문서는 없다. 출처는 이 대화(2026-10-07)의 "4장 웹과제 예상" 답변과, 사용자 요청 "복습문제 html과 동일한 형식으로 다시 구현"이다. 앞 계획 `docs/superpowers/plans/2026-10-07-4장-웹과제예상.md`의 내용(형식 예상·주제표·막판 체크·모의문제 15개, 정답 DBCEBCACEADBEAD)을 이 계획의 카드로 옮긴다. 카드 규칙의 출처는 `.agents/skills/bio-review-pack/references/card-rules.md`이고, 필요한 규칙은 아래에 모두 옮겼다.

## Global Constraints

- 앞 계획의 산출물 `웹과제예상/4장_웹과제예상.html`은 지운다. `tests/test_webquiz_forecast_ch4.py`는 새 내용으로 통째로 바꾼다.
- 새 출력: `웹과제예상/복습문제_4장_웹과제예상.html`. 파일명은 `manifest.review_name(m)` = `복습문제_<range>_<slug>.html`과 같아야 한다(채점 모델 `documentId` 검사). 그래서 `range` = `4장`, `slug` = `웹과제예상`이다.
- `bio-review-pack`의 템플릿·스크립트·assets는 **고치지 않는다.** 재사용만 한다.
- 상단 "정리노트" 링크는 `../복습노트/0929/정리노트_0929_Heredity.html`로 바꾼다.
- 카드 마크업 순서(card-rules.md): `<h3>` → `div.problem` → `details.original` → `details.hint` → `details.solution`. 개요 카드는 `<h3>`와 `div.problem`만 둔다.
- 모의문제 카드: `<h3>`는 `PN. [예상] 제목`. 보기는 `<ul class="choices">` 안 `<li>A. …</li>`~`E.`(웹과제 형식). 풀이 `<ol class="steps">`에서 **모든 보기**에 `A. 맞아요/틀려요. 이유` 한 줄씩. 마지막 단계는 `수업과의 연결: …`이고 정리노트 토픽 링크를 붙인다. 정답 줄은 `<p class="answer">정답: X</p>`.
- 풀이·카드에 쓰지 않을 것: 원문자 ①~⑳, STT 녹음 시각, 사용법 안내 문장("답을 선택하면 …", "여기를 눌러 …"), 모호성 문구(`모호`, `모두 가능`, `답이 하나`, `해석에 따라` 등. 쓰면 `review_interaction`이 빌드를 막는다), 5장 용어(`헬리케이스`, `오카자키`, `코돈`, `전사`, `번역`), 4장 p9 `유전상담`.
- SVG는 카드 안에 인라인으로 넣는다. 클래스는 템플릿의 `fig-ink`, `fig-accent`, `fig-dot`, `fig-text`, `fig-muted`만 쓴다. `#` 색이나 `fill="`/`stroke="` 직접 지정은 쓰지 않는다. `role="img"`와 `aria-label`을 달고, `viewBox` 너비는 360 이하로 한다. `id`를 쓰면 `<pid>-` 접두어를 붙인다.
- 정답 분포: p1~p15 = `DBCEBCACEADBEAD`(A~E 각 3개).
- 유형 표시는 카드 `data-types` 속성이다. 필요 수: `부정형` ≥5, `계산` ≥4, `그림` ≥2, `ㄱㄴㄷ` ≥1, `쌍둥이` ≥1, `장섞기` ≥1.
- 출력 파일은 LF 줄바꿈으로 쓴다(`newline="\n"`).

## Review Focus

1. **정답이 화면에 미리 펼쳐짐**: 풀이가 열린 채 시작하면 연습 가치가 사라진다. 어떤 `<details>`에도 `open`이 없어야 한다. → Task 2 `test_no_open_details`.
2. **375px 폰에서 가로 넘침**: 개요 카드의 4열 표나 그림 SVG 때문에 페이지 전체가 가로로 밀릴 수 있다. 표는 `.table-wrap` 안에만 둔다. → Task 1 `test_tables_wrapped` + Task 3 브라우저 확인.
3. **다른 복습팩과 푼 기록이 섞임**: 템플릿은 `sessionStorage` 키에 `data-range`를 쓴다. `0929` 같은 날짜 range와 겹치지 않게 `data-range="4장"`이어야 한다. → Task 1 `test_range_isolated`.
4. **풀이 속 정리노트 링크 깨짐**: `#s2-frequency` 같은 앵커 오타는 클릭해야 드러난다. → Task 1·2 `test_checker_clean`(`check_html`의 broken-link가 앵커까지 검사).
5. **카드 수정 후 HTML을 다시 안 만듦**: 조각만 고치고 빌드를 잊으면 화면이 옛 내용으로 남는다. → Task 1 `test_output_is_fresh`.

import json
import re
import sys
import unittest
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]

import check_html  # noqa: E402
from scripts.build_webquiz_forecast import render  # noqa: E402


def source() -> str:
    return OUT.read_text(encoding="utf-8")


def model() -> dict:
    m = re.search(r'<script id="review-interaction-model" type="application/json">(.*?)</script>', source(), re.S)
    return json.loads(m.group(1))


def card(cid: str) -> str:
    m = re.search(rf'<article class="card" id="{cid}"[^>]*>(.*?)</article>', source(), re.S)
    if not m:
        raise AssertionError(f"카드 없음: {cid}")
    return m.group(1)


def text(html: str) -> str:
    return re.sub(r"\s+", " ", re.sub(r"<[^>]+>", " ", html)).strip()


class Build(unittest.TestCase):
    def test_output_is_fresh(self):
        name, html = render(SRC)
        self.assertEqual(name, OUT.name)
        self.assertEqual(html, source(), "카드 조각과 HTML이 다름: build_webquiz_forecast.py 다시 실행")

    def test_checker_clean(self):
        self.assertEqual([str(p) for p in check_html.check_file(OUT)], [])

    def test_note_link(self):
        self.assertIn('<a class="top-link" href="../복습노트/0929/정리노트_0929_Heredity.html">정리노트</a>', source())

    def test_range_isolated(self):
        self.assertIn('data-range="4장"', source())

    def test_old_page_removed(self):
        self.assertFalse((ROOT / "웹과제예상/4장_웹과제예상.html").exists())

    def test_overview_cards(self):
        o1, o2 = text(card("o1")), text(card("o2"))
        for term in ["13~17", "30%", "70%", "부정형", "ㄱㄴㄷ", "46문항", "유전 용어", "양성잡종",

                     "이수성", "2/3", "가계도", "X 불활성화", "성 결정", "장 섞기"]:
            self.assertIn(term, o1, f"o1에 '{term}' 없음")

`scripts/build_webquiz_forecast.py`:

```python
#!/usr/bin/env python3
"""웹과제 예상 문제 묶음(pack.json + cards/) → 복습문제 형식 HTML.

bio-review-pack의 assemble.build_review를 그대로 써서 복습문제 HTML과 같은 템플릿·채점 상호작용을 쓴다.
상단 정리노트 링크만 pack.json의 note_href로 바꾼다. 출력은 src 폴더의 두 단계 위(웹과제예상/)에 쓴다.
CLI: python scripts/build_webquiz_forecast.py 웹과제예상/src/4장
"""
from __future__ import annotations

import json
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT / ".agents/skills/bio-review-pack/scripts"))
import assemble  # noqa: E402
import manifest as manifest_mod  # noqa: E402


def load(src_dir: str | Path) -> dict:
    return json.loads((Path(src_dir) / "pack.json").read_text(encoding="utf-8"))


def render(src_dir: str | Path) -> tuple[str, str]:
    src_dir = Path(src_dir)
    m = load(src_dir)
    html = assemble.build_review(m, src_dir)
    default = f'href="{manifest_mod.note_name(m)}"'
    if html.count(default) != 1:
        raise assemble.AssembleError(f"정리노트 링크 자리를 찾지 못함: {default}")
    return manifest_mod.review_name(m), html.replace(default, f'href="{m["note_href"]}"')


def build(src_dir: str | Path) -> Path:
    name, html = render(src_dir)
    out = Path(src_dir).resolve().parents[1] / name
    out.write_text(html, encoding="utf-8", newline="\n")
    return out


def main(argv: list[str] | None = None) -> int:
    args = sys.argv[1:] if argv is None else argv
    if len(args) != 1:
        print("사용법: build_webquiz_forecast.py <src 폴더>", file=sys.stderr)
        return 2
    try:
        print(build(args[0]))
    except (assemble.AssembleError, ValueError) as e:
        print(f"빌드 실패: {e}", file=sys.stderr)
        return 1
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
