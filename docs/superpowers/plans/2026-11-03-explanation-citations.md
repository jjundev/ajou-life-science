# 문제설명 출처 표시 정리

**목표:** 생성 규칙과 기존 문제설명 HTML·MD에서 장·쪽수 출처 표시를 생략한다.
**설계:** 이 대화에서 확정한 #1–#4를 적용한다. 기존 해설 조각에는 자료 위치와 학습 설명이 섞여 있으므로, 내부 원본·근거는 보존하고 해설의 텍스트 노드에 표시 정리를 적용한다. 문제·원문·링크·수식·보충/결함 안내는 보존한다.
**구현:** Python 표준 라이브러리, 기존 HTML→MD 및 검토 계약.

- [x] 출처 단독/혼합 괄호와 원문 보존을 실제 build 테스트로 재현한다.
- [x] 해설 구역과 요약에 한정한 텍스트 변환을 추가하고 렌더러에 연결한다.
- [x] SKILL.md·authoring.md·verification.md의 출처 규칙을 통일한다.
- [x] 기존 산출물을 정리하고 HTML·MD 및 내부 원본의 대응을 검증한다.
- [x] 전체 스킬 테스트, 변경된 화면의 데스크톱/모바일·밝은/어두운 테마를 확인한다.

검토 중점: 학습 정보가 섞인 출처, 수업 밖 보충, 문항 결함/인쇄 정답 오류, 수식·코드·링크, 변경된 산출물에 대한 과거 검토 오인 방지.

구현 결정: 과거 내부 조각은 검토 근거이므로 수정하지 않았다. 렌더러에서 자료 위치 표시를 생략하며, 기존 발행분은 HTML 텍스트 구역만 직접 정리하고 대응 MD를 재생성했다. 과거 manifest·validation은 새 해시로 승인하지 않고 팩별 evidence/display-citations-20261103.json에 실제 표시 대조와 화면 검사 결과를 별도로 남겼다.

검증: 스킬 테스트 265개 통과. 기존 15팩·620문항을 1280×900/375×812·light/dark에서 2,480회 순회했으며 콘솔·수식·자원·외부 요청·문서 가로 넘침 오류는 0이었다. 원문·태그/속성·내부 조각은 보존했다.
