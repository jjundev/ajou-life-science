# 컷 내부 말풍선과 사물 중심 장면

## 요청과 선택

말풍선을 그림 아래에서 컷 내부로 이동한다. 비유의 관계가 학습 대상인 장면은 관련 사물만 보여 주고, 학생·안내자는 화면 밖에서 대화한다. 대화형·한 화자 설명형은 유지하고 그림 출연을 선택 사항으로 바꾼다. 분자가 의지를 가진 것처럼 사물에 입을 붙이지 않는다.

래스터에 한국어를 굽는 방식은 확대·모바일 줄바꿈이 어렵다. 고정 좌표의 HTML 오버레이는 긴 대사가 사물을 가릴 수 있다. 이미지와 같은 CSS Grid 안에 높이가 늘어나는 HTML 말풍선 영역과 그림을 합성하는 방식을 택했다. 그림은 위쪽40%를 비우고 핵심은 아래60%에 배치한다. 말풍선은 이름·좌우 위치로 화자를 구별하고 꼬리는 컷 바깥을 향한다. 원본 노트의 서체·색상·간격·탐색을 유지하며 그림과 말풍선은 밝은 종이 위에서 읽힌다.

## 수정 범위

- `comic_contract.py`: 모든 cast의 발언은 필수, 실제 출연은 선택. 빈 characters 목록이면 인물·얼굴·손을 제외하는 프롬프트를 생성한다.
- `comic_render.py`, `comic.css`: 대사를 figcaption에서 comic-scene 내부로 이동. DOM 읽기 순서대로 위쪽에 배치하고 좁은 화면/긴 대사에서도 핵심 그림 공간을 보존한다.
- SKILL·콘티·계약·이미지·검토 문서 및 기본 프롬프트에 동일 규칙을 반영한다.
- 기존 실제 바이러스 샘플의6이미지를 내장 image_gen으로 새로 생성했다. 짧은 대화와 보충 캡션으로 재편하고 원본7근거의 조건·예외를 보존했다. 원본 정리노트의 기존 링크는 같은 최종 HTML을 가리킨다.

## 검증

- 수정 전: 전 컷 characters=[] 시 `모든 등장인물의 출연과 발언 필요`로 실패, 렌더된 대사는 모두 figcaption 안에 있었다. 독립 에이전트가 같은 실패를 재현했다.
- 수정 후: 스킬 단위 테스트32개 통과. 새 회귀 검사는 사물 전용 페이지의 화면 밖 대화와 컷 내부 대사/figcaption 분리를 검증한다.
- 테스트용 이미지의3페이지·16컷 브라우저 검사: 1440×900/375×812 각각 light/dark 통과. 긴 대사도 실제 글자 경계·컷 경계·그림 핵심 영역과 대조했다. 처음 scrollWidth로 검사했을 때 꼬리 도형을 글자 넘침으로 세는 오탐이 있어 텍스트 Range의 경계를 검사하도록 고쳤다.
- 실제 샘플6PNG 전부 직접 확인. 원본 도해와 안팎 관계·유전체 대안·바이러스 형태·숙주 의존성·효소 예외·비유 한계를 대조했다. 독립 검토자가 데스크톱 라이트/모바일 라이트·다크 전6컷과 실제 DOM을 확인했다.
- 실제 샘플 브라우저4종: 17px 대사, 전 말풍선 컷 내부, 핵심 사물 가림 없음, 전 이미지 디코딩, 탐색/요약/테마/원본 왕복 통과. 최종 발행 HTML도4종으로 재검사했으며 정리노트→만화→원본 복귀가 모두 통과했다.
- skill-creator quick_validate, git diff --check, Impeccable detector(발견0건) 통과.

실제 모바일 기기나 Safari 검증은 수행하지 않았다. Playwright Chromium에서 화면 크기를 에뮬레이션했다. 이 자료는1105 전체가 아닌 s3-structure 한 페이지의6컷 샘플이다.
