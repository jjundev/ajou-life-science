- 인쇄 때 기존 패널 전체가 숨겨지므로 원본 details를 일시적으로 문항 안으로 옮기고 인쇄 종료 후 복원한다. 복제하지 않아 id와 그림이 중복되지 않는다.
- 0910의 첫 문항 id는 p2였다. 기존 번호를 유지하고 브라우저 검사의 p1 가정만 수정했다.

## 별도 리뷰와 수정

fresh-context 리뷰어가 P2 두 건을 발견했고 각각 재현 테스트 실패 후 수정하여 전체 검사를 통과했다.

1. 모호한 해설 표현 누락: 0910 p4와 0915 p3가 잘못 단정 채점됐다. 모든 기존 추가 해설 문단을 재검토하여 이 둘과 해석/수업 모형에 따라 판단이 달라지는 5개 문항(0910 p28·p40, 0917 p2·p17, 0922 p12)에 원래 해설 그대로 주의 안내를 추가했다. 모호성 안내는 총 13개다. 앞으로 같은 표현이 나오면 명시적인 검토 없이는 조립을 통과하지 않는다.
2. 수동 완료 표시: 저장된 답의 복원은 별도로 저장된 수동 완료 표시를 덮어쓰지 않도록 수정했다. 답 제출→표시 해제→새로고침에서 선택은 복원되고 완료 수는 0으로 유지되는 회귀 테스트를 추가했다.

새 mini-run을 실제 조립한 출력에서도 정답 클릭과 3개 해설 표시를 확인했다. 실제 PDF 인쇄(0929, 36쪽)에서 전체 해설과 수업 연결을 확인했고 인쇄 종료 후 패널 복원도 확인했다.

판단 보류 항목과 미해결 리뷰 지적은 없다. 저장 key의 과거 RANGE 기반 수동 완료 집합 구조는 기존 동작으로 유지하며, 신규 선택 기록은 파일명별로 분리된다.

## 후속 변경 검증: 보기별 접기·펼치기

전체 해설 자동 펼침을 내 선택·정답만 펼침으로 변경했다. 모든 보기의 반복 클릭 및 Space로 접기/펼치기, 채점·완료 기록 유지, 정답 선택 시 하나만 표시, 새로고침·초기화, 모바일·인쇄를 Chromium에서 확인했다. 브라우저 10개, Python 98개, Node 5개 테스트 통과. 기존 8개 HTML과 생성 스킬에 함께 적용했다.
