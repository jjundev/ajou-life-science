문제를 내 말로 읽어요

주어진 것: 광독립반응, 곧 캘빈 회로(Calvin cycle)가 돌아가려면 꼭 들어가야 하는 재료가 있어요.

구할 것: 네 보기 가운데 캘빈 회로에 반드시 요구되는 투입물질이 아닌 것 하나를 골라요.

쉽게 말하면, 캘빈 회로라는 공장의 재료 목록에 없는 물건을 찾는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

‘캘빈회로에서 반드시 요구되는 투입물질’이라는 단서에서 캘빈 회로의 요약식을 떠올려요: CO₂ + 2 NADPH + 3 ATP → (CH₂O) + 2 NADP⁺ + 3 ADP + 3 Pᵢ.

각 재료의 역할은 이래요. CO₂는 탄소 고정(carbon fixation) 단계에서 RuBP에 붙는 탄소 재료예요. ATP는 3-인산글리세르산(PGA)에 인산기를 주고 RuBP를 재생하는 데 쓰는 에너지예요. NADPH는 PGA를 G3P로 환원(reduction)하는 전자를 줘요.

FAD(flavin adenine dinucleotide)도 전자운반체지만, 세포호흡의 시트르산 회로에서 전자를 받아 FADH₂가 되는 분자예요. 광합성의 전자운반체는 NADP⁺/NADPH라는 것을 구별의 기준으로 써요.

관련 정리노트: 캘빈 회로의 세 단계

종이에 쓸 첫 줄

먼저 질문 방향을 적어요: “투입물이 아닌 것 1개”.

그다음 캘빈 회로의 투입물 목록을 써요: 캘빈 회로 투입물 = CO₂, ATP, NADPH. 보기를 하나씩 이 목록에 대조해 목록에 없는 것을 찾아요.

왜 이렇게 푸는지 함께 따라가요

(1) 맞아요(반드시 필요한 투입물이에요). ATP는 PGA를 인산화하고 RuBP를 재생하는 데 쓰여요. 목록에 있어요.

(2) 틀려요(투입물이 아니에요). FAD는 세포호흡의 시트르산 회로에서 전자를 받아 FADH₂가 되는 운반체예요. 캘빈 회로의 환원 단계에서 전자를 주는 것은 NADPH이고, FAD는 캘빈 회로에 들어가지 않아요.

(3) 맞아요(반드시 필요한 투입물이에요). CO₂는 RuBP에 고정되는 탄소 재료로, 없으면 탄소 고정 단계가 시작되지 않아요.

(4) 맞아요(반드시 필요한 투입물이에요). NADPH는 PGA를 G3P로 환원하는 전자를 줘요.

투입물이 아닌 것을 고르는 문제이므로, 답은 투입물이 아니라고 판정된 (2)예요.

완성 답과 검산

답 (2) FAD.

교과서 대조: 교과서 2장 p.47은 캘빈 회로가 투입물질로 CO₂, ATP, NADPH를 사용해 G3P를 방출한다고 적고, p.50의 요약식 CO₂ + 2NADPH + 3ATP → (CH₂O) + 2NADP⁺ + 3ADP + 3Pᵢ에도 FAD는 없어요. FADH₂는 p.42 그림 2.14에서 시트르산 회로의 산물로만 나와요.

소거로도 확인해요: 요약식에 등장하는 투입물 셋(CO₂, NADPH, ATP)을 지우면 남는 보기는 (2) 하나예요. 기출 2강 합본 41번(PDF 4쪽)의 표시 답도 ②예요.

이 문항에서 하기 쉬운 실수

NADH·FADH₂(세포호흡)와 NADPH(광합성)를 같은 종류로 묶어 ‘전자운반체니까 다 필요하다’고 판단하기 쉬워요. 광합성의 운반체는 P가 붙은 NADPH예요.

‘광독립반응’이라는 이름 때문에 ATP도 필요 없다고 생각해 (1)을 고르지 않아요. 빛이 직접 필요 없을 뿐, 명반응이 만든 ATP와 NADPH는 반드시 필요해요.

떠올릴 개념·공식

캘빈 회로: CO₂ + 2NADPH + 3ATP → (CH₂O) + 2NADP⁺ + 3ADP + 3Pᵢ. FAD/FADH₂는 세포호흡의 운반체.

첫 줄

“아닌 것 1개”를 적고 투입물 목록 CO₂·ATP·NADPH를 써요.

핵심 판단

ATP·CO₂·NADPH는 목록에 있고, FAD만 시트르산 회로 쪽 분자예요.

검산

교과서 p.47·p.50 요약식과 기출 표시 답 ②가 일치해요. 답 (2).
