# 1006 tRNA 생성·번역 참여·재사용 보충 (2026-10-13)

- 사용자 승인 설계에 따라 s3-trna의 기존 설명 아래에 trna-lifecycle 보충 상자를 추가했다.
- 각각의 유전자에서 만들어지는 mRNA/tRNA, 진핵세포 핵 유전자 기준의 생성·가공·세포질 이동, 안티코돈의 출처, 고정된 생성 순서가 없다는 점을 연결했다.
- tRNA 유전자 → tRNA 준비 → 아미노산 부착 → 번역 참여 → 빈 tRNA의 퇴장 → 다시 아미노산 부착의 순환을 도식화했다. tRNA 자체가 단백질 재료로 들어가지 않음을 명시했다.
- 근거: 교재 5장 인쇄 p.104–107을 이미지로 직접 확인했다(전사와 비단백질 암호화 유전자, tRNA 구조, 합성효소, 빈 tRNA 퇴장). 핵·세포질 이동 보충 근거는 Chatterjee et al., 2018, PMID 29191733의 검색된 초록에서 핵 전사·가공과 세포질 번역을 확인했다. 원문 페이지는 접근 제한으로 전체를 읽지 못했다.
- 수업에서 이 흐름으로 설명했다고 단정하지 않고 ‘보충 · 수업에서 다루지 않았어요’로 표시했다. 재사용은 교재의 아미노산 부착/빈 tRNA 퇴장을 잇는 기작 설명이다.
- HTML과 해당 MD, 새 SVG, manifest의 s3-trna 보충 여부·필수 용어를 동기화했다. 이 팩을 재작성할 때 현재 HTML/MD의 trna-lifecycle 및 재사용 순환을 보존해야 한다. 범용 템플릿이나 다른 날짜의 자료는 수정하지 않았다.
- 기존 미커밋 변경 위에 요청한 블록과 해당 토픽 요약만 추가됐음을 수정 직전 사본과 비교해 확인했다.
