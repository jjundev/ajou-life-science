# 복제 장면 입체화 — 딸 DNA 나선 감기 · 효소 음영 · 3D 토글

날짜: 2026-10-13
파일: `canvas/Main.dc.html` (생성물: `../인터렉티브_03_DNA_구조와_복제_3D.html`)
캔버스: https://claude.ai/artifact/592nYy4Lwta2FDT8MMGDFZ

## Intent
복제 모드의 딸 DNA는 분기점 뒤에서 `z = 0` 평면 사다리(`arm()`), 효소는 납작한 원(`k:5`)이라 돌려 봐도 종이 한 장처럼 보인다. 분기점에서 멀어진, 짝이 맞은 구간을 구조 모드처럼 오른나선으로 다시 감고, 효소를 빛 받은 반투명 구로 그린다. 3D 보기 오른쪽 위 아이콘 버튼 묶음(+, −, 시점 처음으로)에 **3D 토글**을 두고, 끄면 지금 화면(평면 사다리 + 납작한 효소)을 그대로 보여 준다.
Classification: bounded — `buildReplication`의 좌표 함수와 `draw`의 효소 그리기만 바꾸고, 렌더러와 타이밍 모델은 그대로.

## Behavior when done
- 복제 모드 3D 보기 오른쪽 위 버튼 묶음 맨 앞에 「3D」 버튼(눌림 상태 표시). 구조 모드에서는 안 보인다. 처음엔 켜짐.
- 켜짐: 분기점 뒤 짝이 맞은 딸 DNA가 오른나선(반지름·홈 비대칭은 구조 모드와 같음). 분기점 바로 뒤 2–3쌍, 아직 조각이 없는 지연가닥 주형(단일가닥)은 평평하게 열려 있다. 오카자키 조각이 생기면 그 구간이 점점 감긴다. 효소는 음영 구.
- 끔: 0.4초 동안 풀려서 지금과 똑같은 평면 사다리 + 납작한 효소. 동작 줄이기 설정이면 즉시 바뀐다.
- 재생·스크럽·단계 점프·테마 전환·시점 리셋·모드 전환과 무관하게 3D 상태 유지(저장은 안 함).

## Not in this round
- 복제 거품(양방향 분기점 2개) — 타이밍 모델 재설계가 필요한 별도 작업.
- 효소별 고유 모양(헬리케이스 고리 등) — 모델링 비용이 큼.
- 딸 가닥 간격 `AR = 0.62`를 0.34로 — 구도·라벨·효소 위치가 `AR`에 묶여 있음. 딸 나선은 구조 모드보다 늘어진 모양.
- 3D 상태 localStorage 저장 — 요청 없음.
