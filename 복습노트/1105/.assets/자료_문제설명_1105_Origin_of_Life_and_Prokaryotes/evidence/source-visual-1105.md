# 1105 문제설명 source_visual 검토

검토자: notes_microbes 에이전트. 범위: source.json의 20문항 조건·보기·그림·원문 출처 충실도. 이 문서는 실제 소스 대조의 증거이며, review.json 승인·빌드·해설 내용 검토·독립 블라인드 검산·브라우저 전체 검토를 대신하지 않는다.

## 현재 입력 확인

- source.json의 problems 20개를 모두 읽음. p1–p8은 실제 기출8, p9–p20은 생성12로 구별됨. 모든 문항은 하나의 객관식 질문이며 보기 목록을 소문항으로 합치거나 나누지 않았음.
- 원 복습문제 파일 SHA-256이 source.json의 sha256과 현재 일치함. 설명 저작 중 원 문제를 수정하지 않았음.
- 실제 기출은 PDF1–3쪽의 사전 렌더링 PNG를 눈으로 직접 읽어 대조함. p3의 추출 사진도 별도로 열어 원 페이지의 사진 배열·눈금과 대조함.
- 생성12는 최종 저장소 .pack/variants.md의 각 행과 최종 정리노트 실제 개념 앵커를 읽어 대조함. 교재 스캔은 PDF3–11쪽, 인쇄 p178–186의 필요한 본문·그림을 직접 확인함.
- p11·p17은 source.json의 conditions_html에 들어 있는 SVG를 그대로 꺼내 임시 스타일로 렌더링하고 지시선·라벨·구조를 직접 관찰함. 생성 조건을 원 기출이라고 주장하지 않음.

## 주의할 원문과 해설 검토에 넘길 사항

- p3 보기 (1)의 넓은 집단 비교는 입력 문언 그대로다. 출제 의도를 전형적 원핵 대 진핵의 짧은 세대기간과 단위시간의 변이 발생·선택 기회로 한정하고, 복제당 오류율 증가나 모든 다른 생물보다 반드시 빠르다는 뜻으로 확대하지 않는지 후속 content 검토가 확인해야 한다. 최종 노트에는 이 한계가 이미 보존돼 있다.
- p5의 진정세균영역영역은 실제 원 페이지에 있는 중복 오기로서 fidelity 오류가 아니다. 해설의 문항 결함 공개는 후속 content 검토 대상이다.
- p1의 외피는 실제 원문의 단백질 coat 문맥이며, 지질 envelope를 모든 바이러스의 공통 구조로 오해하지 않도록 해설에서 구별해야 한다.
- p19는 최종 설계·입력 모두 ㄷ을 숙주 리보솜 없이 단백질 합성으로 사용한다. 이전 설계표의 교정 기능 전칭을 현재 입력으로 가져오면 불일치다.
- source_visual 결론: 20/20 조건·보기·그림·생성 출처 구분에서 미해결 불일치 없음. p3·p5의 표현 한계는 별도 기록했으며 입력 수정으로 은폐하지 않음.
