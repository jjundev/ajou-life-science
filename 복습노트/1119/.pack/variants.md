# 1119 변형 연습 설계

13장 웹과제 원문이 없는 범위여서 공통 유형 참고 목표(쌍둥이 2, 그림 2, 상황 2 이상, 용어 2, 부정형 약 1/3)를 적용했다. 13문항에서 기본 10개(수준 1–2), 심화 3개(수준 3)를 목표로 잡았다. 독립 풀이에서 필요한 단계를 다시 대조한 결과 기본 11개·심화 2개다. p37은 두 수용체의 감지 위치를 같은 방식으로 대입하므로 수준 2로 조정했다. p44는 개별 단면적과 합산 단면적의 관계를 적용하므로 수준 2로 조정했다. 그림 2개는 개념 도식을 실제로 읽는 문제이고, 표를 읽는 문제 1개를 따로 세었다. ㄱㄴㄷ, 낯선 참 진술, 장 섞기는 선택 유형으로 이번에는 두지 않았다. 가는 관 모형은 수업에서 배운 유량·총 단면적 관계를 장치에 적용하는 전이다.
