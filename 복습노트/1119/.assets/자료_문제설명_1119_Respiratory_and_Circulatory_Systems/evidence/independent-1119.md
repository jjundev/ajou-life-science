# 1119 독립 검토

정리노트와 문항에 연결된 그림만으로 P1–P46을 먼저 풀고, 독립 판정을 `reports/blind.tsv`에 기록했다. 이후 강의노트와 교재 13장으로 선택지 해석을 대조했다.

| 문항 | 판정과 자료 근거 |
| --- | --- |
| P1 | (1). 정리노트는 골수까지 설명한다. 교재 p.300은 적혈구와 백혈구가 적색 골수 줄기세포에서 발생한다고 설명한다. 강의노트 p4도 백혈구의 적색 골수 기원을 명시한다. |

| P14 | (1). 강의노트 p2와 교재 p.293 모두 최대 강제 호기 후에도 공기가 남는다고 명시한다. 같은 교재 쪽은 (2) 신체 활동에 따른 1회 호흡량 증가, (3) 폐활량을 '최대 1회 호흡량'으로 부르는 표현, (5) 폐포 공기와 폐 혈액 사이의 지속되는 기체교환도 직접 확인해 준다. (3)은 교재 맥락에서 맞다. 해설에서는 평소 한 번의 공기 이동량과 최대 들숨 뒤 최대 날숨으로 움직인 양을 구별한다. |
