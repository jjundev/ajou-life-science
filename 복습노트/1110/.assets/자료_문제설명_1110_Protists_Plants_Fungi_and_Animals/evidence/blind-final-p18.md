# 18번 최종 블라인드 검증

| 항목 | 판정 |
|---|---|
| 내 답 | **② 정자는 꽃가루 안에서 발생한다.** |
| 노트의 직접 근거 | 「꽃가루·밑씨·씨방은 서로 다른 단계」의 ‘밑씨 안에는 난세포가 형성되고, **꽃가루 안에서 정자 세포가 발달해요**.’ |
| ④ 배제 근거 | 같은 토픽의 보충: ‘**겉씨식물의 포자체도 감수분열로 포자를 만들지만, 포자는 배우체가 발달하는 생식 구조 안에 머물러요. 포자를 만드는 것과 포자를 외부에 독립적인 산포 단위로 퍼뜨리는 것은 달라요.**’ 따라서 ④의 ‘포자를 퍼트린다’를 외부 산포로 읽으면 틀리다. |
| 다른 보기 | ① 꽃은 속씨식물의 구조, ③ 겉씨식물도 종자를 가짐, ⑤ 겉씨식물 수분에 자유로운 물이 꼭 필요하지 않음: 모두 노트가 직접 설명한다. |
| 단일정답성 | **② 유일.** ④의 일상적인 ‘퍼트린다’는 외부로 퍼지는 뜻이며, 노트가 포자 생산과 외부 산포를 구분해 이전 근거 공백을 메웠다. |
| 실제 최소 수준 | **1** — 정자 발달 위치를 노트 문장과 바로 대응하면 ②를 선택할 수 있다. |
| 남은 우려 | ④의 ‘퍼트린다’가 과학적으로는 외부 독립 산포를 뜻한다는 문맥이 노트의 보충에만 있고 문제 문장 자체에는 없다. 보충을 읽은 학습자에게는 유일하나, 포자 ‘생산’과 ‘산포’를 혼용하면 혼란이 남을 수 있다. |

허용된 최종 정리노트와 블라인드 18번 원문만 사용했다.
