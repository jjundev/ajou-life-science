14장 면역계는 11월 24일에 시작해 11월 26일 대면 수업에서 알레르기까지 마쳤어요.

## 3. 보류 문항 재분류

14강 합본의 유효 기출 51개 가운데 34개를 1124 복습문제에, 16개를 1126 복습문제에 실었어요. 52번은 보기 번호만 있는 편집 자리표시자예요.

- 1124의 보류 17개 중 **1, 6, 7, 12, 21, 24, 29, 30, 32, 34, 35, 38, 39, 40, 44, 47번**을 1126에 실었어요. 32번의 사이클로스포린 A는 교재 321쪽을 근거로 [도움 T세포의 역할](../정리노트_1126_Immune_System.html#s1-linked-help)에 보충했어요.
- **18번 · 범위 불명.** 항체를 생체분자 연구와 검사에 활용하는 사례는 강의노트 6쪽에 있어요. 11월 26일 수업은 세포매개면역을 마치고 곧장 면역계 기능 장애로 넘어갔어요. 해당 항목의 개별 시험 범위를 지정한 발언이나 공지는 확인되지 않았어요.
- 21번·34번은 인쇄 답 외에 퇴행성 관절염 보기도 성립할 수 있어요. 두 문항의 풀이와 [자가면역 보충](../정리노트_1126_Immune_System.html#s3-autoimmunity)에 강의자료의 용어 차이를 표시했어요.

남은 미수록 유효 문항 재분류는 시험 범위 확인됨 0 · 보충 학습 권장 0 · 제외 근거 있음 0 · 범위 불명 1이에요. [1124 복습문제](../../1124/복습문제_1124_Respiratory_and_Circulatory_Systems_and_Immune_System.html) · [1126 복습문제](../복습문제_1126_Immune_System.html)

## 4. 시험 범위

강의계획서 6–7쪽은 13주차에 14장 면역계를 배정하고, 16주차 기말고사에 9–15주 학습 내용을 다룬다고 명시해요. 11월 26일 수업 말미에는 15·17·18장과 15장 일부 생략을 이어 안내하면서 강의노트와 영상의 내용을 기준으로 공부하라고 했어요. 따라서 14장은 장 단위에서 기말 학습 범위에 들어가며, 수업에서 건너뛴 6쪽 항체 활용과 8쪽 특집의 개별 포함 여부는 불명이에요.

## 5. 변형 연습 풀이 점검

- 1124의 14장 변형 11개(p42–p52)는 블라인드 풀이에서 모두 설계 정답과 일치했어요. p48은 결합 부위가 달라도 같은 항원의 서로 다른 에피톱에 붙을 수 있다는 이의가 나와 표현을 보완한 뒤 다시 풀었어요. p49도 독립 풀이에서 수준을 재확인했어요. 재확인 결과 두 문항 모두 답이 일치했고 이의가 없었어요.
- 1126의 14장 변형 13개(p17–p29)는 정리노트만 읽고 다시 풀었을 때 13개 모두 설계 정답과 일치했어요. 변형 문항에 대한 이의나 풀이 근거 누락은 없었어요. 실제 풀이 단계에 맞춰 난이도를 다시 분류했어요.

## 6. 웹과제 실제 문항의 본문 피드백

14장 웹과제의 문제은행, 원본 캡처와 본문 피드백 파일이 저장소에 없어요. 1124·1126 본문 피드백 감사에서 14장 피드백 ID는 0개였어요.
