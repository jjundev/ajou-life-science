# 브라우저 화면 직접 확인

검토자 /root. 1280×900·375×812, light/dark의 8개 조합에서 56문항의 recall 링크 전수 실제 클릭(총260회), 목적지 id와 표시 여부 확인. 문제설명 자체의 외부 요청·콘솔·KaTeX 오류·문서 가로 넘침은 0. 기존 정리노트의 CDN 로드는 별도 기록했으며 정리노트는 변경하지 않음.

직접 열어 본 스크린샷: 1013 PC p29(겔의 음극 홈/양극 방향·A/B/C 밴드)와 p34(핵·난자·자궁 제공자), 1015 PC p10(엑손 A-B/A-C)과 dark p11(안내 RNA/절단 단백질), 1013 mobile p29 및 1015 mobile dark p19. 그림 라벨·본문·링크를 확인했고 링크 문구와 목표 개념이 일치함.

최종 해설 페이지는 stage에서 제공하되 목적지 정리노트와 원 문제는 실제 저장소 파일을 제공하는 로컬 HTTP overlay로 확인. 발행 직후 파일 SHA256 및 실제 file:// 링크 이동은 별도 최종 점검 대상으로 둠.
