# 컷별 이미지 제작

내장 이미지 생성 도구를 사용한다. 필요하면 사용 가능한 `imagegen` 스킬의 내장 도구 워크플로를 읽는다. 이 스킬은 별도 API 키·결제·제3자 업로드를 요구하지 않는다.

## 생성 단위와 일관성

[공통 그림체](style.md)를 읽고 해당 장면의 승인 참조 이미지를 실제로 확인한다. 인물·생물 구조·과정·비유 사물 모두 같은 플랫 윤곽선·면색·배경을 사용한다. 참조는 그림체용이며 과학 구조와 장면의 근거는 원본·콘티다.

배정된 작업 파일의 `jobs`에 있는 프롬프트와 같은 폴더의 고정 참조 파일을 사용한다. 한 컷당 실제 도구를 한 번 호출하는 것을 기본으로 한다. `characters`가 비면 사물·구조만 그린다. 캐릭터를 그려야 할 때는 필요한 외형과 행동을 구체적으로 명시한다. 방향·구조·개수·보여야 하는 조건은 컷의 `scene`에 쓴다.

기본 승인 참조는 인물 컷에 `flat-people`, 사물 컷에 `flat-objects`다. 구조나 과정에는 컷에서 `style_reference`로 `flat-structure` 또는 `flat-process`를 고를 수 있다. 원본 도해나 승인된 기준 컷이 필요하면 `art_references`에 종류(`structure` 또는 `continuity`)와 저장소 상대 경로를 적는다. 첫 컷을 같은 페이지의 기준으로 쓸 때는 `prepare --stage generate --panel 1`로 해당 컷을 먼저 등록하고 그 실제 파일을 뒤따르는 컷의 참조로 지정한다. 각 참조의 역할과 실제 파일 지문은 배정에 고정된다.

## 읽을 수 있는 그림

- 한 컷에 구체적인 관찰 대상·행동·변화가 보여야 한다. 문장만 다른 동일한 실험실 풍경을 반복하지 않는다.
- 모양·크기·개수·막의 안팎·가닥 방향·염색체 관계·효소의 작용 표적을 원본과 대조한다.
- 이미지 위쪽 40%는 조용한 종이 여백으로 비우고 중요한 사물·관계는 아래쪽 60%에 온전히 배치한다. 내부 테두리를 그리지 않는다. HTML 말풍선이 해당 여백에 합성되므로 모든 컷에서 실제 가림을 확인한다.
- 정확한 글자·화살표 라벨·수식·단위는 HTML caption/dialogue에 쓴다. 그림에는 글자·말풍선을 생성하지 않는다. **이미지에 말풍선을 굽지 않는다는 뜻이며, 완성된 컷에는 HTML 말풍선이 들어간다.**
- 밝은 종이 배경을 유지한다. 다크 테마에서는 주변 HTML과 말풍선만 테마를 바꾼다. 색만으로 개념을 구별하지 않는다.

## 변경과 재사용

현재 생성 지문과 파일 해시가 일치하면 그림을 재사용한다. 문구가 그림의 실제 대상·동작·관계를 바꾸면 `scene`도 수정한다. 말풍선·보충 배지·비유의 한계만 바뀌면 내용과 합성 화면을 다시 확인한다.

같은 프롬프트의 그림을 실제 검토에서 수정해야 하면 `prepare --stage generate --redo --panel 컷번호`로 해당 컷을 재배정한다. 결과 등록에는 배정 지문과 실제 파일 해시가 필요하다. PNG·JPEG·WebP의 짧은 변은 256px 이상이어야 한다. 브라우저에서 실제 디코딩과 로딩을 검사한다.

위임·도구·파일 확보가 실패하면 성공한 컷과 실패 원인을 구별해 반환한다. 실제 학습만화에는 도구에서 얻은 그림을 사용한다.

신규·재생성 호출을 따로 집계하려면 생성 보고서에 `calls_by_panel`(예: `{"1": 1, "2": 2}`)을 남긴다. 실제 호출 수 합계와 일치해야 한다.
