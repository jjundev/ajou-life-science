# 컷별 이미지 제작

내장 이미지 생성 도구를 사용한다. 필요하면 사용 가능한 `imagegen` 스킬의 내장 도구 워크플로를 읽는다. 이 스킬은 별도 API 키·결제·제3자 업로드를 요구하지 않는다.

## 생성 단위와 일관성

`prompts`는 페이지마다 4~8개, 컷마다 하나의 프롬프트를 만든다. 각 작업의 `page`, `panel`, `prompt`, `output`을 확인하고 생성 결과를 `register-image`로 등록한다. `output`은 저장할 위치의 안내이며 파일이 이미 존재한다는 뜻이 아니다. 실제로 도구가 반환한 로컬 파일을 `--image`에 넣는다. PNG/JPEG/WebP를 지원하며 짧은 변 256px 이상이어야 한다. 실사용에는 더 높은 해상도를 사용하고 모바일/데스크톱의 실제 표시 크기에서 확인한다.

컷의 `characters`에 명시한 사람만 그린다. 빈 목록이면 관련 사물·구조만 그리고 사람·얼굴·손을 넣지 않는다. 화면 밖 화자의 대사 때문에 사람을 다시 그리지 않는다. 캐릭터가 출연할 때는 표정·행동이 이해를 돕는지 확인한다. 비유 사물이 이해할 관계를 보여 주는지 확인하고 실제 생물 구조 안에 문자 그대로 넣지 않는다. 프롬프트는 출연자 정의·대사 의미·비유 대응과 한계를 포함한다.

반복 대상의 형태가 중요하면 첫 컷의 실제 파일을 다음 생성의 참조로 사용한다. 참조 이미지는 스타일/동일 대상 유지용임을 명시하고 이번 컷의 실제 상태를 따로 쓴다. 원본 도해는 구조 근거, 이전 컷은 외형 연속성 근거이므로 역할을 구별한다.

## 읽을 수 있는 그림

- 한 컷에 구체적인 관찰 대상·행동·변화가 보여야 한다. 문장만 다른 동일한 실험실 풍경을 반복하지 않는다.
- 모양·크기·개수·막의 안팎·가닥 방향·염색체 관계·효소의 작용 표적을 원본과 대조한다.
- 이미지 위쪽 40%는 조용한 종이 여백으로 비우고 중요한 사물·관계는 아래쪽 60%에 온전히 배치한다. 내부 테두리를 그리지 않는다. HTML 말풍선이 해당 여백에 합성되므로 모든 컷에서 실제 가림을 확인한다.
- 정확한 글자·화살표 라벨·수식·단위는 HTML caption/dialogue에 쓴다. 그림에는 글자·말풍선을 생성하지 않는다. **이미지에 말풍선을 굽지 않는다는 뜻이며, 완성된 컷에는 HTML 말풍선이 들어간다.**
- 밝은 종이 배경을 유지한다. 다크 테마에서는 주변 HTML과 말풍선만 테마를 바꾼다. 색만으로 개념을 구별하지 않는다.

## 변경과 재사용

`reusable`은 공통 스타일·페이지 질문·장면·caption·근거·컷 위치가 같은 프롬프트와 실제 파일 해시를 확인한 결과다. 프롬프트가 같아도 사람이 그림 의미가 틀렸다고 판단하면 재생성한다. 대사·출연자·캐릭터 외형·비유 정보 변경은 해당 프롬프트와 그림 재사용을 무효화한다. 요약/연결 문구 변경도 내용·그림·브라우저 검토를 무효화한다. 장면 의미가 바뀌면 scene/caption도 함께 고친다.

이전 그림을 바꿀 때는 새 이미지를 실제로 확인하고 같은 컷으로 다시 등록한다. 다른 컷의 파일·검토 지문을 이름만 바꿔 가져오지 않는다. 이미지 헤더 검사는 완전한 이미지 디코딩 검사가 아니므로 브라우저에서 `naturalWidth`와 로딩 오류도 검사한다.

도구가 없거나 저장 경로를 확보할 수 없으면 해당 페이지를 보류한다. 도형·스톡 이미지·빈 래스터로 만화 그림의 완료 수를 채우지 않는다. 테스트가 사용하는 단색 PNG는 자동화 검사 전용이며 실제 수업 만화로 발행하지 않는다.
