# 페이지별 콘티 기준

## 장면이 설명하게 하기

페이지의 핵심 질문 하나를 잡고, 답을 이해하는 데 필요한 관찰 대상·시작 조건·상태 변화·결과를 그림과 대사로 연결한다. 컷마다 무엇이 달라졌고 어떤 근거를 배웠는지 설명할 수 있어야 한다. 제목과 요약 문장을 여러 그림 아래 나눠 놓는 방식은 피한다.

- **정의·구조:** 실제 대상의 외형과 부분 → 부분이 하는 일 → 구별 사례. 이동이 없는 구조에 가짜 시간 변화를 붙이지 않는다.
- **과정·실험:** 질문 → 재료/조건 → 조작·작동 → 직접 관찰값 → 해석과 한계. 측정값과 해석을 분리한다.
- **비교·분류:** 같은 비교 질문을 두 대상에 적용하고, 경계 사례를 판단하는 장면으로 마무리한다. 역사·진화적 선후관계가 없는 분류를 진화 사다리로 그리지 않는다.
- **계산:** 출발 데이터·구하려는 값 → 필요한 관계 → 대입·계산 → 값의 해석과 조건. 식·단위는 HTML에 쓴다.
- **복습·전체 요약:** 원본의 핵심 항목들을 컷당 관련 묶음으로 연결한다. 8컷에 어렵다면 한 컷에서 비교할 수 있는 범위를 묶고 우측 용어에 조건을 보존한다. 범위를 다룰 수 없으면 보류 사유를 남긴다.

4컷은 단순 정의/대조, 6컷은 기본 과정, 8컷은 필수 중간 단계·조건·예외가 있는 경우의 출발점이다. 목표 수를 채우기 위한 장면은 만들지 않는다. 페이지를 합치거나 주요 페이지를 대표 몇 개로 대체하지 않는다.

## 혼동 → 비유 → 실제 개념

각 페이지에서 구별하기 어려운 관계 하나를 `clarification`으로 먼저 적는다. 원본과 학생 기록으로 확인할 수 있는 범위를 구별하고, 개인의 약점을 추측해 단정하지 않는다. 이미 아는 사물·상황의 **관계**로 설명하고, 비유의 대응과 한계를 `analogy`에 기록한다. 단순히 생물에 별명을 붙이는 것만으로 비유를 충족하지 않는다.

권장 흐름은 혼동 제시 → 익숙한 상황 → 관계 관찰 → 실제 개념과 대응 → 적용과 한계다. 정의·실험·비교·요약에 맞게 순서를 조정하고 4~8컷 안에서 핵심 조건을 유지한다. 매 페이지에 같은 줄거리를 강요하지 않는다. 좋은 대응을 만들 수 없으면 과학적 관계를 왜곡하지 말고 콘티를 다시 쓰거나 이유와 함께 보류한다.

비유 장면과 실제 구조는 그림·대사에서 명확히 구분한다. 예를 들어 USB와 컴퓨터는 바이러스의 숙주 의존성을 설명하지만, 실제 감염이 USB를 꽂는 과정과 같다는 뜻은 아니다. 비유의 한계가 긴 부록에만 묻히지 않게 해당 페이지에서 설명한다.

## 캐릭터가 이해를 이끌기

기본 화자는 같은 차수에서 반복되는 **학생＋안내자** 두 명이다. 간단한 주제는 한 화자 설명형으로 한다. `characters`의 외형·역할·말투, 페이지 `narrative`의 cast, 컷별 실제 출연자와 화자 ID를 명시한다. **화자의 존재와 얼굴의 노출을 분리한다.** USB·컴퓨터의 작동 관계나 구조 비교가 주제인 컷에서는 관련 사물만 확대하고 대화는 화면 밖에서 이어간다. 불필요한 인물을 넣기 위해 관찰 대상을 줄이지 않는다.

- 한 명 설명형: 캐릭터가 사물·모형을 보여 주며 관찰 → 관계 → 결론을 자신의 말로 연결한다.
- 두 명 이상 대화형: 질문, 반례, 설명, 자기수정으로 상대의 발언에 반응한다. 서로 독립된 요약문을 차례로 읽는 방식은 피한다.
- 화자는 핵심 추론을 대사로 전달한다. 그림 출연은 표정·행동·상호작용을 볼 필요가 있을 때 선택한다. 사물 중심 페이지는 전 컷 `characters: []`도 가능하다. 말 없는 확대·관찰 컷도 허용한다. 캡션은 조건·정확한 용어를 보완한다.
- 사람을 기본으로 하되 생물·분자의 실제 관계를 가리지 않는다. 분자가 판단하거나 진화가 목적을 향해 움직인다는 의인화는 피한다.
- 같은 대상과 인물의 외형·색·관찰 시점 약속을 유지한다. 대사는 짧게 시작하되 조건을 삭제하지 않는다.

## 컷 내부 말풍선

한 컷의 위쪽에서 질문→응답 순서로 짧은 말풍선을 읽고 바로 아래 사물의 관계를 관찰하게 한다. 말풍선은 이미지와 같은 `.comic-scene` 안에 HTML로 합성하므로 한국어를 선택·확대할 수 있다. 이미지 자체에는 글자를 넣지 않는다. 그림의 위쪽 40%는 조용한 종이 여백, 중요한 사물·작동은 아래쪽 60%에 둔다. 조립기는 말풍선 높이에 따라 컷을 늘려 모바일에서도 그림의 핵심 영역을 보존한다. 긴 해설을 작은 글자로 압축하지 말고 대사를 줄이거나 조건을 캡션·우측 용어에 정확히 남긴다. 화면 밖 화자의 말풍선은 화자 이름과 일관된 좌우 배치로 구별하며 꼬리를 생물·사물 쪽으로 향하게 하지 않는다.

## 원본 충실성

근거 ID는 `source.json`의 토픽별 실제 문장이다. 각 컷의 설명·대사·그림 의미를 지지하는 항목을 `evidence`에 기록한다. 여러 근거를 결합해 설명할 수 있지만 원본에 없는 인과관계를 추가하지 않는다. 원본 그림에만 있는 정보는 원본 그림을 직접 보고 확인하고 검토 기록에 원본 그림 ID/관찰 사항을 남긴다. 텍스트 ID가 그림의 정확성을 자동 보장하지 않는다.

`coverage`에는 원본 근거마다 컷 번호 또는 생략 이유를 기록한다. 반복·주변 사례는 이유와 함께 생략할 수 있다. 개념의 성립 조건, 수치·단위, 예외, 원인과 결과, 핵심 비교 기준, 교수님이 강조한 오류 방지는 남긴다. 단순한 `분량 부족`은 핵심의 생략 이유가 아니다.

보충 근거가 참조된 컷·요약·용어에는 조립기가 원본의 보충 배지를 표시한다. 보충 사실을 설명하면서 보충 근거 참조를 빼는 식으로 표시를 우회하지 않는다. 가설과 확립된 사실, 실험의 모형 조건과 실제 과거, 관찰과 추정의 강도를 유지한다.

## 예시: 밀러–유레이 실험의 6컷 흐름

1. 생명에 필요한 작은 재료도 생길 수 있을까? 실험 질문을 보여 준다.
2. 가정한 기체 조건을 준비한다. 실제 과거 대기의 확정 조성으로 표현하지 않는다.
3. 전기 방전으로 에너지를 공급한다.
4. 순환·냉각·수집으로 분석할 시료를 모은다.
5. 아미노산 같은 유기물이 검출된 관찰값을 보여 준다.
6. 유기물의 합성과 살아 있는 세포의 생성, 실제 생명 탄생 경로의 입증을 구분한다.

이 흐름만으로 원본 페이지의 모든 내용이 포함되었다고 판단하지 않는다. 메탄의 유기물 여부, 다른 환경 가설, 용기·광물의 역할 등 원본의 나머지 주장도 coverage에서 대조하고 필요한 경우 7~8컷이나 짧은 설명으로 반영한다. 이 예시는 대본 복사본이 아니다.
