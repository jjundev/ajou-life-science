# 페이지별 콘티 기준

## 장면이 설명하게 하기

페이지의 핵심 질문 하나를 잡고, 답을 이해하는 데 필요한 관찰 대상·시작 조건·상태 변화·결과를 그림과 대사로 연결한다. 컷마다 무엇이 달라졌고 어떤 근거를 배웠는지 설명할 수 있어야 한다. 제목과 요약 문장을 여러 그림 아래 나눠 놓는 방식은 피한다.

- **정의·구조:** 실제 대상의 외형과 부분 → 부분이 하는 일 → 구별 사례. 이동이 없는 구조에 가짜 시간 변화를 붙이지 않는다.
- **과정·실험:** 질문 → 재료/조건 → 조작·작동 → 직접 관찰값 → 해석과 한계. 측정값과 해석을 분리한다.
- **비교·분류:** 같은 비교 질문을 두 대상에 적용하고, 경계 사례를 판단하는 장면으로 마무리한다. 역사·진화적 선후관계가 없는 분류를 진화 사다리로 그리지 않는다.
- **계산:** 출발 데이터·구하려는 값 → 필요한 관계 → 대입·계산 → 값의 해석과 조건. 식·단위는 HTML에 쓴다.
- **복습·전체 요약:** 원본의 핵심 항목들을 컷당 관련 묶음으로 연결한다. 8컷에 어렵다면 한 컷에서 비교할 수 있는 범위를 묶고 우측 용어에 조건을 보존한다. 범위를 다룰 수 없으면 보류 사유를 남긴다.

4컷은 단순 정의/대조, 6컷은 기본 과정, 8컷은 필수 중간 단계·조건·예외가 있는 경우의 출발점이다. 목표 수를 채우기 위한 장면은 만들지 않는다. 페이지를 합치거나 주요 페이지를 대표 몇 개로 대체하지 않는다.

## 서술과 등장 대상

학생·관찰자가 질문하거나 정정하는 인물은 필요할 때만 쓴다. 생물·분자 자체를 설명의 중심에 둔다. 컷당 대사는 짧게 시작하되, 조건을 삭제해서 길이를 맞추지 않는다. HTML 설명과 대사에 핵심을 남겨 그림만으로 추론해야 하는 사실을 줄인다.

같은 대상은 같은 색·모양·방향 약속을 유지한다. 분자·세포를 눈/표정으로 구분해도 실제 결합 위치·막 구조·가닥 방향·염색체 개수를 왜곡하지 않는다. 의인화가 의도·목적·필연성을 암시하면 관찰자의 말이나 설명으로 바꾼다. 비유의 한계가 핵심이면 같은 페이지에서 밝힌다.

## 원본 충실성

근거 ID는 `source.json`의 토픽별 실제 문장이다. 각 컷의 설명·대사·그림 의미를 지지하는 항목을 `evidence`에 기록한다. 여러 근거를 결합해 설명할 수 있지만 원본에 없는 인과관계를 추가하지 않는다. 원본 그림에만 있는 정보는 원본 그림을 직접 보고 확인하고 검토 기록에 원본 그림 ID/관찰 사항을 남긴다. 텍스트 ID가 그림의 정확성을 자동 보장하지 않는다.

`coverage`에는 원본 근거마다 컷 번호 또는 생략 이유를 기록한다. 반복·주변 사례는 이유와 함께 생략할 수 있다. 개념의 성립 조건, 수치·단위, 예외, 원인과 결과, 핵심 비교 기준, 교수님이 강조한 오류 방지는 남긴다. 단순한 `분량 부족`은 핵심의 생략 이유가 아니다.

보충 근거가 참조된 컷·요약·용어에는 조립기가 원본의 보충 배지를 표시한다. 보충 사실을 설명하면서 보충 근거 참조를 빼는 식으로 표시를 우회하지 않는다. 가설과 확립된 사실, 실험의 모형 조건과 실제 과거, 관찰과 추정의 강도를 유지한다.

## 예시: 밀러–유레이 실험의 6컷 흐름

1. 생명에 필요한 작은 재료도 생길 수 있을까? 실험 질문을 보여 준다.
2. 가정한 기체 조건을 준비한다. 실제 과거 대기의 확정 조성으로 표현하지 않는다.
3. 전기 방전으로 에너지를 공급한다.
4. 순환·냉각·수집으로 분석할 시료를 모은다.
5. 아미노산 같은 유기물이 검출된 관찰값을 보여 준다.
6. 유기물의 합성과 살아 있는 세포의 생성, 실제 생명 탄생 경로의 입증을 구분한다.

이 흐름만으로 원본 페이지의 모든 내용이 포함되었다고 판단하지 않는다. 메탄의 유기물 여부, 다른 환경 가설, 용기·광물의 역할 등 원본의 나머지 주장도 coverage에서 대조하고 필요한 경우 7~8컷이나 짧은 설명으로 반영한다. 이 예시는 대본 복사본이 아니다.
