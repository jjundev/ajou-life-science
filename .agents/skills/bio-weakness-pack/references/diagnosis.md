# 공부 기록에서 보완 대상 고르기

## 자료의 역할

- 선택한 SSTT: 약점 후보를 고르는 근거. 같은 날짜 파일은 기본 파일 다음 숫자 순서로 읽는다. 각 파일에서 발언의 뒤쪽 정정까지 확인한다. 파일 마지막의 다음 회차 안내만으로 그 회차까지 포함하지 않는다.
- 기존 `복습노트/`: 관련 개념의 설명·그림·맥락을 실제로 읽는다. 공부 날짜와 원래 수업 날짜가 다를 수 있으므로 날짜와 개념으로 찾는다. 어떤 노트·토픽을 확인했는지 기록한다. 기존 노트의 존재는 학습자가 읽었다는 증거가 아니다.
- 강의자료·교재: 정의·조건·그림·정답을 검증한다. 교재 스캔은 필요한 쪽을 렌더링해 직접 확인하고 인쇄 쪽과 PDF 쪽을 구분한다. 자료 충돌은 비교·공개하며 기존 노트의 표현만으로 확정하지 않는다.
- 실제 문제: SSTT에서 원문을 특정할 수 있을 때만 대조한다. 선택지·최종 제출·공식 답을 녹음에서 복원해 단정하지 않는다. 웹과제 피드백이 해당 개념과 관련 있으면 참고하되 개인의 오답으로 바꾸지 않는다.

기존 복습노트에 관련 자료가 없으면 검색 범위와 부재를 적고 강의자료·교재로 진행한다. 그 자료들로도 검증할 수 없는 설명은 보류한다. 외부 검색은 기본 절차에 포함하지 않는다.

## 판정과 학습량

| status | 관찰 | 반영 |
|---|---|---|
| uncorrected | 혼동 발언 이후 명확한 정정이 확인되지 않음 | 정의·비교 기준·작은 사례와 적용 문제 |
| self_corrected | 뒤에서 스스로 정정함 | 정정을 인정하고 짧게 재확인 |
| hesitant_application | 원리는 말하지만 문항 적용에서 망설임 | 판단 기준과 조건을 바꾼 적용 |
| name_recall | 이름이 바로 떠오르지 않음 | 명칭과 현상의 양방향 회상 |

혼동인지 전사 오류인지 불명확한 신호는 `excluded`에 이유와 확인 방법을 적고 오개념 교정 문제로 만들지 않는다. 말더듬·욕설·발음 오류 자체, 무응답, 정답을 말한 사실만으로 약점·숙련을 확정하지 않는다. 첫 발언과 자기교정을 함께 기록한다. 설명 후 성공·최초 독립 회상·장기 기억 확인을 혼동하지 않는다. 순위는 반복된 혼동, 다른 개념의 선행 조건, 적용 어려움에 따라 정하되 기계적 점수·문항 수로 숙련을 산정하지 않는다.

## diagnosis.json 계약

`plan.json`의 `inputs`를 그대로 복사한다. 경로는 저장소 상대 경로이며 Unicode NFC로 기록하고 실제 파일은 정규화해 찾는다. 참고자료는 `weakness_pack.py`의 `fingerprint(REPO, PATH)` 또는 동일 SHA-256 계산으로 기록한다. `locations`는 읽은 페이지·토픽을 구체적으로 적는다. 아래는 키 형식의 예이며 내용은 실제 자료로 저작한다.

```json
{
  "schema": 1,
  "inputs": [{"path": "SSTT/0910 공부.md", "sha256": "실제 파일 해시"}],
  "review_note_search": "기존 노트에서 찾아 실제로 읽은 관련 토픽, 또는 검색 범위와 부재 이유",
  "references": [
    {"path": "복습노트/날짜/정리노트_파일.html", "sha256": "실제 해시", "role": "review-note", "locations": ["관련 토픽 ID"]},
    {"path": "강의노트/관련장.pdf", "sha256": "실제 해시", "role": "lecture", "locations": ["PDF p5"]}
  ],
  "weaknesses": [
    {
      "id": "w1",
      "status": "self_corrected",
      "evidence": [{"path": "SSTT/0910 공부.md", "line_start": 10, "line_end": 18, "quote": "해당 줄 범위 안의 실제 원문 인용"}],
      "later_check": "뒤쪽 정정 또는 이후 발언 끝까지 확인한 결과와 위치",
      "criterion": "이 혼동을 해결하는 판단 기준",
      "topic": "s0-concept",
      "problems": ["p1"]
    }
  ],
  "excluded": [{"reason": "보류·미포함 이유와 확인 방법"}]
}
```

보완한 약점마다 본문 토픽과 문항을 연결하고, 모든 문항이 선정한 약점과 연결되게 한다. 같은 개념의 반복 발언은 하나로 묶되 파일별 근거는 보존한다. 판단 보류 대상은 정상 약점 목록에 섞지 않는다.

내부 기록에는 인용·줄·녹음 위치를 보존한다. 학생용 본문에는 당시의 혼동과 정정을 자연스럽게 요약하고 녹음 위치·욕설·말더듬은 싣지 않는다. 참고자료를 학습자의 실제 발언인 것처럼 쓰지 않는다.
