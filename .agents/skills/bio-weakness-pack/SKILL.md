# SSTT 맞춤 약점팩

`SSTT/`는 학습자의 공부 중 발언이고, `STT/`는 수업 전사다. SSTT는 해당 차시의 **정리노트·복습문제·문제설명 HTML을 함께 공부하며 남긴 기록**이다. 약점은 선택한 SSTT에서 찾되, 해당 차시 HTML 3종의 **학습 내용을 모두 읽고** 발언을 원래 문항·보기·해설과 연결한 뒤 강의자료·교재로 검증한다. 기존 복습팩의 디자인·채점·문제설명 생성기를 재사용한다.

## 호출과 범위

- 인자 없음: **가장 이른 미처리 날짜 하나**. 같은 날짜 파일은 숫자 순서로 묶는다.
- `0910`: `0910 공부.md`와 `0910 공부 2.md` 등을 한 팩으로 묶는다.
- `"SSTT/0910 공부 2.md"`: 명시한 한 파일만 사용한다.
- `remaining`: 미처리 날짜를 날짜별 팩으로 차례로 생성한다. 한 날짜 실패는 기록하고 다음 날짜를 계속한다.
- `0910 regenerate`: 지정 날짜를 현재 입력으로 새 버전에 재생성한다. 기존 결과·풀이기록은 보존한다.
- 완료 입력은 중복 생성하지 않는다. 변경됨·미완료는 자동 재생성하지 않고 상태와 명시 `regenerate` 호출을 안내한다. 새 파일이 완료 날짜에 추가돼도 해당 날짜는 변경됨으로 본다.

새 팩은 `약점노트/<MMDD>/`, 재생성은 같은 날짜의 `v2/`, `v3/`에 HTML 3종을 둔다. `.assets/`에 MD·그림, `.pack/`에 입력·진단·문항·검토 근거를 보존한다. 기존 0908 테스트도 완료 기록으로 인식한다.

## 실행

`REPO`는 생명과학 저장소, `SKILL`은 이 폴더의 **실제 절대 경로**, `CLI`는 `SKILL/scripts/weakness_pack.py`다. 모든 명령의 경로를 실제 절대 경로로 치환한다. `RUN`은 저장소 밖의 새 임시 폴더이며 **`Path.resolve()`로 정규화한 경로**를 쓴다(`/tmp`와 `/private/tmp` 혼용 방지). 보조 도구는 학습 내용·정답·검토 승인을 자동 작성하지 않는다.

1. **선택:** `python3 CLI select --repo REPO [--target 0910|remaining|파일경로] [--regenerate]`. `selected`와 `catalog`를 읽고 실제 입력·날짜 수를 알린다. 날짜만 보고 다른 공부 회차 내용을 끌어오지 않는다. 선택 없음이면 상태만 보고 종료한다.
2. **준비:** 날짜별로 `python3 CLI prepare --repo REPO [--target 0910|파일경로] --run RUN [--regenerate]`. `remaining`은 select 후 날짜마다 따로 prepare한다. 인자 없는 호출은 prepare에도 target을 생략할 수 있다. `plan.json`의 입력·날짜·slug·출력 위치가 계약이다. 입력이 바뀌면 새 RUN에서 다시 준비한다.
3. **진단:** [diagnosis.md](references/diagnosis.md)를 읽고 모든 선택 파일을 끝까지 읽는다. 날짜와 실제 발언으로 공부한 차시를 확정한다. `python3 CLI study --repo REPO --folder 복습노트/차시`로 세 HTML의 항목 목록을 만든 다음, **세 자료의 전체 학습 내용**을 끝까지 읽는다(접힌 힌트·풀이 포함, CSS·JS 제외). 발언과 원래 문제·보기·문제설명을 연결하고 읽은 범위·그림 확인·누락·불확실성을 기록한다. 강의자료·교재와 대조해 schema 2의 `RUN/diagnosis.json`을 작성한다. 약점 신호가 부족하면 이유를 보고하고 해당 팩 생성을 보류한다.
4. **저작·조립:** [generation.md](references/generation.md)에 따라 기존 복습팩 규칙으로 `manifest.json`, `sections/*.html`, `cards/*.html`과 문항 근거를 작성한다. `python3 CLI assemble --run RUN`으로 조립·기계 검사·MD 변환을 실행한다. 이 상태는 **초안**이며 처리 완료가 아니다.
5. **독립 검토·문제설명:** 정답·풀이를 숨긴 문항 사본과 개념 자료만 별도 검산자에게 주어 정답 유일성·노트 충분성을 확인한다. 최종 복습문제의 절대 경로로 형제 `bio-problem-explain/SKILL.md`의 전체 extract→저작→검산→build/check→네 검토→publish를 실행한다. 검산 결과를 공유할 때도 답안·저작물 변경 여부를 확인한다. 독립 검산자가 없으면 독립 검토를 했다고 표시하지 말고 문제설명 발행을 보류한다.
6. **완료:** 차시 HTML 3종 전체 읽기·발언과 원래 문항의 연결·정정 경로, 정리노트·복습문제 화면과 진단 반영을 실제 검토한 `RUN/review.json` 및 근거 파일을 작성한다. `python3 CLI finish --run RUN`으로 원문·참고자료·발행 검토 해시와 HTML/MD 3종을 확인한 뒤 완료 처리한다. 문제설명이 보류되면 초안을 보존하고 보류 이유를 보고한다.

기존 `bio-review-pack`의 날짜 자동 선택·수업 전체 범위·기출 전수 수록 절차는 호출하지 않는다. 아래 참조한 저작·조립·검증 기능만 재사용한다. 원본 SSTT, 기존 복습노트, 형제 스킬은 수정하지 않는다. 커밋·푸시는 별도 요청 때만 한다.

## 보고

최종 HTML 3종 링크, 입력 파일, 보완한 개념, 자기교정 재확인, 문항 수·구성, 실제 검토 결과와 보류를 짧게 보고한다. 당시 발언과 현재 숙련도를 구별한다. 공부 중 정정·해설 참고 후 정정·독립적인 자기교정을 구분하고, 정정 경로가 불명확하면 그대로 표시한다. 정답을 말한 것을 독립 풀이 성공으로 세지 않는다. 스킬을 만드는 요청은 다른 날짜 약점팩을 생성하라는 요청이 아니다.
