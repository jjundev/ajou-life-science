# STT 요약 에이전트 지시문

메인 에이전트는 날짜마다 아래 브리프로 에이전트 1명을 띄운다(병렬, model: opus). 요약 전체(`stt-<MMDD>.md`)는 작성자와 검토자가 읽는 근거 자료다. **메인 에이전트는 발췌(`stt-<MMDD>.digest.md`)만 읽는다.** 영수증 형식은 `references/report-contract.md`를 따른다.

---
생명과학(이영만 교수님) <MMDD> 수업 녹음 전사를 정밀 요약한다.

- 입력(읽기 전용): `<RUN>/repo/STT/<MMDD 생명.md>` — **처음부터 끝까지 전부** 읽는다. 건너뛰지 않는다.
- 대조 자료: `<RUN>/repo/강의노트/<N장 *.pdf>` 텍스트(메인이 추출해 `<RUN>/slides.txt`에 둠, 쪽마다 `=== N장 pK ===`)
- 출력: `<RUN>/summaries/stt-<MMDD>.md`와 그 발췌 `<RUN>/summaries/stt-<MMDD>.digest.md` 두 파일만 쓴다. 다른 곳에는 쓰지 않는다(임시 파일은 아래 규칙).
- 임시·보조 파일은 `<RUN>/work/` 아래에만 둔다. 저장소(`STT/`, `강의노트/`, `교과서/`, `23, 24 소스/`, `웹과제/`, `복습노트/`)와 `<RUN>` 밖(scratchpad 루트, `/tmp` 등)에는 아무것도 쓰지 않는다. 한글(NFD) 파일명은 복사하거나 이름을 바꾸지 말고 Python `os.listdir` + `unicodedata.normalize('NFC', …)`로 찾아 그 경로로 연다.

출력 형식:
1. `# <MMDD> 생명과학 강의 개요 (이영만 교수, <YYYY-MM-DD>)`
2. **총평**: 녹음 길이, 이번 수업이 다룬 강의노트 장과 쪽 범위(예: "3장 p12–20"), **시작하지 않은** 쪽, 흐름 한 줄.
3. `## 0. 지난 수업 복습`: 교수님이 도입부에서 앞 수업을 다시 짚었으면 요점 3~5줄과 타임스탬프. 없으면 "없음".
4. 흐름 순서대로 `## N. 제목 (Part PP MM:SS–MM:SS)` 절. 이 표기는 내부 요약 전용이며 학생용 HTML로 옮기지 않는다. 각 절에:
   - **핵심 내용**: 정의와 성립 조건, 인과(왜 그렇게 되는가), 과정이면 위치·입력·출력. 강의노트에 없는 설명은 `[강의노트 외]` 표시.
   - **비유와 일화**: 개념을 싣는 비유만. 순수 잡담(출석, 자리, 공지 등)은 쓰지 않는다.
   - **학생과의 대화**: 학생 이름은 "한 학생".
   - 강조 발언: 원문 인용 + `(MM:SS)`. "중요", "시험", "꼭", "외워" 같은 표현이 붙은 발언은 모두.
   - `⚠️ 혼동 지점:` 교수님이 반복했거나, 학생에게 되물었거나, "헷갈린다"고 말한 곳. 무엇과 무엇이 헷갈리는지 한 줄씩, 빠짐없이.
   - "나중에 할게요", "교재 보세요"처럼 미룬 설명은 `🕳️ 미룬 설명:`으로 표시.
5. `## 끊긴 지점`: 마지막 발언 원문과 타임스탬프, 개념 중간에서 끊겼는지, 다음 시간 예고 항목.
6. `## 슬라이드 대조표`: | 쪽 | 다룸/일부/예고만/안 다룸 | 근거 타임스탬프 |
7. `## 용어 목록`: 수업에서 실제로 쓴 용어를 `한국어(영어)` 형태로(정리노트 required_terms 후보). 화학식·반응식은 쓴 그대로.
8. `## 말실수 정정`: STT 오인식(비슷한 소리의 생물 용어 등) 또는 교수님 말실수와 올바른 형태.

타임스탬프가 파트마다 00:00부터 다시 시작하면 `(P03 04:12)`처럼 파트 번호를 붙인다.

발췌 파일(`stt-<MMDD>.digest.md`, 150줄 이하): 메인 에이전트가 manifest를 짤 때 이 파일만 읽는다. 요약 본문을 다 쓴 뒤 거기서 뽑아 만들고, 새 내용을 더하지 않는다. 원문 인용과 비유 설명은 넣지 않는다.
1. `## 총평` (요약의 총평 그대로)
2. `## 지난 수업 복습`: "있음(요점 한 줄)" 또는 "없음"
3. `## 절 목록`: `| 절 | 제목 | 강의노트 쪽 | 강조 발언 유무 | 혼동 지점 수 | 미룬 설명 유무 |`
4. `## 혼동 지점`: 절 번호와 함께 한 줄씩 전부
5. `## 강조 발언 요지`: 절 번호와 요지 한 줄씩(원문 인용 없이), 교수님 비유의 핵심 단어
6. `## 미룬 설명`: 한 줄씩
7. `## 슬라이드 대조표` (요약의 표 그대로)
8. `## 용어 목록` (요약의 목록 그대로)
9. `## 금지어 후보`: 대조표에서 "예고만/안 다룸"인 쪽의 핵심 용어 중 이번 수업에서 **한 번도** 말하지 않은 것
10. `## 끊긴 지점`: 한두 줄과 다음 시간 예고 항목

보고: 두 파일 경로와 총평 3줄만 돌려준다.
