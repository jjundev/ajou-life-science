# 웹과제 장별 원본 관찰 (문항 감사 에이전트)

`webquiz-style.md` 2절에서 분리한 장별 관찰이다. 장이 늘수록 길어지므로, partC를 설계할 때 **이번 범위의 장과 장 섞기에 쓸 장의 절만** 읽는다. 해당 장의 절이 없으면 `webquiz-style.md` 2절의 1~3장 집계와 4절의 참고 목표를 쓴다. 새 장 관찰은 이 파일에 `### N장 원본 관찰` 절로 더한다.

### 4장 원본 관찰

근거: `웹과제/4장/intake.md`와 거기에 연결된 raw 15장(2026-10-08 캡처 파일명, 전체 문항 수는 사용자 확인). **공식 답 미확인·기출 재사용 미집계·정본 bank 미등록**이다. 선택 표시는 정답이나 난이도 판단 근거로 쓰지 않는다.

| 관찰 | 수 | 원본 문항 |
|---|---:|---|
| 전체 | 15문항 | 1~15 |
| 부정형 | 4 | 1·2·7·10 |
| 유전 확률·비율(계산) | 5 | 5·6·9·13·14 |
| 그림 | 3 | 9·11·12 |
| 표 | 1 | 15 |
| ㄱㄴㄷ | 0 | 없음 |

유형은 중복 가능하다. 이 원본 관찰은 위 1~3장 확정 집계에 합산하지 않는다. 장별 근거로 배합을 정하며, 4장 계산 비중을 다른 장에 그대로 적용하지 않는다. 관찰을 참고하는 것과 원문을 partA에 등록하는 것은 별개다. raw만 있는 장은 기존 규칙대로 partA에서 제외한다.

4장에서는 짧은 교배 계산과 인접 개념 판별이 중심이다. 예: 상동염색체/자매염색분체, 염색체 하나/완전한 세트, 공동우성/불완전우성. 생성 목표는 실제 관찰 수와 구별해 적는다. 그림·표는 답을 정하는 데 읽어야 할 때 해당 유형으로 센다. 표 해석은 `표`로 별도 집계하며, 장식 그림은 `그림` 판독 유형으로 세지 않는다.

### 5장 원본 관찰

근거: `웹과제/5장/questions.json`, `intake.md`, `note-feedback.md`(2026-10-15). 전체 17문항·84보기, q14만 4보기다. 공식 답 미확인·기출 재사용 미집계이며 1~3장 집계와 합산하지 않는다. 부정형은 q03·q04·q06·q08·q14(5/17), 수치 계산은 q11, 서열 처리는 q05·q07, 제공 표 판독은 q07 코돈표다. 유형은 중복 가능하다. bank 그림 자산 1개를 일반 그림 판독 유형과 혼동하지 않는다.

명칭 전환(q09 정지/넌센스/nonsense), 비교 단위(q01 전구체의 여러 산물/q06 성숙 mRNA 한 종류), 작용 대상과 단계(q03·q04·q15), 결합 대상(q02·q16), 합성/교정 방향(q13·q17)을 구별한다. q09에는 한국어·영어가 함께 있으므로 ‘영어만 출제’라고 쓰지 않는다. 선택 불일치 q03·q06·q09는 공식 오답이 아니고 q07 무선택·방향 생략은 개인 진단에서 보류한다. 개인 가설은 장별 피드백의 별도 절에서만 미확인 상태로 다룬다. 이 관찰만으로 난이도 분포를 확정하거나 다른 장의 의무 배합을 만들지 않는다.

### 6장 원본 관찰

근거: `웹과제/6장/questions.json`, `note-feedback.md`(2026-10-19). 전체 14문항·70보기, 모두 5보기다. 공식 답 미확인·기출 재사용 미집계이며 1~3장 집계와 합산하지 않는다. 부정형은 q03·q06·q07·q08·q12·q14(6/14), 수치 계산은 q13(PCR 주기별 총 분자 수), 제공 그림 판독은 q14(크리스퍼-카스 그림)다. 유형은 중복 가능하다.

같은 기술을 여러 각도에서 묻는다. PCR은 단계 순서(q05), 반응 재료(q12), 총량 계산(q13)으로, CRISPR는 문장(q02)과 그림(q14)으로 나온다. 인접 개념의 경계도 묻는다: 생물정보학/시스템생물학(q10), 체세포/생식계열(q03), 핵 DNA/미토콘드리아 DNA(q09). 원문 오탈자(q01 끝 ㅊ 등)는 교정하지 않는다.

### 7장 원본 관찰

근거: `웹과제/7장/questions.json`, `intake.md`, `note-feedback.md`(2026-11-12). 전체 13문항·65보기, 모두 5보기다. 공식 답 미확인·기출 재사용 미집계이며 1~3장 집계와 합산하지 않는다. 부정형은 q01·q02·q06·q08(4/13, `거리가 먼`·`적절하지 못한` 포함), ㄱㄴㄷ 조합형은 q03, 하디-바인베르크 계산은 q04(열성 표현형 → 우성 동형접합자 역산)·q05(2pq → 기대 개체 수)다. 그림·표 자산은 없고, q09는 발문 속 표현형 비율 수치를 읽는다.

같은 식이나 개념을 질문 방향을 바꿔 다시 묻는다(q04/q05 같은 식의 역산과 정산, q07 사례/q12 정의의 유전적 부동, q09 한쪽 극단/q10 중간의 선택 양상). 진화 증거는 관찰 자료의 종류와 형질의 기원으로 구분한다(q08·q11·q13). q01·q02·q08·q09는 교재 요약 기준으로는 답이 하나지만 엄밀히 따지면 다른 보기도 부정확하다(`note-feedback.md`의 원문 주의점). 이 패턴은 **관찰로만 기록**하고 출제 경향이나 생성 목표로 쓰지 않는다.

### 8장 원본 관찰

근거: `웹과제/8장/questions.json`, `intake.md`, `note-feedback.md`(2026-11-12). 전체 14문항·69보기, q07만 4보기다. 공식 답 미확인·기출 재사용 미집계이며 1~3장 집계와 합산하지 않는다. 부정형 발문은 0/14다. 수치 계산은 q11(C-14 잔존 비율 → 경과 시간 역산), 자료 판독은 q02(학명과 서열 차이 수)·q06(교배 실험 결과 그림 자산), 조합형은 q07((가)~(라) 중 접합 후 장벽), 순서 배열은 q14(생명사 사건)다.

종 개념 적용과 생식 장벽 단계(q03·q05·q06·q07·q12), 비슷한 형질의 기원(q09 수렴/q13 상동·상사)을 구별한다. q01 오답 보기에는 7장 용어(동일과정설·격변설)가 섞인다. **장 경계:** q04 RNA 세계 가설은 교재상 9장 내용이지만 8장 웹과제 전에 1105 강의에서 다뤘다. 웹과제 범위는 교재 장 번호가 아니라 응시 전까지 강의한 내용을 따른다고 본다. 금지어 기준은 `bio-webquiz-forecast/references/question-blueprint.md`의 `forbidden`·`## 경계 주제`를 따른다.
