# 주제 고르기

## 후보 만들기
- 정리노트(`notes`)의 H2·H3 절 하나가 후보 하나예요. 「직접 해 보기」 블록이 있는 절은 표시해 둬요.
- 정리노트가 없으면 STT와 그 장 강의노트 쪽 제목으로 후보를 만들어요.
- 같은 대상을 다루는 이웃 절(예: 「DNA 구조」와 「염기쌍」)은 한 후보로 합쳐요.

## 점수
| 기준 | 점수 | 예 |
|---|---|---|
| 순서·타이밍이 있는 과정 | +2 | DNA 복제, 전사·번역, 세포 분열 단계, 활동전위 |
| 공간 구조(돌려 보면 이해가 쉬움) | +2 | 이중나선, 세포막, 미토콘드리아, 리보솜 |
| 조건을 바꾸면 결과가 달라지는 관계 | +2 | 젖당 유무와 lac 오페론, 기질 농도와 반응 속도, 교차와 재조합 |
| 정리노트 「직접 해 보기」 표시 | +1 | |

- 기준은 **3점** 이상이에요.
- 빼는 것: 정의·분류·역사 위주 절(점수와 상관없이), `existing`의 `<title>`과 같은 대상을 다루는 후보.

## 개수
- 날짜 입력: 3점 이상 후보를 점수 순으로 **최대 4개**. 2개보다 적으면 남은 후보 중 점수 높은 순으로 **2개까지 채워요**. 동점이면 수업에서 더 길게 다룬 쪽.
- 주제 입력: 1개.
- 후보가 아예 없으면(모두 빠짐) 「후보 없음」으로 보고하고 멈춰요.

## 브리프 (`RUN/<n>/brief.md`)
```
# <주제> — <점수>점 (<기준별 점수>)
- 제목: <상단 바 제목, 15자 안팎>
- 모드 1–3개: <key> <label> — 무엇을 보여 주는지, rotatable/playback
- 단계: <과정 모드면 4–7개: 제목 · 누가 · 핵심 한 줄>
- 꼭 기억해요 3개(모드마다): <헷갈리는 짝> — <구별법>
- 오른쪽 패널 숫자·범례: …
- 근거: 정리노트 <절>, 강의노트 <N장 pN>, 교과서 <쪽> (수업 밖 보충이면 표시)
- 단순화: <개수·속도·위치 등>
```
