# 디자인 규칙

기준은 「DNA 구조와 복제 3D」(`example-dna.dc.html`)예요. 셸은 템플릿이 이미 갖고 있으니, 주제 작성자는 아래 규칙으로 슬롯·장면·문구만 맞춰요.

## 화면 구성
- **상단 바**: 조작 토글 · 제목(`__TITLE__`, 짧게 「○○ 3D」, 「○○ 과정」) · 모드 버튼(1–3개) · 테마 · 설명 토글. 640px 미만에서는 제목이 숨어요.
- **왼쪽 패널(조작)**: 「보기 옵션」(`TOGGLES`, 2–6개) → 슬롯(주제 전용 조작: 서열, 값 고르기 등) → 「단계」(`STEPS`, 과정 주제는 4–7개).
- **가운데 캔버스**: 드래그 회전(회전 모드), 오른쪽 위 확대·축소·시점 처음으로. 재생이 있는 모드만 아래 재생 바.
- **오른쪽 패널(설명)**: 슬롯(숫자 타일 2–4개 → 「지금 일어나는 일」 또는 범례 → 짧은 설명 한 줄) → 「꼭 기억해요」 3개.
- 1024px 미만은 두 패널이 서랍이 되고 한 번에 하나만 열려요(셸이 처리).

## 모드 고르기
- 입체 구조(분자, 소기관, 막)는 `rotatable: true`, `autoSpin: true`, `cam` 약간 비스듬히(`yaw -0.55, pitch 0.32`).
- 순서·타이밍이 있는 과정은 `playback`을 쓰고, 도식이 평면이면 `rotatable: false`, `cam {yaw 0, pitch 0}`.
- 한 주제에 구조 + 과정 두 모드가 흔한 조합이에요. 같은 대상을 두 번 보여 주는 모드는 만들지 않아요.

## 장면
- 실제 구조를 따라 모델링해요: 개수, 방향(5′→3′, N→C), 상대 크기, 결합 위치.
- 색은 `PAL`로만. 같은 역할은 같은 색(예: 옛 가닥 회색, 새 DNA 민트, RNA 분홍). 라이트·다크 둘 다 배경과 대비가 나게 하고, 다크는 같은 색상의 밝은 쪽으로.
- 덩어리(효소, 단백질 복합체)는 `k: 5` 반투명 음영 구, 원자·단위체는 `k: 0` 구, 결합·골격은 `k: 1` 막대(`rod: true`면 입체).
- 라벨 칩은 꼭 필요한 이름만(한 화면 6개 이하), 평면 기준 고정 오프셋(`dx/dy`)으로 겹치지 않게. 회전해도 글자가 뒤집히지 않아요(셸이 화면 좌표에 그림).
- `fit`은 375×812 세로 화면에서도 장면이 잘리지 않게 여유를 둬요.
- 움직임은 의미가 있을 때만. 자동 회전은 셸이 동작 줄이기를 존중해요. 장면에서 따로 흔들거나 깜박이게 하지 않아요.

## 문구
- 해요체, 한 문장에 한 가지. 패널 문장은 40자 안팎.
- 정리노트의 용어와 표기를 그대로(예: 「DNA 중합효소 III」, 「오카자키 조각」). 영어는 처음 한 번만 괄호로.
- 「꼭 기억해요」는 학생이 실제로 헷갈리는 짝을 제목으로(「채우기 ≠ 잇기」), 본문은 구별법과 화면에서 확인하는 방법.
- 단계 `text`는 누가(`who`) 무엇을 왜 하는지 2–3문장.
- 수업 밖 내용은 「(교과서 보충)」.

## 접근성
- 버튼은 최소 44px, 상태는 `aria-pressed`, 아이콘 버튼은 `aria-label`(셸에 있음). 슬롯에 버튼을 넣으면 `.btn`과 `aria-pressed`를 써요.
- `canvasLabel(f)`는 지금 화면을 한 문장으로(무엇이, 어디까지 진행했는지).
- 색만으로 구별하지 않아요: 범례에 이름을 같이 적고, 캔버스에도 핵심 대상엔 라벨을 달아요.
- 마크업 색은 토큰(`var(--ink-2)`, `var(--surface)` 등)이나 구멍으로만, `#rrggbb` 직접 금지.
