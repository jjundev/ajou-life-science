# 범위·원문·단답형 저작

prepare가 만든 초안은 의미 검토 전 자료다. 실제 공통 MD 두 개와 해당 장 feedback을 열고 읽은 절/요약/적용/비적용 이유를 policy-notes에 적는다. 문항의 style_basis를 그 기록과 연결한다. 경향의 오래된 bank 상태는 현재 검증된 파일과 비교하여 불일치를 적는다. 유형·난이도는 최신 자료에서 실행별로 정한다. 고정 15문항·A~E 균등·이전 장 허용을 시험에 적용하지 않는다.

토픽은 강의노트/PDF/STT/교과서에 연결한다. 그림이 판단에 필요하면 PDF 페이지나 원본 이미지를 실제로 연다. 텍스트 추출 성공은 시각 확인이 아니다. 수업 설명 누락만으로 시험 제외를 단정하지 않는다. required_chapters에는 정답뿐 아니라 모든 보기와 그림에 필요한 장을 넣는다. scope_status=uncertain은 최종 선정에서 제외하고 확정 근거를 찾는다.

웹과제는 complete validator를 통과한 bank에서만 원문으로 가져온다. observations.selected_option_id는 응시 선택, analysis.answer_option_id는 분석 답, official_answer는 별도 공식 답이다. reasoned 답을 공식이라 쓰지 않는다. 충돌/모호함/그림 미확인은 제외·보류한다. 원문은 조건·숫자·순서·그림 전체를 유지한다. 수정하거나 단답형으로 전환하면 variant다. 원문 payload hash를 새 저작에 맞춰 임의로 갈아끼우지 않는다.

기출 collector는 복습 카드 기반 발견 도구다. 카드 파일명/기존 답을 검증으로 간주하지 말고 `23, 24 소스/` PDF 원페이지·답안과 대조한다. PDF 근거 path/hash/locator를 source_refs에 추가한다. 원문 미확정이면 보류한다.

새 문제는 범위 내 포함 토픽으로 만든다. 낯선 표현에 대한 참 판정·개념 경계·방향/대상 비교 등 최신 MD의 기준을 문항에 실제 적용한다. 최소 추론 수(level 1~3)를 기록하고 이유 없는 복잡화는 피한다. 새로운 유형을 enum 제한 때문에 버리지 않는다. 변형 가족과 문제 간 답 노출을 점검한다.

단답은 무엇을 어떤 단위/형식으로 쓰는지 명시한다. 정답과 허용 표현, 대소문자 구별을 직접 정한다. Aa/aa, DNA/dna 등 의미가 다르면 대소문자를 보존한다. 1/2와0.5, 기호/한글/영문 동의어를 허용하려면 accepted 각각에 적는다. rejected_answers에는 대표 혼동과 이유를 기록한다. 미등록 답을 자동 오답으로 단정하지 않고 자기채점으로 넘긴다.

선정 전에 review.scope/key/source/style/family의 실제 evidence를 작성한다. 일괄 pass 복제·TEST ONLY fixture의 실자료 사용은 금지한다. 스크립트는 답안 의미·경향 적용·학술 난이도를 증명하지 않는다.
