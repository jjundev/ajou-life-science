# 배정과 선정

총 75개를 장별 균등 배정하고 잔여는 장 번호 오름차순. 객관식 55개를 장별 총수에 비례해 largest remainder로 배정하고 나머지는 단답형이다. 1~6장은 객관식 10/9/9/9/9/9, 단답형 3/4/4/3/3/3이다.

출처 목표는 실제 시험 통계가 아닌 생성 정책이다. 객관식 web-original20/web-variant10/past-original10/new15, 단답 web-derived8/past4/new8. 출처가 부족하면 같은 장·형식의 적격 후보로 보완하고 selection-report에 목표/실제/사유를 남긴다. 장별 수·형식·입력 범위·가족 중복 제약을 출처 목표보다 우선한다.

후보 우선순위 5개: 시험 포함/중요 명시 → 서로 다른 실제 평가의 재등장 → 누락 핵심 토픽 → 명칭·대상·단계·방향·단위 혼동 → 이전 버전의 미사용 가족. 복습팩에 복제된 같은 원문은 재등장 통계로 세지 않는다.

원문·변형·단답 전환·출처 간 동일 문제를 안정적 family_id로 묶는다. 정확한 fingerprint로도 중복을 검사하지만 의미상 가족 판정은 실제 검토가 필요하다. 가족-장/형식 슬롯의 augmenting path로 재배정하여 단순 greedy 때문에 가짜 부족을 보고하지 않는다. 출처 배합은 빈 가족 교체로 개선하는 soft 목표다. 불가피한 차이는 공개한다.

기존 버전 미사용 가족을 선호한다. 원문 가족이 소진되면 재사용을 공개할 수 있으나 생성한 동일 발문 재사용은 금지한다. 문항끼리 답을 알려주거나 한 개념이 과집중되는지는 75개를 함께 읽어 판정한다. shortage를 범위 확장/중복으로 덮지 않는다.
