# 문제 검토와 불변성

`check`는 구조를, `check --final`은 현재 입력에 묶인 검토 완료를 검사한다. 구조 성공을 학술 검증으로 보고하지 않는다. question-review.json은 build 시 모두 not_run이다. 현재 input_hash는 pack/blueprint/scope/policy/candidates/manifest/report/75 cards/두 문제 HTML/presentations.json/vendor/assets에 묶인다. 원본 근거는 별도 freshness로 검사한다. MD 수정·삭제·부재 파일 신규 등장 시 이전 pass로 진행하지 않는다.

네 검토 모두 status=pass, reviewer, 구체적 evidence, items의 p1~p75 각각 비어 있지 않은 근거가 필요하다.

새 버전은 [공통 계약](dual-html.md)의 두 문제판을 모두 확인한다. `reviews.browser.presentations.practice`와 `.exam` 각각 status=pass, reviewer, evidence가 필요하다. 학술·독립 풀이 검토는 공통 원본에 한 번 수행하고, 표시 일치와 브라우저 동작은 두 판 각각 확인한다. 아래 자동 이동·전체 제출·입력 잠금 기준은 시험형에 적용한다. 연습형은 기존 복습문제의 객관식 비이동·즉시 판정·보기별 설명·다시 풀기·애매함 표시를 확인한다. 단답형은 입력 후 `답 확인`으로 판정·입력 잠금, `다시 풀기`로 초기화하며 마지막 문항의 복기 프롬프트에 함께 포함되는지 확인한다. 추가 기능 바·시험식 전체 결과가 없고 새로고침 시 모두 초기화되는지도 검사한다.

- source_visual: 발문·수치·조건·보기 순서·원본 그림/PDF 페이지, 분석/공식 답 구별. PDF는 필요한 실제 페이지를 렌더해 읽는다.
- content_scope_style: 모든 보기의 required_chapters, included topic, 최신 policy-notes/style_basis의 실제 적용, 난이도·오답의 타당성, 중복 개념 과집중·문항 간 답 노출.
- independent: 별도 검토자가 blind HTML과 학습 근거로 처음부터 다시 푼 답/판단. 원 정답·해설·pack/blueprint/style_basis/출처는 제공하지 않는다. SVG·표·래스터 그림은 그대로 둔다. 다시 푼 결과와 제작자의 답을 컨트롤러가 대조한다.
- browser: [확정 화면·동작 양식](exam-ui.md)에 따라 아래 항목을 1280x900/375x812, light/dark에서 실제 확인한다.
  - 75문항 접근, 보기·표·그림·수식·단답 입력 표시. 본문·목차·풀이 패널의 `pN. 개념 요약` 일치와 가로 넘침 없음.
  - `다시 풀기`는 상단 툴바에 하나. 객관식 선택 후 즉시 다음 문항, 이전 이동 후 답 보존, 수정 후 재이동, 마지막 객관식→첫 단답형 이동. 단답형 입력 중 자동 이동·자동 제출 없음.
  - 첫 화면·중간 문항의 `전체 제출` 숨김, 마지막 문항에서만 표시하고 `처음으로` 숨김. 제출 전 답/출처는 JS off와 print에서도 hidden.
  - 전체 제출 후 입력 잠금과 모든 문항의 결과 표시. 객관식 정답/오답, 단답형 자동 일치/자기채점 대기, 미응답 구분. 필터와 빈 분류, 결과→문제·해설→전체 결과 왕복.
  - 오른쪽 5열 채점표가 전체 75문항과 ○/×/?/—를 표시하고 결과 필터와 무관하게 유지됨. 데스크톱 결과 진입 시 열림, 모바일 버튼으로 열기·닫기. 문항 링크와 브라우저 뒤로/앞으로 후 패널 내용 동기화.
  - 복기 프롬프트의 묶음(오답·자기채점 대기·미응답, 맞힌 문항은 제목만)이 결과와 일치. 입력 원문 보존, 수식이 KaTeX 렌더 전 원문으로 들어감, 클립보드가 막히면 직접 복사 대화상자. 다시 풀기 취소 시 유지, 실행 시 입력·결과·채점표 초기화.
  - 키보드 사용·초점 이동·판정의 접근성 이름·콘솔/자원 실패·외부 요청 확인. 결과 화면의 인쇄도 확인.

확정 v9와 비교한 화면 검증이나 합성 테스트 성공은 학술 승인으로 간주하지 않는다. 새 문제·해설은 현재 입력에 대한 실제 검토가 필요하다.

blind 명령은 새 출력 폴더로 실행한다. 문제용 그림만 복사하고 해설용 그림·허용답·hint·script·데이터 모델·출처를 제외한다. blind 자체의 75문항·20단답·그림/표 보존을 실제로 확인한다.

초안 변경/rebuild는 네 검토를 초기화한다. 네 검토가 완료된 버전은 새 버전을 사용한다. 해시만 바꿔 이전 승인을 살리지 않는다. 최대 2회 수정 예산은 explanation-handoff를 따른다. 합성 테스트의 TEST ONLY 검토는 실제 시험 문제 검토로 사용하지 않는다.

새 연습형·시험형의 Pretendard·KaTeX는 `복습노트/_shared/`의 버전별 공용 자원을 사용한다. 두 HTML의 검토 입력 해시와 해설 인계에는 이 자원 파일의 해시가 포함된다. 이전 시험 버전은 팩 내부의 `vendor/`를 계속 사용한다.
