# 확정된 시험예상문제 화면과 동작

## 기준과 적용 범위

사용자가 확정한 기준은 [1장~6장 확정 문제 HTML](../../../../시험예상/1장-6장/시험예상문제_1장-6장.html)이다. 향후 모든 범위의 시험예상문제에 같은 화면 구성과 동작을 적용한다. v9의 문제·정답·출제 비율을 새 범위의 저작 근거로 복사하지 않는다. 매 실행의 원자료·최신 경향 읽기, 범위 검토, 독립 풀이와 해설 검토는 별도로 수행한다.

구현은 `../assets/exam-template.html`, `../assets/exam-runtime.js`, `../assets/exam-results.html`, `../scripts/exam_build.py`에 있다. 공통 화면은 `../../bio-review-pack/assets/review-template.html`을 사용하고 시험 확장은 이 스킬에서 적용한다. 공통 복습문제의 선택 즉시 채점 런타임을 붙이지 않는다. v9는 시각·동작 비교 기준이며, 앞으로 공통 화면을 수정하면 아래 동작과 레퍼런스 화면을 비교한다.

대표 화면: [데스크톱 결과·채점표](../../../../시험예상/1장-6장/.pack/v9/presentation-review/1280-light-results.png), [모바일 결과·채점표](../../../../시험예상/1장-6장/.pack/v9/presentation-review/375-dark-results.png), [모바일 문항 제목·툴바](../../../../시험예상/1장-6장/.pack/v9/presentation-review/375-dark-concept-title.png). 다른 밝기·크기의 캡처와 실제 검증 기록은 같은 `presentation-review/` 폴더에 있다.

## 화면과 문항 제목

- 기존 복습 양식의 상단 툴바·왼쪽 목차·가운데 한 문항·오른쪽 풀이 패널, 테마와 반응형 동작을 유지한다.
- `다시 풀기`는 상단 툴바에 하나만 둔다. 하단이나 결과 본문에 중복 배치하지 않는다. 제출 버튼이 없는 풀이 화면에서는 비어 있는 하단 보조 영역을 숨긴다.
- 문항마다 짧은 `concept_summary`를 저작하고 `pN. 개념 요약`으로 표시한다. 예: `p4. 생체분자의 구조와 중합체`. 본문·목차·현재 문항 풀이 패널의 제목은 같다.
- 개념 요약은 묻는 주제나 과제를 나타낸다. 정답 용어를 맞히는 문항의 답, 계산 결과, 정오 판정이나 풀이 결론을 제목으로 쓰지 않는다. 전체 문항 제목을 함께 보며 문항 간 답 노출도 검토한다.
- 제목 미작성 시 생성기는 포함 토픽의 제목을 기본값으로 넣는다. 발행 전에는 각 제목이 해당 문항을 적절히 요약하는지 검토한다. 과거 `concept_summary` 없는 보존본을 소급 수정하지 않는다.

## 풀이와 제출

| 상태 | 동작 |
|---|---|
| 객관식 답 선택·변경 | 입력을 보존하고 즉시 다음 문항으로 이동한다. 이전 문항으로 돌아가 수정할 수 있다. 선택 직후 정답·해설·출처는 공개하지 않는다. 이동 후 문항 제목으로 초점을 옮긴다. |
| 단답형 입력 | 입력 중 자동 이동하지 않는다. `다음`으로 이동한다. |
| 제출 전 첫 화면·중간 문항 | `전체 제출`을 표시하지 않는다. |
| 제출 전 마지막 문항 | 실제 마지막 문항에만 `전체 제출`을 표시한다. `처음으로`는 숨긴다. 미응답이 있어도 제출 가능하며 자동 제출하지 않는다. |
| 전체 제출 | 모든 답안을 한 번에 채점하고 입력을 잠근 뒤 같은 HTML의 전체 풀이 결과로 이동한다. |
| 제출 후 문제 복습 | 오른쪽에 해당 문항의 해설·출처를 표시하고 `전체 결과`로 돌아갈 수 있다. |
| 다시 풀기 | 제출 후에는 JSON 보관 안내와 함께 확인을 받고, 취소 시 유지한다. 실행 시 입력·결과·채점표를 지우고 첫 문항으로 돌아간다. |

마지막 문항은 실제 문항 순서에서 계산한다. JavaScript를 끄거나 제출 전에 인쇄해도 정답·해설·출처는 숨긴다.

## 결과와 채점표

- 결과 본문에 전체 문항의 내 답·정답·판정을 표시하고 전체/정답/오답/자동 일치/자기채점 대기/미응답 필터를 제공한다. 분류가 비면 안내한다.
- 오른쪽 패널 제목과 열기 버튼을 `채점표`로 바꾼다. 데스크톱(현재 공통 화면 기준 1024px 이상)에서는 결과 진입 시 패널을 열고, 모바일에서는 버튼으로 연다.
- 실제 HTML 표를 5열로 배치하고 칸마다 문항 번호와 판정 기호를 표시한다. 표는 결과 필터와 무관하게 전체 문항을 유지한다.

| 기호 | 의미 |
|---|---|
| ○ | 객관식 정답 또는 단답형 정답·명시 허용답과 자동 일치 |
| × | 객관식 오답 |
| ? | 단답형 자기채점 대기. 자동 오답으로 단정하지 않는다. |
| — | 미응답 |

표와 결과 목록에서 문항을 누르면 그 문제와 해설로 이동한다. 색상만으로 판정을 구분하지 않으며 접근성 이름에 문항 번호·판정·이동 목적을 넣는다. 뒤로/앞으로 이동에도 결과 본문·패널 제목·내용을 동기화한다.

## 풀이기록과 검증

제출 때 고정한 동일 응시 기록으로 결과 본문·채점표·JSON을 생성한다. [시험 풀이기록 계약](attempt-export.md)의 `bio-exam-attempt`/`schemaVersion=1`을 유지한다. 재내보내기는 응시 ID·제출 시각을 유지하고 내보내기 시각만 새로 기록한다. 다운로드 실패 시 결과를 보존하고 재시도할 수 있다. 새로고침 시 기록이 사라짐을 화면에 안내한다.

[검토 기준](verification.md)의 브라우저 항목으로 실제 새 산출물을 확인한다. v9의 `presentation_verified`는 화면 검증 기록이며 새 문제의 학술 승인으로 사용할 수 없다. 과거 해설·학술 검토 기록을 새 input_hash의 pass로 복사하지 않는다.

## 버전 관리

현재 1장~6장 v1~v8 문제판 폐기는 사용자가 승인한 한 차례 정리다. v9와 기존 v3 해설·필수 자료·검토 근거를 남긴다. 보존된 v3 기록은 당시 원본과 검토의 증거이며 v9를 새로 학술 검토했다는 의미가 아니다. 앞으로는 기존 불변 버전 생성 정책을 유지하고 이전 버전을 자동 삭제하지 않는다.

화면 제목에는 내부 버전(v3, v9 등)을 표시하지 않는다. 현재 1장~6장의 최종 공개 HTML은 사용자의 파일명 정리 요청에 따라 버전 접미사를 제거했고, 내부 자료 버전과의 연결은 `.pack/publication.json`에 기록했다. 생성기의 build/publish는 기존 불변 `_vK.html` 경로를 사용한다. 이 한 차례 정리를 앞으로 생성되는 파일의 자동 덮어쓰기 정책으로 확대하지 않는다. 내부 자료·검토 이력의 버전 경로와 풀이기록의 식별 정보는 보존한다.

문제 본문의 첫 문단 선두에 붙은 원본 문항 번호(`1. `, `2) `, `(3) ` 등)는 화면에서 제거한다. 제목의 `pN.`은 유지한다. 소수(`3.2`), 단위가 붙은 수량, 문장 중간 숫자, 보기 번호·풀이 단계에는 이 규칙을 적용하지 않는다. 원자료·pack의 원문은 보존하고 문제판 및 시험 해설 문제 패널의 표시만 정리한다.
