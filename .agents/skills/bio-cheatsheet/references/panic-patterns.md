# 당황 패턴 — ① 시험장 체크의 원천

기출 중심 대비에서 주의할 실제 출제 요구다. 개인이 실제 당황했는지 확인한 결과와 구별한다. 출처: 1장은 `docs/2026-09-17-1장-웹과제-분석과-노트-개선안.md` §3(시험 구성)·§5(문항별 감사), 3장은 `웹과제/3장/raw/` 화면 14장(2026-10-01 응시). 2장은 `웹과제/2장/questions.json`·`intake.md`(2026-10-01 응시). 4장은 `웹과제/4장/intake.md`·`raw/` 15화면과 `23, 24 소스/4강 합본.pdf`(캡처 파일명상 2026-10-08, 실제 응시일 미확인). 6장은 `웹과제/6장/questions.json`·`intake.md`·`note-feedback.md`(2026-10-19 캡처).

## 1장 웹과제 사실 (① 안에서는 반드시 "1장:"을 붙인다)

- 17문항 11분 → 문항당 약 39초. 보기 4개·5개가 섞임.
- 기출과 같은 문제는 Q1·Q7 둘뿐이고, 그마저 보기 순서가 바뀜. 15/17은 다른 문장.
- 8/17이 부정형("옳지 않은 것", "속하지 않는 것").
- 표기 차이: 웹과제 "전자전달사슬"·"뉴클레오티드" ↔ 노트 "전자전달계"·"뉴클레오타이드".

## 2장 웹과제 사실 (① 안에서는 반드시 "2장:"을 붙인다)

- 16문항, 모두 보기 5개. 시간 제한은 화면에 없음.
- 4/16이 부정형("일어나지 않는 것" Q1, "옳지 않은 것" Q5·Q9, "잘못 설명" Q10).
- 그림 3개: Q4 자유에너지 그래프(구간 I~IV), Q9 세포호흡 개요 모식도((가)(나)(다) 빈 라벨), Q15 ATP 분자.
- 기출과 같은 문제는 3개(Q3·Q13·Q15), 기출 발문 그대로 정답만 바꾼 문제 3개(Q1·Q8·Q10).

## 3장 웹과제 사실 (① 안에서는 반드시 "3장:"을 붙인다)

- 13문항, 모두 보기 5개. 시간 제한은 화면에 없음.
- 6/13이 부정형("옳지 않은 것" Q5·Q6·Q9, "아닌 것" Q10·Q11, "가장 거리가 먼 것" Q7).
- 4/13이 체크박스 형식("최대 4개의 옵션 선택", Q1·Q2·Q4·Q7). 나머지는 라디오.

- Q1은 그림이 아니라 실제 현미경 사진(양파 뿌리 끝)을 판독한다.

## 4장 웹과제 사실 (① 안에서는 반드시 "4장:"을 붙인다)

- 출처: `웹과제/4장/intake.md`와 `웹과제/4장/raw/` 15화면, 동일 문항 비교용 `23, 24 소스/4강 합본.pdf`. 파일명상 캡처일 2026-10-08, 실제 응시·완료일 미확인. 선택 표시를 답으로 사용하지 않음.
- 15문항, Q3만 보기 4개이고 나머지 14문항은 보기 5개. 시간 제한은 화면에 없음.
- 4/15이 부정형(Q1 "관련이 없는", Q2 "잘못된", Q7 "적절하지 않은", Q10 "옳지 않은").
- 체크박스 Q1·Q3·Q6·Q7·Q10·Q13·Q15, 나머지 라디오. 체크박스의 단일/다중 선택 채점 규칙은 확정하지 않음.
- 그림 3개: Q9 가계도, Q11 염색체 구조 변화, Q12 초파리 교배. Q15는 HH/Hh/hh 수용체 수준 표.
- 기출과 발문·보기 내용이 같은 문제 2개(Q3 ↔ 4강 36번, Q6 ↔ 4강 2번; 보기 순서 변경, Q6의 겹친 기호는 intake의 판독 유보 유지). Q2·Q8은 기출 39번·3/44번과 발문이 유사하지만 보기 내용이 달라 동일 문항으로 세지 않음.

## 5장 웹과제 사실 (① 안에서는 반드시 "5장:"을 붙인다)

- 출처: `웹과제/5장/questions.json`, `intake.md`, `note-feedback.md`와 연결된 raw 17화면(2026-10-15). 사용자는 전체 문항·응시 완료를 확인했다. 캡처는 제출 전이며 공식 답·최종 제출 답은 미확인이다. 기출 재사용은 미집계다.
- 17문항·84보기, Q14만 4보기. 시간 제한 미확인으로 문항당 시간을 만들지 않는다. 1장 수치를 참고로 쓰면 반드시 "1장:"을 붙인다.
- 부정형 5/17(Q3·Q4·Q6·Q8·Q14). 수치 계산 Q11, 서열 처리 Q5·Q7, 표 판독 Q7 코돈표다. 유형은 중복된다. bank 그림 자산 1개와 표 판독 1개는 같은 문항의 다른 분류다.
- 명칭 전환 Q9(넌센스/nonsense ↔ 강의노트 PDF 6쪽의 정지 돌연변이), 비교 단위 Q1/Q6(전구체/성숙 mRNA), 대상·단계 Q3/Q4/Q15가 요구된다. Q9는 영어만 나온 문제가 아니다.
- Q3·Q6·Q9의 캡처 선택과 분석 답 차이를 공식 오답으로 세지 않는다. Q7 무선택·원문 방향 생략은 개인 진단에서 보류한다. 아래 패턴은 출제 요구이며 학생의 확정 취약점이 아니다([공통 기준](../../bio-review-pack/references/note-feedback.md)).

## 6장 웹과제 사실 (① 안에서는 반드시 "6장:"을 붙인다)

- 14문항·70보기, 모두 보기 5개, 전 문항 라디오(단일 선택). 시간 제한 미확인.
- 부정형 6/14(Q3·Q6·Q7·Q8 "옳지 않은 것", Q12 "요소가 아닌 것", Q14 "옳지 않은 것").
- 그림 1개: Q14 크리스퍼-카스 그림(A·B·C 표지, 문제 그림에 표적 DNA 없음). 계산 1개: Q13 PCR 이론 총 DNA 분자 수(3분자, 5주기).

## 패턴 → 이 장 구역 번호로 잇기

| 패턴 | 예 | ① 줄에 쓸 것 |
|---|---|---|
| 보기 순서 바뀜 | Q1·Q7 | 번호 말고 내용으로 확인 |
| 다른 문장 | 15/17 | 개념으로 찾기, 표기가 다르면 ② |
| 부정형 발문 | 8/17 | 각 구역 함정 상자부터 |
| 그림 변형(이온형·회전·표지 교체, 실제 사진) | 1장 Q9·Q14, 3장 Q1 사진 | 그림 판독이 필요한 이 장 구역 번호들 |
| 조건 바꾸기 | Q15(같은 종 → 여러 종+무생물) | 조건이 바뀌면 답이 바뀌는 이 장 구역 번호들 |
| 거꾸로 묻기(기능 → 대상) | Q5·Q8 | 결과·기능으로 원인·장소를 물을 만한 구역 번호들 |
| 포함·제외와 결정 단서 | Q2·Q4·Q17 | "~이 아닌 것"을 물을 목록, "이 말이면 이것" 단서가 있는 구역 번호들 |
| 체크박스 형식 | 3장 Q1·Q2·Q4·Q7 | "최대 4개 선택" 표시에 휘둘리지 말고 보기마다 참·거짓 판정 |
| ㄱ·ㄴ·ㄷ 조합형 | 3장 Q12 | 진술 하나씩 판정한 뒤 조합 고르기. 진술마다 판정 근거가 있는 구역 번호들 |
| 같은 발문, 다른 정답 | 2장 Q1·Q8·Q10(기출 2강 9·39·32번 발문 그대로) | 발문이 익숙해도 보기마다 참·거짓 판정. 외운 답 번호로 고르지 않기 |
| 오타로 정답이 이상해 보임 | 2장 Q7 "관계"(=광계), Q1 "관합성", Q5 "마지막 관계" | 말이 안 되는 보기는 비슷한 용어로 바꿔 읽어 보기 |
| 다른 장 개념이 섞임 | 3장 Q7 정답 "연관"(4장 개념) | 아는 범위 밖 낱말이 정답일 수 있음. 응시일까지 배운 다음 장 개념도 후보 |
| 표로 기능 수준 비교 | 4장 Q15 HH/Hh/hh 수용체 수준 | 표의 중간 수준·없음·정상 수준을 먼저 비교하고 관련 구역에서 판별 |
| 명칭 전환 | 5장 Q9 정지/넌센스/nonsense | 원천에서 확인한 대응과 현상 단서는 ② |
| 비교 단위 변경 | 5장 Q1 전구체 한 개/Q6 성숙 mRNA 한 종류 | 무엇 하나를 세는지 확인하고 관련 구역으로 |
| 작용 대상·단계 변경 | 5장 Q3·Q4·Q15 | DNA/RNA/단백질 중 바뀐 대상과 조절 단계를 확인 |
| 계산 문항 | 5장 Q11, 6장 Q13 PCR 총 분자 수 | 무엇을 세는지(분자/가닥) 확인하고 원천의 식이 있는 구역으로 |
| 순환 순서의 시작점 | 6장 Q5 PCR 1사이클 | 원천이 정한 첫 단계부터 순서를 맞춰 보기 |

① 구역은 표에서 이 장에 적용 가능한 줄을 `ul.pts`로 쓰고, 각 줄 끝에 이 장의 구역 번호(③ ⑦ …)를 단다. 시간 제한이 확인된 경우에만 문항당 초를 쓴다. 미확인인 장에 1장 시간을 이 장 값처럼 쓰지 않는다.

## 새 웹과제가 등록되면

위 사실 목록에 없는 장의 `웹과제/<N>장/questions.json`이나 `raw/` 화면이 있으면, 시트를 만들기 전에 메인 에이전트가 **이 파일을 직접 고친다**(SKILL.md 0단계). 그 평가의 문항 수, 시간 제한, 부정형 비율, 그림 문항, 기출과 같은 문제를 세어 "N장 웹과제 사실" 절을 더한다. 위 표에 없는 패턴이 보이면 표에 줄을 더한다. 이 파일이 바뀌면 해시가 달라지므로, 이미 만든 시트는 `stale.py`가 낡은 시트로 보고한다.
