# 당황 패턴 — ① 시험장 체크의 원천

기출만 공부하고 웹과제를 봤을 때 당황한 지점이다. 출처: `docs/2026-09-17-1장-웹과제-분석과-노트-개선안.md` §3(시험 구성)·§5(문항별 감사).

## 1장 웹과제 사실 (① 안에서는 반드시 "1장:"을 붙인다)

- 17문항 11분 → 문항당 약 39초. 보기 4개·5개가 섞임.
- 기출과 같은 문제는 Q1·Q7 둘뿐이고, 그마저 보기 순서가 바뀜. 15/17은 다른 문장.
- 8/17이 부정형("옳지 않은 것", "속하지 않는 것").
- 표기 차이: 웹과제 "전자전달사슬"·"뉴클레오티드" ↔ 노트 "전자전달계"·"뉴클레오타이드".

## 패턴 7개 → 이 장 구역 번호로 잇기

| 패턴 | 1장 예 | ① 줄에 쓸 것 |
|---|---|---|
| 보기 순서 바뀜 | Q1·Q7 | 번호 말고 내용으로 확인 |
| 다른 문장 | 15/17 | 개념으로 찾기, 표기가 다르면 ② |
| 부정형 발문 | 8/17 | 각 구역 함정 상자부터 |
| 그림 변형(이온형·회전·표지 교체) | Q9·Q14 | 그림 판독이 필요한 이 장 구역 번호들 |
| 조건 바꾸기 | Q15(같은 종 → 여러 종+무생물) | 조건이 바뀌면 답이 바뀌는 이 장 구역 번호들 |
| 거꾸로 묻기(기능 → 대상) | Q5·Q8 | 결과·기능으로 원인·장소를 물을 만한 구역 번호들 |
| 포함·제외와 결정 단서 | Q2·Q4·Q17 | "~이 아닌 것"을 물을 목록, "이 말이면 이것" 단서가 있는 구역 번호들 |

① 구역은 위 7줄을 `ul.pts`로 쓰고, 각 줄 끝에 이 장의 구역 번호(③ ⑦ …)를 단다. 맨 위 한 줄에 시간 압박(문항당 초)을 쓴다.

## 새 웹과제가 등록되면

1장 말고 다른 장의 `웹과제/<N>장/questions.json`이 있으면, 메인 에이전트가 그 평가의 문항 수·시간 제한·부정형 비율을 세어 ① 맨 위 사실 줄에 "N장:"으로 더하고, 위 표에 없는 패턴이 보이면 ① 줄을 하나 더한다. 이 파일은 고치지 않고, 끝 보고에 "panic-patterns.md 갱신 제안"으로 적는다.
